# 測定ツール マニュアル

このドキュメントは、本ソフトウェアを使って  
**音声信号や測定対象を観測・評価するための操作方法**をまとめたものです。

本ツールは、専用の測定器を持たない環境でも、
PC とオーディオインターフェースを使って
基本的な測定や観測ができることを目的としています。

---

## このマニュアルの読み方

- 初めて使う方は  
  → [クイックスタート](quickstart.md) を先に読んでください
- 特定の機能を使いたい場合は  
  → 各 **ウィジットの説明** を参照してください
- 実際の測定例を知りたい場合は  
  → **測定レシピ** を参照してください

---

## 前提条件

このマニュアルでは、以下を前提としています。

- ソフトウェアはすでに起動できている
- オーディオ入力・出力デバイスはOS上で認識されている
- 基本的なPC操作ができる

インストール方法やビルド手順については、本書では扱いません。
