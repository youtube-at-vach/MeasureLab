# クイックスタート

## 1. ソフトウェアを起動する

MeasureLab は Windows および Linux で動作します。
[Releases](https://github.com/vach/MeasureLab/releases) ページから、お使いの OS に合わせた最新バージョンをダウンロードしてください。

### Windows の場合
1. `MeasureLab-<version>-windows-x64-onefile.zip`（または `onedir.zip`）をダウンロードします。
2. ZIP ファイルを解凍します。
3. フォルダ内の `MeasureLab.exe` をダブルクリックして実行します。

### Linux の場合
1. `MeasureLab-<version>-linux-x86_64.AppImage` をダウンロードします。
2. ファイルに実行権限を付与します。
   ```bash
   chmod +x MeasureLab-*-linux-x86_64.AppImage
   ```
3. そのまま実行します。
   ```bash
   ./MeasureLab-*-linux-x86_64.AppImage
   ```

!!! info "初回起動時の注意：FFT 最適化 (WISDOM)"
    初回起動時、高速フーリエ変換 (FFT) の処理を高速化するために **「WISDOM」** と呼ばれる最適化データの生成が行われます。
    
    *   この処理には数秒〜数十秒かかる場合がありますが、異常ではありません。
    *   生成されたデータはキャッシュされ、**次回起動時からはロードされるため高速に起動します**。
    *   **ソフトウェアを別の PC に移動した場合**や CPU が変わった場合は、再度この最適化処理が必要になります（自動的に行われます）。

## 2. UIの表示設定

Settings ウィジットでは、使いやすいように UI の言語や配色を変更できます。

### 言語設定 (Language)
デフォルトでは英語になっている場合があります。
**Languages** コンボボックスから **Japanese** を選択すると、インターフェースが日本語に切り替わります。

### テーマ設定 (Theme)
環境や好みに合わせて配色を変更できます。
**Themes** コンボボックスから選択してください。

*   **Dark**: 暗い場所でも目に優しいダークモード（推奨）
*   **Light**: 明るい表示
*   **System**: OS の設定に追従

## 3. サウンドデバイスの設定

起動したら、まずはオーディオ入出力の設定を行います。
左側のメニューから **Settings** ウィジット（歯車アイコン）を開いてください。

### Windows の場合
デバイスリストから使用するオーディオインターフェースなどを選択します。
Windows の場合、複数のドライバモード（MME, DirectSound, WASAPI, ASIO など）が表示されることがありますが、可能な限り **WASAPI** （または対応していれば ASIO）を選択することを推奨します。これらは低遅延で安定した動作が見込めます。

### Linux の場合
Linux 環境で高精度な測定（特に位相連続性が重要な測定）を行う場合、サウンドサーバーとして **JACK** または **PipeWire** の使用を強く推奨します。

1. システム側で JACK または PipeWire が動作していることを確認してください。
2. Settings ウィジットで、入出力デバイスとして `jack` などを選択します。
3. **「Jack/Pipewire mode」** のチェックボックスに必ずチェックを入れてください。
   *   これにより、MeasureLab が位相連続性を保った処理モードに切り替わります（チェックがないとバッファ境界で位相が飛ぶ可能性があります）。

### 入出力とサンプリング設定の推奨

*   **入出力チャンネル (Input/Output)**
    *   基本的にはデフォルトのまま **Stereo (2ch)** を選択してください。
*   **サンプリングレート (Sampling Rate)**
    *   PC のスペックが許す限り、**192kHz** などの高いレート（ハイレゾ設定）を選択することをお勧めします。より広い帯域を測定でき、時間分解能も向上します。
*   **バッファサイズ (Buffer Size)**
    *   **「長め」に設定することを強く推奨します。**
    *   本ソフトウェアはリアルタイム演奏用ではなく「測定用」です。ごく短時間のレイテンシーよりも、データの安定性が重要です。
    *   もし音が飛んだり（ドロップアウト）、波形が途切れる場合は、バッファサイズをさらに大きく設定してください。

---

## 4. 測定を開始する

設定が完了したら、実際にウィジットを開いて測定を始めましょう。

*   **周波数を詳しく見たい** → [Spectrum Analyzer](widgets/spectrum_analyzer.md)
*   **波形を直接見たい** → [Oscilloscope](widgets/oscilloscope.md)
*   **信号を発生させたい** → [Signal Generator](widgets/signal_generator.md)

各機能の詳細は [ウィジットガイド](widget_guide.md) を参照してください。
