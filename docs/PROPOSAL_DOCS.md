# ドキュメント改善提案 (PROPOSAL_DOCS.md)

このドキュメントは、MeasureLab のドキュメントを「初心者視点」で読み込み、改善点をまとめたものです。

## 1. 全体的な印象

- **良い点**:
    - 「仮想の測定デスク」というコンセプトや、「Hello Loopback」のような実践的な導入は非常に分かりやすく、モチベーションを高めます。
    - `widget_guide.md` の「クイック検索ガイド（やりたいことから探す）」は、機能が多岐にわたる本ツールにおいて非常に有用です。
- **課題**:
    - `README.md` や `quickstart.md` において、専門用語や開発者向けの情報（ビルド手順など）が前面に出すぎており、単にツールを使いたいだけのユーザー（特にWindowsユーザーやLinux初心者）を圧倒してしまう可能性があります。

## 2. 具体的な改善案

### 前提知識の要求レベル (Prerequisites)

- **専門用語の補足**:
    - `README.md` や `quickstart.md` で唐突に登場する `JACK`, `PipeWire`, `FFT Wisdom`, `AppImage`, `venv` などの用語について、初心者は戸惑う可能性があります。
    - **提案**: これらを注釈で補足するか、用語集 (`glossary.md`) を作成してリンクすることを推奨します。特に `FFT Wisdom` については「初回起動時に最適化計算を行う仕組み」と明記されていますが、「Wisdom」という単語自体がFFTW固有の用語であるため、より一般的な表現（「初期最適化」など）を併記すると親切です。
- **ループバック接続の重要性**:
    - `quickstart.md` での解説は丁寧ですが、なぜそれが必要なのか（自己診断、基準作り）をもう少し強調すると、初心者が安心して取り組めます。

### 技術説明の難易度 (Complexity)

- **インストール手順の分離**:
    - `README.md` の「ソースコードから実行する場合」のセクションは、Python環境構築や依存関係の解決を含んでおり、初心者にはハードルが高いです。
    - **提案**: `README.md` では「バイナリ版（実行ファイル）」のダウンロード手順を最優先し、ソースコードからのビルド手順は `DEVELOPMENT.md` または `CONTRIBUTING.md`、あるいは `docs/installation.md` 等の別ファイルに移動させることを検討してください。
- **Linuxオーディオバックエンドの説明**:
    - `quickstart.md` の `JACK / PipeWire` に関する説明は重要ですが、設定項目の場所（「Settingsウィジットのどこにあるか」）が明示されていないため、初心者は迷うかもしれません。スクリーンショットや具体的なパス（例: `Settings > Audio > Driver`）を追加すると良いでしょう。

### 構成と順序 (Structure & Order)

- **Quickstartの順序**:
    - 現在の `quickstart.md` では、「オーディオインターフェースがない場合 (仮想モード)」の説明が、「ソフトウェアを起動する」よりも前に来ています。まだソフトを起動していない段階で設定変更を求められるため、混乱を招きます。
    - **提案**: このセクションを「ソフトウェアを起動する」および「UIの表示設定」の後に移動し、「起動後の設定オプション」として紹介する流れに修正すべきです。

### 読む価値 (Value)

- **Widget Guideの活用**:
    - `widget_guide.md` の冒頭にある表（やりたいこと別インデックス）は非常に価値が高いです。
    - **提案**: `README.md` の「主な機能」セクションから、この表へのリンクをより目立たせる（例: 「目的から探す方はこちら」と大きく表示する）ことで、ユーザーが迷わずに目的の機能に到達できるようになります。

## 3. 初心者・熟練者の両立 (Audience Balance)

- **情報の階層化**:
    - 初心者は「ダウンロードしてすぐ使いたい」、熟練者は「詳細な仕様やカスタマイズ方法を知りたい」というニーズがあります。
    - 現状はこれらが1つのページに混在しています。
    - **提案**:
        - **Level 1 (入門)**: `README.md` (概要とダウンロードリンクのみ), `quickstart.md` (インストール〜Hello Loopback)。
        - **Level 2 (活用)**: `widget_guide.md`, `measurement_recipes/`.
        - **Level 3 (詳細/開発)**: ビルド手順、詳細なアルゴリズム説明、APIドキュメントなどは別ディレクトリや `Advanced` セクションに隔離する。

## 4. まとめ

MeasureLab は非常に多機能で強力なツールですが、その多機能さがドキュメントの複雑さにつながっています。「まずは音を出して波形を見る」という最初の成功体験（Hello Loopback）に最短距離で到達できるよう、導入部分の情報を整理・削減することが、初心者ユーザーの定着に繋がると考えます。
