# 用語集 (Glossary)

MeasureLab のドキュメントで使用される専門用語の解説です。

## オーディオ・システム関連

### JACK (JACK Audio Connection Kit)

Linux でプロフェッショナルなオーディオ処理を行うためのサウンドサーバーデーモンです。低遅延な接続と、アプリケーション間の自由な配線（ルーティング）を実現します。MeasureLab で位相同期が必要な精密な測定を行う場合に推奨されます。

💡 **身近な例えで言うと：**
JACKは、テレビ局やスタジオにある「プロ用の巨大な配線盤」のようなものです。「このアプリの音を、あのアプリとスピーカーの両方に同時に送る」といった複雑な接続を、音の遅れ（遅延）なしで完璧にこなしてくれます。

### PipeWire

Linux における新しいマルチメディアサーバーです。従来の PulseAudio と JACK の両方の機能を統合・置換することを目指しています。最新の Linux ディストリビューションでは標準採用が進んでおり、JACK と同様に低遅延かつ柔軟なルーティングが可能です。

💡 **身近な例えで言うと：**
PipeWireは、古いシステムとプロ用システム（JACK）のいいとこ取りをした「次世代の賢い交通整理役」です。普段使いの気軽さと、プロ用の正確さを両立しています。

## アプリケーション・実行環境

### AppImage

Linux 向けのアプリケーション配布形式の一つです。必要なライブラリや依存関係を1つのファイルにまとめているため、インストール不要で、ファイルをダウンロードして実行権限を与えるだけで起動できます。

💡 **身近な例えで言うと：**
AppImageは「全部入りの幕の内弁当」です！ 普通のアプリは「ご飯はここ、おかずはあそこ」とバラバラに準備（インストール）する必要がありますが、AppImageならこれ一つポツンと置くだけで、すぐに美味しい機能が楽しめます。

### venv (仮想環境)

Python の標準機能で、プロジェクトごとに独立した実行環境を作成する仕組みです。システムの Python 環境を汚さずに、MeasureLab に必要な特定のバージョンのライブラリをインストールするために使用します。

💡 **身近な例えで言うと：**
venvは、パソコンの中に作る「一時的な専用の実験机」です。ここでどんなに散らかしても（色々な部品を入れても）、他の机（システム全体）には全く影響が出ないので、安心して作業できます。終わったら机ごと捨てることも簡単です！

## その他

### FFT Wisdom (初期最適化)

高速フーリエ変換 (FFT) ライブラリである FFTW が行う、「その計算機で最も高速に計算できるアルゴリズム」を探索・保存する仕組みです。MeasureLab の初回起動時にこの計算が行われるため、数十秒〜数分待たされることがありますが、2回目以降は保存された「Wisdom（知恵）」を使って瞬時に起動します。

#### ☕ コーヒーブレイク：Wisdom（知恵）ってどういうこと？

新しい職場や学校に通い始めた初日を想像してみてください。初日は地図アプリを見ながら「こっちの道が早いかな？ あっちの道が空いてるかな？」と試行錯誤するので時間がかかりますよね。
でも、何日か通うと**「自分だけの最速の通勤ルート（Wisdom）」**が見つかり、次からは迷わず最速で到着できるようになります。

FFTW（計算エンジン）も全く同じことをしています！ あなたのパソコンのCPUに一番合った「計算の裏道」を初日に一生懸命探して、それを「Wisdom（知恵）」という名前のファイルにメモしているのです。だから初回の起動だけ、少しだけ温かく見守ってあげてくださいね。
