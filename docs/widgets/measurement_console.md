# 計測コンソール（試験的機能）

## 概要

計測コンソールは、複数の測定ウィジェットを1つのドッキング可能なウィンドウで観察・操作するための
ワークスペースです。メインウィンドウにある既存のウィジェットインスタンスをそのまま移動するため、
リアルタイム音声処理が重複して作成されることはありません。

メインウィンドウのサイドバー上部にある **計測コンソール** から開きます。

## 計器の操作

* **計器を追加**: ウィジェットをコンソールに追加します。すでにコンソール内にあるウィジェットは、
  このメニューで選択できません。
* **計器ドックを閉じる**: そのウィジェットをメインウィンドウの通常ページへ戻します。状態と進行中の
  測定は保持されます。
* **コンソールで表示**: コンソール内にあるウィジェットの通常ページでは、このボタンで対応するドックを
  前面へ表示できます。
* **すべて停止**: コンソール内で実行中の対応測定器を一括停止します。停止済みの測定器と、単一の
  開始／停止主操作を持たない測定器には影響しません。

初期プリセットには、オシロスコープ、スペクトラムアナライザー、スペクトログラム、ゴニオメーターが
含まれます。意図してこの構成へ戻すときは **レイアウト → デフォルトコンソール** を使います。

## レイアウトと操作

ツールバーの配置図ボタンを押すと、ワンクリックでレイアウトを変更できます。
**レイアウト** メニューから名前で選ぶこともできます。枠で強調されたボタンが選択中のプリセットです。
選択中のボタンをもう一度押すと、計器の配置を1つずつ順送りします。メイン＋サブ配置では、
次の計器がメインになります。区画数を超えてタブに入っている計器も順送りの対象です。
別のプリセットを選ぶときは順送りせず、その配置を適用します。
比率だけを戻すには **レイアウト → 配置を整え直す** を使います。

| プリセット | 配置 |
| --- | --- |
| **タブ表示** | 1つの区画で全計器をタブ切り替え。 |
| **横に並べる** | 同じ幅の2列。 |
| **2 x 2 グリッド** | 2列・2行の4区画。 |
| **2列 × 3行** | 縦方向に並ぶ6区画。 |
| **3列 × 2行** | 横方向に並ぶ6区画。 |
| **メイン＋右に3分割** | 幅の約3分の2をメインに使い、右側に3区画を縦に配置。 |
| **メイン＋下に3分割** | 高さの約3分の2をメインに使い、下側に3区画を横に配置。 |

グリッドには左から右、上から下の順に計器を配置します。計器が少ないときは空き区画を詰め、
区画数を超えた計器はタブで切り替えられます。プリセットを変更しても、計器・測定設定・実行中の測定は保持されます。

* **レイアウト → メイン計器**: メインを大きく表示する2種類の配置で、主役にする計器を選択します。
  初期状態では最初に追加した計器を使います。
* **レイアウト → 配置を整え直す**: 選択中のプリセットの比率へ戻します。
* **配置を元に戻す**: 直前のプリセット変更・順送り・メイン計器変更前の配置へ戻します。手動調整した仕切りの位置も
  復元します。**Alt+Backspace** でも操作できます。計器を追加・削除すると、この復元履歴は消去されます。
* **レイアウト → デフォルトコンソール**: 初期の4計器を2×2で配置し直します。

ドックはドラッグで配置を変更したり、タブ化したりできます。配置後に **レイアウトを固定** を有効にすると、
誤操作による計器の追加・削除やプリセット変更を防げます。測定の操作は引き続き利用できます。

対応モジュールでは、ドックのタイトルバーに開始／停止の主操作が表示されます。表示名、アイコン、有効状態、
実行状態は元のボタンと同期します。安全に1つの開始／停止ボタンへまとめられないモジュールでは、
この主操作は表示されず、**すべて停止** の対象にもなりません。

## ワークスペースの復元

コンソールは、追加した計器、ドックの配置、ウィンドウサイズ、固定状態、対応するコンパクトモードの選択を
保存します。選択したプリセットとメイン計器も保存対象です。保存済みレイアウトを安全に復元できない場合は、見える状態のデフォルトレイアウトへ戻ります。
小さな画面ではタブ表示に調整し、大きな画面へ戻ったときに元の配置を復元します。
この元の配置はアプリを再起動しても保持されます。小さな画面でもプリセットを明示的に選び直せます。

## 制限事項

これは試験的なワークスペース機能です。1つのメインウィンドウでの利用を前提としており、1つの計器を
通常ページとコンソールの両方に同時表示することはできません。
