# Lock-in Modeler

## 概要

Lock-in Modelerは、同期スイープサイン (Synchronized Swept Sine, SSS) 信号とデジタルロックイン検出アルゴリズムを使用して、測定対象システム（DUT）の周波数特性および非線形歪み特性を極めて高い精度で高速測定するツールです。

本ツールは通常の周波数スイープ測定（基本波および最大5次の高調波の同時追跡）に加え、**非線形モデル（ハマーシュタインモデル）同定機能**を備えており、同定したモデルをJSONファイルとしてエクスポートできます。

## 測定手順

### 1. 遅延キャリブレーション（必須）

測定を実行する前に、オーディオ入出力系統の往復レイテンシを正確に測定し、補正する必要があります。キャリブレーションが行われていない場合、測定開始ボタンは無効化されます。

1. **Calibrate Latency** ボタンをクリックします。
2. テスト信号が送信され、自動的にシステムのレイテンシ（サンプル数およびミリ秒）が測定されて表示されます。
3. キャリブレーションが成功すると、**Start Sweep** ボタンが有効になります。

### 2. スイープ測定の実行

1. `Settings` タブで `Sweep Mode` や周波数範囲などのパラメータを設定します。
2. **Start Sweep** ボタンをクリックして測定を開始します。
3. スイープ中は `Overview` パネルに進捗率、現在の信号周波数、解析中の周波数、および等価ノイズ帯域幅（ENBW）が表示されます。
4. 測定を途中で停止するには **Stop Sweep** ボタンをクリックします。

## 設定項目

### Settings（設定）タブ

* **Sweep Mode (スイープモード)**: 3つの測定モードから選択します。
    * `Sweep Measurement (Default)`: 標準のスイープ測定を行い、基本波および設定された高調波の応答をプロットします。
    * `Nonlinear Model (Forward)`: 標準のフォワードモデルを使用し、異なるテスト振幅レベルで自動的に複数回のスイープを実行して高次カーネルを同定します。
    * `Nonlinear Model (Parallel Complex)`: 複雑な非線形挙動を捉えることができる、並列複素ハマーシュタイン構造（Parallel Complex Hammerstein structure）を用いて非線形モデルを同定します。
* **Start Freq / End Freq (開始/終了周波数)**: スイープする周波数の範囲を 2.0 Hz からナイキスト周波数（サンプリング周波数の半分）の間で指定します。
* **Duration (スイープ時間)**: 1回のスイープ時間を秒単位（2.0 s 〜 600.0 s）で設定します。
* **Amplitude (振幅)**: 出力信号のレベルを dBFS 単位（-100.0 dBFS 〜 0.0 dBFS）で設定します。
* **Max Harmonic (最大高調波次数)**: 解析する最高高調波次数（1次〜5次）を設定します。
* **Averages (アベレージング回数)**: 各振幅レベルにおけるスイープの平均化回数を設定します。値を増やすとランダムノイズが低減され、SNRが向上します。
* **Amplitude Steps (振幅ステップ数)**: 非線形モデルモード選択時に有効になり、同定に使用する振幅測定ポイントの数（5 〜 10ステップ）を設定します。

### Advanced Settings（高度な設定）

* **Advanced Settings**: 高度なアルゴリズムパラメータを設定するダイアログを開きます。
    * **Time-Synchronized Averaging (TSA)**:
        * **Cycles (サイクル数)**: 平均化するサイクル数（1〜100）。
        * **Rejection Threshold (棄却閾値)**: 外れ値を除外するための標準偏差の閾値。

### Display（表示設定）タブ

* **Show Relative to Fundamental (基本波相対表示)**: 有効にすると、各高調波の振幅および位相が絶対値ではなく、基本波の応答に対する相対値（dB / 度）としてプロットされます。
* **Unwrap Phase (位相アンラップ)**: 有効にすると、$\pm 180$ 度を超える位相の変化を折り返さずに連続的な曲線として滑らかにプロットします。
* **Show Raw Lock-in (Unprocessed) (未処理データ表示)**: 有効にすると、平滑化や補間を適用する前の、ロックインアンプから得られた生の測定ブロックデータを表示します（ハマーシュタイン同定モード時は無効化されます）。
* **Display Data (表示データ)**: ハマーシュタインモードにおいて、全体の「Model Kernels」を表示するか、特定のテスト振幅での個別の応答を表示するかを選択します。
* **Graph Smoothing (グラフ平滑化)**: 描画するプロット曲線の平滑化レベルを選択します（None, Low, Medium, High）。内部で Savitzky-Golay フィルタが適用されます。

### Routing（ルーティング）タブ

* **Output Ch (出力チャンネル)**: スイープ信号を出力する物理チャンネル（Left, Right, または Stereo (両方)）を選択します。
* **Input Mode (入力モード)**: 入力信号の取得モードを選択します。
    * `Single Ch (Left Input)`: 左入力チャンネルのみを使用して絶対測定を行います。
    * `Single Ch (Right Input)`: 右入力チャンネルのみを使用して絶対測定を行います。
    * `2-Ch Relative (Ref=Left, Meas=Right)`: 左を入出力監視用のリファレンス、右を測定用として、2チャンネルの比（伝達関数 $H(f)$）を測定します。システム自体の非線形歪みや周波数特性のうねりを相殺できます。
    * `2-Ch Relative (Ref=Right, Meas=Left)`: 右をリファレンス、左を測定用とする伝達関数測定モードです。
* **REF Phase Lock Only (Absolute) (REF位相同期のみ)**: 2-Ch Relativeモード時のみ有効です。これを有効にすると、リファレンスチャンネルは位相の同期（時間遅れや位相ドリフトの補正）にのみ使用され、振幅特性については相対比ではなく測定チャンネルの絶対レベルとして算出されます。

### Advanced（詳細設定）タブ

* **Analysis Cycles (解析サイクル数)**: 各周波数におけるロックイン解析用ウィンドウのサイクル数を設定します（2.0 〜 2048.0 サイクル）。値を大きくすると周波数分解能が向上しノイズに強くなりますが、過渡応答の影響を受けやすくなります。
* **Meas Points (測定点数)**: スイープ全体におけるサンプリング周波数ポイントの総数を設定します（100 〜 5000 点）。
* **Min Window (最小窓長)**: 解析ウィンドウの最小の長さ（ms）を設定します。極端に高い周波数でウィンドウが短くなりすぎて ENBW が過大になるのを防ぎます。
* **Preset (プリセット)**: 特定の測定シナリオに最適な解析サイクル数と最小窓長のバランスを自動的に設定する事前定義の設定（例：「高速・動的 (16サイクル / 30 ms)」、「Normal (64 cyc / 100 ms)」、「高分解能 (128サイクル / 500 ms)」、「高安定性 (256サイクル / 1.0秒)」、「極大安定性 (512サイクル / 2.0秒)」）を選択できます。「Custom」を選択すると手動調整が可能になります。
* **Real-time Display (リアルタイム表示)**: 有効にすると、スイープ進行中にプロットを即座に更新します。無効にすると、スイープ中は計算をバックグラウンドに回し、測定完了後に一括で描画を行います。これにより、再生中のオーディオバッファアンダーラン（音切れ）のリスクを最小限に抑えられます。

## 解析結果とモデルのエクスポート

### プロットの表示

* **Frequency Response タブ**:
  設定した `Max Harmonic` に応じて、基本波（Fundamental）および各高調波（2nd 〜 5th）の振幅特性（Magnitude）と位相特性（Phase）が表示されます。表示オプションにより、基本波に対する相対特性として見ることも可能です。
* **Impulse Responses (Kernels) タブ**:
  非線形モデル（Hammerstein）測定完了後に有効化されます。同定された 1次から最大5次までの時間領域インパルス応答カーネル（$h_1(t)$ 〜 $h_5(t)$）を表示します。

### モデルの保存と共有

非線形モデル（Hammerstein）測定が完了すると、**Export Model...** ボタンが有効になります。

1. **Export Model...** をクリックします。
2. ファイル保存ダイアログが表示されるので、保存先のパスとファイル名（JSON）を指定します。
3. エクスポートされた JSON モデルには、サンプリングレート、スイープ情報、測定時のパラメータなどのメタデータのほか、時間領域および周波数領域のカーネルデータが含まれます。
4. 保存と同時に、同定されたモデルは MeasureLab 内のアクティブモデルとしてキャッシュに登録されます。これにより、他のモジュール（歪み補正機能など）でこのモデルを即座に適用できるようになります。
