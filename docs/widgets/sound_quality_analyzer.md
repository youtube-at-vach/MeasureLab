# Sound Quality Analyzer (音質評価 / 心理音響分析)

![Sound Quality Analyzer](../assets/widgets/sound_quality_analyzer.png)

## 概要

人間の耳で感じた「音の聞こえ方（主観量）」を数値化するための分析ツールです。単なる電圧や音圧の測定ではなく、心理音響学（Psychoacoustics）に基づいた指標を用いて、音の心地よさや不快さを客観的に評価します。

従来の測定器は電圧や周波数といった物理量を計測しますが、それだけでは人間が「うるさい」「不快だ」と感じる感覚を完全には説明できません。心理音響学は、人間の聴覚メカニズムや脳の認知特性をモデル化し、音の「粗さ（Roughness）」や「鋭さ（Sharpness）」といった主観的な感覚を客観的な数値として評価します。

このツールは**オフライン分析専用**です。録音された音声ファイルを読み込んで解析を行います。

## 指標の説明

* **Integrated Loudness (ラウドネス)**: 人間の耳の感度特性（BS.1770 K特性）を考慮した「音の大きさ」の平均値です。単位は `LUFS` です。
* **Sharpness (シャープネス)**: 音の「鋭さ」や「キンキンした感じ」を表します。高域成分（おおむね 15.8 Bark 以上）が多いほど高い値になります。単位は `acum` です。
* **Roughness (ラフネス)**: 音の「ざらつき」や「粗さ」を表します。振幅変調（70Hz付近など）によって発生する不快なうなりを評価します。単位は `asper` です。
* **Tonality (トナリティ)**: 音の中にどれくらい「純音に近い成分」が含まれているか（Spectral Flatness）を表します。ホワイトノイズのような音は低く、口笛や正弦波のような音は 1.0 に近づきます。単位は `0-1` (正規化値) です。
* **Fluctuation Strength (変動強度)**: ラフネスと同様に音の「うなり」や「変動」を表しますが、よりゆっくりとした変化（おおむね 20Hz 以下、特に 4Hz 付近）を評価します。単位は `vacil` です。
* **Articulation Index (明瞭度指数/AI)**: 騒音下での「言葉の聞き取りやすさ」を表す指標です。0.0 から 1.0 の範囲で、1.0 に近いほど明瞭に聞き取れることを意味します。

## 操作方法

1. **Load File** で音声ファイルを選択します。
    * サポート形式: WAV, FLAC, AIFF
    * 読み込めるファイルのサイズは全チャンネル合計で5億サンプルまで（48kHzステレオの場合、約1時間26分）です。
2. **Analyze** ボタンを押すと解析が始まります。
    * 内部的に 48kHz にリサンプリングして解析されます（心理音響フィルタの最適化のため）。
    * ファイルが長いと時間がかかります。進捗と処理内容を表示し、**キャンセル**で中断できます。実行中の計算段階が終わるまで中断を待つことがあります。
3. 左側の **Summary Metrics** に6指標を表示します。ラウドネスは積分値、ほかの5指標は平均値です。青が左（モノラルでは単一チャンネル）、琥珀色が右です。未解析の値は「—」で表示します。
4. 指標カードを選ぶと、右側の大きなグラフに時間変化を表示します。チャンネルは色と実線・破線で区別します。指標を切り替えても表示中の時間範囲を保持します。
5. **Export CSV** で、各チャンネルの6指標の要約値を保存します。時系列データはCSVに含みません。

グラフの上には算出方法を表示します。シャープネス、ラフネス、変動強度は簡易モデルによる推定値、トナリティはスペクトル平坦度の逆指標です。AIはノイズフロアを −60 dBFS と仮定した推定値で、実際の騒音下の了解度を保証する値ではありません。

### 再生と確認

* **再生 / 一時停止 (▶ / ⏸)**: 解析済みの音声を再生・一時停止します。**停止 (■)** は再生位置を先頭に戻します。再生終了時は末尾の位置を保持し、もう一度再生すると先頭から始まります。
* **時間表示とスライダー**: 現在位置と全体の長さを表示します。スライダーまたはグラフのクリックで任意の位置へ移動できます。
* **Follow Cursor**: 再生位置が表示範囲から外れると、グラフを移動して追従します。再生カーソル自体はこの設定にかかわらず更新されます。
* **グラフ操作**: ドラッグで移動、スクロールで拡大・縮小します。**全体を表示**でファイル全体の時間範囲と縦軸の自動調整に戻ります。
* **ファイルの切替と再解析**: 古い結果と再生データを消去します。ファイル選択ダイアログをキャンセルした場合は結果を保持します。解析失敗時には理由を表示し、再試行できます。

## 使用例

* **不快なノイズの分析**: ファンやモーターの音が「なぜ耳障りなのか」をラフネスやシャープネスで定量化します。
* **サウンドデザインの評価**: 製品の動作音や通知音が、意図したイメージ（穏やか、鋭い、力強いなど）に合っているかを確認します。
* **異常音の検知**: 定常的なノイズの中で、突発的なトナリティの変化（ピー音の発生など）を検出します。
