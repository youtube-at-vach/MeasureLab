# Processor Benchmark

## 概要

リアルタイム測定におけるFFT演算とUI描画のパフォーマンスをテストするツールです。使用しているプロセッサが音声フレームを落とすことなく処理できる最適なFFTサイズの推奨値を判定します。

## 操作方法

### Benchmark Controls (ベンチマーク制御)

- **Start Benchmark**: シーケンシャルベンチマークプロセスを開始します。
- **Safety Factor**: オーディオバッファサイクル時間のうち、処理に割り当てる許容割合を設定します。`0.8`の場合、処理はバッファサイクル時間の80%以内に完了する必要があります。
- **Enable Extreme Sizes (Max 16M)**: 最大 16,777,216 までの極端に大きなFFTサイズのベンチマークを有効にします。

### ベンチマーク結果

- **結果テーブル**: テストされた各FFTサイズにおける理論上の最大リアルタイムFPSを表示します。各種サンプリングレート(44.1kHz, 48kHz, 96kHz, 192kHz)において、リアルタイム処理が可能かどうかを評価します。
    - **OK**: 処理時間が安全制限の80%以内に完了します。
    - **⚠**: 処理時間が安全制限内に完了しますが、80%の警告閾値を超えています。
    - **NG**: 処理時間が安全制限を超過しており、リアルタイム処理はできません。

- **Render Test View**: 描画パフォーマンステスト中にシミュレートされた音声データの振幅スペクトルをプロットします。

- **Recommendations (推奨値)**: ベンチマークスコアに基づき、各サンプリングレートにおける最適なFFTサイズと、達成可能な最大リアルタイム分解能(Hz)を提案します。
