# Welcome (ようこそ)

## 概要

MeasureLabを起動した際に最初に表示されるダッシュボード画面です。本ソフトウェアに含まれる主要な測定ツールのリストアップや、開発のコンセプトを表示します。

初めて本ツールを使用する場合は、ここから各ウィジット（測定ツール）の全体像を把握し、左側のサイドバーから目的のツールを選択してください。

## ☕ コーヒーブレイク：「MeasureLab」という名前の由来と仮想実験室

「Measure」は「測る」、「Lab」は「Laboratory（実験室）」を意味します。
このソフトウェアは、あなたのパソコンの中に作られた **「音の仮想実験室」** です！

現実の世界で本格的なオーディオの実験室を作ろうとすると、大きくて高価な測定器を何台も買って、複雑なケーブルで繋がなければなりません。それはプロのエンジニアにしかできないことでした。
しかし MeasureLab では、左側のメニュー（引き出し）から使いたい測定器（ウィジット）をクリックするだけで、あなたの机（画面）の上にパッと魔法のように現れます。
オシロスコープで波の形を覗き込んだり、スペクトラムアナライザで音の色合いを調べたり… まるで科学者になった気分で、目に見えない「音」の正体を楽しく探求してみてください！

## 操作方法

* **ツールの選択**: 左側のサイドバーにあるアイコンや名前をクリックすることで、各測定ウィジットに切り替えることができます。
* **Menu Onlyモード**: サイドバー下部の「Menu Only」ボタンをクリックすると、右側の画面を隠してUIをコンパクトなメニューのみの表示に折りたたむことができます。このモードの時は、サイドバーのツールをダブルクリックすると別ウィンドウとして分離して開くことができます。
* **アクティビティ表示**: 測定や録音などが実行中のツールは、サイドバー上で名前が強調表示（太字・ハイライト色）されます。マウスオーバーすると詳細な状態（実行中、別ウィンドウで分離中など）をツールチップで確認できます。
* **画面の確認**: 中央のメインエリアにツールのロゴや概要が表示されます。

## 機能

* **主要ツールのプレビュー**: MeasureLabが備えている主要な測定機能（スペクトラムアナライザ、信号発生器、オシロスコープなど）が一覧表示されます。
* **バージョン情報とアップデート通知**: 現在のバージョンを表示します。また、GitHub上で新しいリリースが公開されている場合は、通知が表示されます。通知をクリックするとリリースページを開くことができます。
