# ログビューア (Log Viewer)

## 概要

ログビューアは、アプリケーションの実行中に発生するイベント、警告、エラーなどのログメッセージをリアルタイムで表示するための機能です。問題を診断したり、バックグラウンドでの動作を確認したりするのに役立ちます。

## 主な機能

- **リアルタイム表示**: ログメッセージが生成されるとすぐに表示されます。
- **フィルタリング**: 表示するログレベル（情報、警告、エラーなど）を選択して、必要な情報だけを抽出できます。
- **色分け表示**: ログレベルに応じてメッセージが色分けされ（例：エラーは赤色）、重要度が一目でわかります。
- **ログのクリア**: 表示されているログをクリアして、新しいメッセージだけを確認できます。

## 使い方

1. アプリケーションのメニューから「ログビューア」を開きます。
2. 上部のドロップダウンメニューから、表示したいログのレベルを選択します。
    - `All Logs (DEBUG)`: すべての詳細なログを表示します（開発者向け）。
    - `Info`: 一般的な情報とそれ以上の重要なメッセージを表示します（デフォルト）。
    - `Warnings`: 警告とエラーのみを表示します。
    - `Errors Only`: エラーメッセージのみを表示します。
3. ログの表示をクリアしたい場合は、「Clear Logs」ボタンをクリックします。
