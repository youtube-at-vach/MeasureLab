# Log Viewer

## Overview

The Log Viewer is a feature designed to display log messages such as events, warnings, and errors generated during the application's runtime in real-time. It is highly useful for diagnosing issues and monitoring background activities.

## Key Features

- **Real-time Display**: Log messages appear immediately as they are generated.
- **Filtering**: You can select the log level to display (e.g., Info, Warnings, Errors) to focus on relevant information.
- **Color-Coded Messages**: Messages are color-coded based on their severity (e.g., errors in red) for quick identification.
- **Clear Logs**: You can clear the currently displayed logs to focus only on new messages.

## How to Use

1. Open the "Log Viewer" from the application menu.
2. Select the desired log level from the dropdown menu at the top.
    - `All Logs (DEBUG)`: Displays all detailed logs (useful for developers).
    - `Info`: Displays general information and more critical messages (default).
    - `Warnings`: Displays only warnings and errors.
    - `Errors Only`: Displays only error messages.
3. Click the "Clear Logs" button to clear the display.
