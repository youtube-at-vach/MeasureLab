# Spatial Binaural Mixer

## 概要

複数の音声ファイルを聴取者の周囲に配置し、ステレオHRTFデータを使ってバイノーラル音声を生成・試聴・保存するウィジットです。
処理はオフラインで行い、位置やゲインの変更は次のレンダリングに反映されます。編集中は直前のミックスの試聴が停止します。

画面は上から見た方位図と、番号付きのトラックカードで構成されます。方位図は方向のみを表し、距離や仰角は表しません。
ライトテーマとダークテーマの両方に対応しています。

## 音源の読み込みと配置

1. **SOFAを読み込む**で、ステレオHRIRデータセット（`.sofa`、`.nc`）を読み込みます。
   共通ローダーは、度単位の球面座標と両耳のインパルス応答を前提としています。
2. **音声ファイルを追加**で複数ファイルをまとめて追加できます。**トラック追加**で空のカードを作り、
   **音声ロード**でファイルを指定・交換することもできます。
3. カードの番号を選択し、方位図をクリックまたはドラッグして方位角を変更します。カードで角度を直接入力することもできます。
   方位図にフォーカスがあるときは左右キーで1°、Shift＋左右キーで10°ずつ変更し、Homeで正面へ戻せます。
4. 仰角とゲインはカードで設定します。ファイル名にポインターを置くと、完全なパス、長さ、サンプルレート、チャンネル数を確認できます。

角度は、読み込んだHRIRと同じSOFAの座標規約に従います。

| パラメーター | 方向 |
| --- | --- |
| 方位角 0° | 正面 |
| 方位角 +90° | 聴取者の左 |
| 方位角 −90° | 聴取者の右 |
| 方位角 ±180° | 背面 |
| 仰角 0° | 水平面 |
| 仰角 +90° / −90° | 真上 / 真下 |

[SOFA座標仕様](https://sofacoustics.org/mediawiki/index.php/SOFA_specifications)も参照してください。
旧ガイドの左右表記は逆でした。レンダラーの角度の扱い自体は変更していません。

すべての音源は同時に開始します。複数チャンネルのファイルは、各チャンネルを**平均してモノラル化**してから空間処理します。
元のステレオ幅は維持されず、逆相のチャンネルは打ち消し合う場合があります。タイムライン編集機能はありません。

**ソロ**は読み込み済みのソロ音源だけをミックスに含めます。**ミュートはソロより優先**され、常にその音源を除外します。
空のカードをソロにしても読み込み済みの音源は消音されません。対象外または未読み込みの音源は、方位図の番号に斜線を表示します。
マーカーが重なる音源もカードの番号から選択できます。カードを削除しても残りの音源の番号は変わりません。

## プレビュー区間

**プレビューモード**では、すべての対象音源の同じ時間区間を処理します。開始位置と長さを指定し、前／次の区間ボタンで長さ分だけ移動できます。
既に終了した音源は無音として扱い、末尾へ巻き戻しません。選択区間に音声がなければエラーを表示します。

画面の対象区間は**試聴とWAV出力の両方**に適用されます。ミックス全体を書き出す場合はプレビューモードを解除してください。
畳み込みのフィルター末尾を含めるため、出力は指定した音源区間より長くなることがあります。
区間ごとに独立して畳み込むため、開始位置より前の音声に由来するフィルターの履歴は含みません。

## レンダリング・試聴・保存

* **レンダー＆モニター**は現在のミックスを生成し、使用中のオーディオデバイスで試聴します。
* **モニター停止**は試聴を停止し、音声コールバックを解除します。最後まで再生したときも自動的に解除します。
* **WAVへレンダリング**は先に保存先を指定し、バックグラウンドで生成・保存します。形式はステレオの32ビットFloat WAVです。
  ファイルのサンプルレートには処理開始時の値を使用し、全体の書き込みが成功してから保存先を置き換えます。
* 進捗、キャンセル、再生位置は画面内に表示します。処理中は設定を固定します。
  キャンセルは実行中の読み込み、リサンプリング、畳み込み、ピーク解析の区切り、または書き込みブロックの間で反映されます。
* ウィジットを離れる・閉じると試聴を停止し、実行中のレンダリングをキャンセルします。
  キャンセルした結果から試聴を開始したり、保存先のファイルを置き換えたりすることはありません。
* デバイスのサンプルレートが変わった場合は、異なる速度で再生せず、再レンダリングを求めます。
  WAV出力には引き続き処理開始時のサンプルレートを使用します。

生成後は、出力の長さとピーク対策で適用した減衰量を確認できます。

## 処理方式と出力ヘッドルーム

球面上の角距離による逆距離加重で最大3点のHRIRを補間し、必要に応じてリサンプリングした後、FFT畳み込みを行います。
加算はfloat64で行い、全ファイルの展開済み音声を同時に保持せず、音源ごとに順次処理します。
ただし、出力バッファと処理中の畳み込みには音声の長さに応じたメモリが必要です。
補間品質はデータセット、測定角度の範囲、HRIRの特性に依存します。補間によって未測定の音響情報が増えるわけではありません。

推定True Peakが−1 dBTPを超えた場合は、ミックス全体を減衰します。ステレオのバランスを維持し、圧縮や小音量の自動増幅は行いません。
4倍補間と余裕の確保でサンプル間ピークによる過大出力を抑えますが、すべてのDACの再構成フィルターで非クリップを保証するものではありません。
