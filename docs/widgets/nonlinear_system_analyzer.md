# Nonlinear System Analyzer

Nonlinear System Analyzer（非線形システムアナライザ）は、オーディオ機器やアンプ等の非線形特性を詳細に解析するための高度なウィジットです。
Synchronized Swept Sine (SSS) を用いて、システム応答から線形成分（基本波）と各次数の高調波成分（カーネル）を分離・抽出します。
Hammersteinモデルに基づく非線形解析により、複雑な歪み特性の評価が可能です。

## ☕ Coffee Break: Hammersteinモデルとは？

Hammerstein（ハンマースタイン）モデルは、現実のオーディオ機器（スピーカーや真空管アンプなど）の歪みを数学的に表現する手法の一つです。
入力信号がまず「非線形な要素（歪む部分）」を通り、次に「線形な要素（周波数特性を持つフィルタ）」を通る、という直列構造を仮定しています。
このモジュールでは、このモデルを利用して測定した信号から各次数の歪み成分（カーネル）を逆算して分離し、より精密な歪み特性を描き出します。

## 概要

このウィジットでは以下の解析が可能です。

* **Hammerstein Kernel Extraction:** 測定対象の応答から、1次（線形）から5次までのカーネルを抽出します。
* **周波数特性表示:** 抽出された各次数のカーネルの周波数特性（Magnitude）をグラフに表示します。
* **THD/高調波歪み解析:** 基本波に対する各高調波成分のレベルを測定し、歪みの周波数依存性を評価します。
* **インパルス応答表示:** 各カーネルの時間領域でのインパルス応答を確認できます。

## 使用方法

1. **Ref. Channel / Meas. Channel:** リファレンス（基準）となるチャンネルと、測定対象が接続されたチャンネルを選択します。
2. **Start Frequency / End Frequency:** スイープ信号の開始・終了周波数を設定します。
3. **Sweep Duration:** 1回のスイープにかける時間を設定します。長くするとS/N比が向上します。
4. **Num Amplitudes:** 解析に使用する振幅ステップ数（通常は5程度）を設定します。
5. **Average:** 測定の平均化回数を設定します。
6. **Analyze ボタン:** クリックすると測定シーケンスが開始されます。

## グラフの見方

* **Fundamental (Linear Kernel h1):** システムの線形な周波数応答（基本波）を示します。
* **2nd Order (Kernel h2) 〜 5th Order (Kernel h5):** 2次から5次までの非線形カーネルの周波数特性（歪み成分）を示します。
