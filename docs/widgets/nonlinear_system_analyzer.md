# Nonlinear System Analyzer

Nonlinear System Analyzer（非線形システムアナライザ）は、オーディオ機器やアンプ等の非線形特性を詳細に解析するための高度なウィジットです。
Synchronized Swept Sine (SSS) を用いて、システム応答から線形成分（基本波）と各次数の高調波成分（カーネル）を分離・抽出します。
Hammersteinモデルに基づく非線形解析により、複雑な歪み特性の評価が可能です。

## ☕ Coffee Break: Hammersteinモデルとは？

Hammerstein（ハンマースタイン）モデルは、現実のオーディオ機器（スピーカーや真空管アンプなど）の歪みを数学的に表現する手法の一つです。
入力信号がまず「非線形な要素（歪む部分）」を通り、次に「線形な要素（周波数特性を持つフィルタ）」を通る、という直列構造を仮定しています。
このモジュールでは、このモデルを利用して測定した信号から各次数の歪み成分（カーネル）を逆算して分離し、より精密な歪み特性を描き出します。

## 概要

このウィジットでは以下の解析が可能です。

* **Hammerstein Kernel Extraction:** 測定対象の応答から、1次（線形）から5次までのカーネルを抽出します。
* **ボード線図（振幅・位相）表示:** 抽出された各次数のカーネルのゲイン特性（Magnitude）および位相特性（Phase）をグラフ表示します。
* **インパルス応答表示:** 各カーネルの時間領域でのインパルス応答（時間波形）を確認できます。
* **高調波シミュレータ:** 測定データを基に、任意の周波数と振幅の正弦波を入力した際の出力高調波成分（1次〜5次）のスペクトルと各要素のレベルをリアルタイムに予測・シミュレーションします。

## 設定項目

### SSS Parameters（SSSパラメータ）

* **Start Freq (Hz):** スイープ信号の開始周波数を設定します（2.0〜20000 Hz）。
* **End Freq (Hz):** スイープ信号の終了周波数を設定します（20〜24000 Hz）。
* **Sweep Time (s):** 1回のスイープにかける時間を設定します（0.5〜30.0 s）。
* **TSA Averages:** 時間同期平均（Time Synchronized Averaging）の回数を設定します（1〜20回）。平均回数を増やすことで、環境ノイズの影響を効果的に低減できます。

### Hammerstein Modeling（ハンマースタインモデリング）

* **Max Amp (dBFS):** スイープ信号の最大振幅（ピーク値）を設定します（-60.0〜0.0 dBFS）。
* **Amp Scans (P=5):** PHM（Parallel Hammerstein Model）の分離処理に使用する振幅スキャンのステップ数を設定します（5〜10回、通常は5回）。
* **Display Smoothing:** グラフ描画時の平滑化フィルターの強度を設定します（"None", "Light", "Medium", "Heavy"）。Savitzky-Golay フィルターを適用して測定ノイズを滑らかにします。

### Routing & Calibration（ルーティング＆キャリブレーション）

* **Output Ch:** スイープ信号を出力するチャンネルを設定します（"Left", "Right", "Stereo"）。
* **Input Mode:** 入力信号のキャプチャモードを設定します。
    * **Left (Ch1):** チャンネル1のみを使用します。
    * **Right (Ch2):** チャンネル2のみを使用します。
    * **XFER (Ref=L, Meas=R):** チャンネル1をリファレンス（基準）、チャンネル2を測定対象とする転送関数測定です。
    * **XFER (Ref=R, Meas=L):** チャンネル2をリファレンス、チャンネル1を測定対象とします。
* **Latency:** 測定されたループバック遅延時間をミリ秒（ms）で表示します。
* **Calibrate Delay ボタン:** 機器の物理的なループバック経路を用いて入出力のレイテンシを測定・校正します（Input Mode が `Left (Ch1)` または `Right (Ch2)` のときのみ有効です。XFERモードでは位相差が自動的にキャンセルされるため無効化されます）。

## 測定コントロール

* **Start Analysis ボタン:** クリックすると、設定されたパラメータで振幅スキャンおよびスイープ測定シーケンスを開始します。測定中はメインのオーディオエンジンストリームは一時的に占有されます。
* **Stop ボタン:** 測定シーケンスを途中で停止します。
* **プログレスバー:** 測定全体の進捗状況をパーセンテージで表示します。

## グラフとタブの見方

グラフエリアはタブで区切られており、以下の4種類の解析データを確認できます。

### 1. Bode Magnitude（ボード振幅特性）

分離された 1次〜5次 の高調波カーネルのゲイン周波数特性（dB vs Hz、対数軸表示）を表示します。
測定が完了すると、シミュレーション用周波数を設定するための灰色の垂直破線（`Sim Freq`）が表示されます。この破線を左右にドラッグすると、高調波シミュレータの入力周波数がリアルタイムに更新されます。

### 2. Bode Phase（ボード位相特性）

分離された 1次〜5次 の高調波カーネルの位相周波数特性（deg vs Hz、対数軸表示）を表示します。
こちらも `Bode Magnitude` と同期したシミュレーション用周波数ラインが表示されます。

### 3. Hammerstein Kernels（時間領域カーネル）

時間領域での 1次〜5次 の分離インパルス応答 $h_1(t) \sim h_5(t)$ を表示します。
インパルス応答のピーク周辺を詳細に観察できるよう、時間軸（X軸）は自動的に -5 ms から +35 ms の範囲にズームされます。

### 4. Harmonic Simulator（高調波シミュレータ）

実測した Hammerstein カーネルのゲインおよび位相データを使用して、任意の正弦波をシステムに入力したときの出力応答を数値およびスペクトルで予測します。
測定完了後に有効化されます。

* **入力パラメータ設定:**
    * **Input Frequency:** 入力する正弦波の基本周波数 $f_0$ を設定します（20.0〜20000.0 Hz）。スライダーまたは数値入力ボックスから変更可能です。また、Bode Magnitude/Phase上の `Sim Freq` カーソルのドラッグとも双方向に連動します。
    * **Input Amplitude:** 入力する正弦波の振幅を設定します（-60.0〜0.0 dBFS）。
    * **Include Audio Interface Phase:** チェックを入れると、オーディオインターフェース自体の測定系ループバック位相（Reference phase）をシミュレーション結果に反映して補正します。
* **予測結果テーブル:**
    * 歪み成分（Fundamental, 2nd Harmonic 〜 5th Harmonic）ごとに、予測される「周波数」「振幅（dBFS）」「位相（Fundamental基準の相対角度）」をリアルタイムに計算して表示します。
    * 各高調波の周波数がナイキスト周波数（サンプリングレートの半分）を超えた場合は、自動的に `N/A (Nyquist)` となり、予測対象から除外されます。
* **Output Prediction Spectrum（出力予測スペクトル）:**
    * シミュレーションされた各高調波成分のレベルを周波数スペクトル上にカラーの縦棒（およびドット）で表示し、視覚的な歪みプロファイルを確認できます。
