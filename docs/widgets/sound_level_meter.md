# Sound Level Meter (騒音計・SPLメーター)

![Sound Level Meter](../assets/widgets/sound_level_meter.png)

## 概要

Sound Level Meter（騒音計）は、環境騒音やオーディオ機器の音圧レベル（SPL）を測定します。A/C/Zの周波数重み付けと時間応答を選択できます。これらの機能だけで、測定システム全体のIEC 61672適合を保証するものではありません。

## 基本操作

### 測定の開始

* **Startボタン**: 測定を開始します。
* **Resetボタン**: すべての測定値、統計、ヒストグラム、フィルタの履歴を消去します。取得中は新しい区間を開始し、設定した測定時間も最初から数え直します。停止中は結果を消去し、取得は開始しません。
* チャンネル、周波数・時間重み付け、帯域、測定時間を変更すると、新しい取得区間を開始します。異なる条件の結果は混在させません。
* 状態行に取得済みの音声時間とLN統計の対象時間を表示します。完了した結果は、リセットまたは次の取得まで各タブで確認できます。

### メインディスプレイ

画面上部に大きく表示される数値です。

* **Instantaneous (Lp)**: 現在の瞬間的な音圧レベルです。
* **Equivalent (Leq)**: 等価騒音レベル。測定開始から現在までの「平均的な」エネルギーレベルを示します。変動する騒音の評価によく使われます。

### 詳細タブ

* **Histogram (LN)**: 音圧レベルの分布を棒グラフで表示します。
* **Statistics**: 統計的な指標を表示します。
    * **L10 / L90**: サンプリングした時間のうち、それぞれ10%・90%で超えていたレベルです。
    * **L50**: 中央値（50%の時間はこのレベルを超えていた）。
    * **L5 / L95**: それぞれ、騒音のピークに近いレベルと、暗騒音（バックグラウンドノイズ）に近いレベルを表します。
* **Details**: Lmax（最大値）、Lmin（最小値）、Lpeak（波形のピーク値）、LE（単発騒音暴露レベル）などの詳細データを表示します。

## 設定

### Channel (チャンネル)

測定に使用する入力チャンネル（LまたはR）を選択します。

### Freq Weight (周波数重み付け)

人間の聴覚特性に合わせるためのフィルタを選択します。

* **A特性 (A-Weighting)**: 人間の耳の感度に近い特性。一般的な騒音測定（環境音、騒音規制など）で最もよく使われます。
* **C特性 (C-Weighting)**: A特性よりも低音域をカットしない特性。大きな音や機械音の測定に使われます。
* **Z特性 (Z-Weighting)**: 補正なし（フラット）の特性。物理的な音圧そのものを測る場合に使われます。

### Time Weight (時間重み付け)

レベル変動への追従速度を選択します。

* **FAST (125ms)**: 一般的な測定用。変動する音を捉えます。
* **SLOW (1s)**: ゆったりとした変動の平均的なレベルを見るのに適しています。
* **IMPULSE**: 衝撃音（打撃音など）を測定するための特殊なモードです（立ち上がりが非常に速く、減衰が遅い）。
* **10ms**: 非常に高速な変動を捉えるための独自設定です。

### Bandwidth (帯域制限)

測定する周波数帯域を制限します。

* **20Hz - 20kHz (Wide)**: 可聴帯域全体。
* **20Hz - 12.5kHz** / **8kHz**: 特定の騒音計規格に合わせる場合などに使用します。

### Duration (測定時間)

取得する音声の長さを設定します（例: 1分間、10分間）。コールバックの途中でも指定時間のサンプル境界で終了します。PCの時計ではなく、受け取った音声サンプル数で時間を数えるため、中断時間を無音として加算しません。「Continuous」では手動で停止するまで取得します。サンプルレートが変わると区間とフィルタ履歴を消去し、新しいレートで取得します。

### LN統計の対象区間

Lpは音声サンプル数を基準に100 msごとに収集します（44.1 kHzでは4,410サンプル、48 kHzでは4,800サンプル）。大きなコールバック内の複数の境界もすべて収集します。この間隔は固定で、設定項目はありません。

LN値とヒストグラムは直近の最大10時間が対象です。上限に達すると古いデータから置き換わります。Leq、LE、Lmax、Lmin、Lpeakは取得区間全体が対象です。最初の100 ms境界に達するまでLN値は表示されません。Laveは保持しているLpサンプルのエネルギー平均であり、周波数重み付け後の全入力サンプルを積分するLeqとは異なります。

IMPULSEは二乗した各サンプルに非対称な指数応答を適用し、立ち上がり35 ms、減衰1.5 sで追従します。状態を次のコールバックへ引き継ぎます。従来の8サンプル単位の最大値による近似を置き換えるため、旧バージョンとはIMPULSEの値が変わる場合があります。規格認証を示すものではありません。

## キャリブレーションについて

正確な「dB SPL」値を表示するためには、事前に **Settingsウィジェット** の「Calibration」タブで「SPL Offset」の校正を行ってください。校正されていない場合、警告メッセージが表示され、表示単位は自動的にデジタルフルスケール（dBFS）へとフォールバックします。

校正オフセットは、停止中も測定値・LN値・ヒストグラムの軸へ一貫して適用されます。オフセットの変更は同じデジタル測定値の換算を変える操作であり、取得区間はリセットしません。
