# Lock-in Spectrum Finder

## 概要

**Lock-in Spectrum Finder** は、ロックイン検出（マトリックス射影）の原理を用いて、極めて高い分解能で指定した周波数帯域のスペクトルを計算・表示するウィジェットです。
通常のFFTベースのスペクトラムアナライザでは分解能が不足するような特定の狭帯域や、低ノイズフロアでの微小信号の検出に特化しています。

## モード

用途に合わせて2つの分析モードから選択できます。

* **Basic (基本モード)**
    * 指定した開始周波数から終了周波数までの範囲を、対数(Log)またはリニア(Lin)の間隔で計算します。
    * 広帯域全体の高精度なスペクトルを確認したい場合に使用します。
* **Zoom (ズームモード)**
    * 特定の中心周波数の周囲（スパン）のみを極めて高い分解能で計算します。
    * デジタルダウンコンバージョン（DDC）とダウンサンプリングを内部で組み合わせており、特定のピーク周辺の詳細な観察に最適です。

## 操作・設定項目

### 共通設定

* **Start Analysis / Stop Analysis ボタン**
    * クリックして測定の開始・停止を切り替えます。
* **Mode (モード)**
    * `Basic` または `Zoom` を選択します。
* **Buffer Size (バッファサイズ)**
    * 一度に取得・処理するデータ長を指定します。
    * サイズを大きくすると周波数分解能が向上しますが、計算の更新頻度は下がります（Basicモードでは最大 512k、Zoomモードでは最大 8M）。
* **Input Ch (入力チャンネル)**
    * 分析対象のチャンネル (`Left (Ch 1)` または `Right (Ch 2)`) を選択します。
* **Basis Points (計算ポイント数)**
    * スペクトルを計算するポイント（ビン）の数を設定します（16 ～ 1024）。
    * 数が多いほど細かく表示されますが、計算の負荷が増加します。

### Basic モード専用設定

* **Start Freq (開始周波数)**
    * 分析の開始周波数 (Hz) を指定します。
* **Stop Freq (終了周波数)**
    * 分析の終了周波数 (Hz) を指定します。
* **Spacing (間隔)**
    * `Log` (対数) または `Lin` (リニア) からポイントの配置間隔を選びます。グラフのX軸表示もこれに連動してLog/Linが切り替わります。

### Zoom モード専用設定

* **Zoom Center (ズーム中心周波数)**
    * ズーム分析の中心となる周波数 (Hz) を指定します。
* **Zoom Span (±ズームスパン)**
    * 中心周波数からの分析幅（±Hz）を指定します。（例：Center=1000Hz, Span=10Hz の場合、990Hz～1010Hzの範囲を分析します）

## グラフの読み方

* **横軸 (Frequency)**: 周波数 (Hz) を表します。
* **縦軸 (Amplitude)**: 信号の振幅レベル (dBFS) を表します。キャリブレーションが行われている場合は、入力オフセットが加味されます。
* 計算中はグラフ上に現在の計算進捗を示す赤い縦線（スイープライン）が表示され、逐次スペクトルが更新されていきます。
