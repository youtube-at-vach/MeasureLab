# Remote Audio I/O（リモート音声I/O）

## 概要

Remote Audio I/O は、同一LAN上の別のMeasureLab PCに接続されたオーディオデバイスを、測定用の入力またはデュープレックス入出力として使用する機能です。OSの仮想オーディオドライバーではなく、MeasureLabのAudioEngine内部で使用するリモートI/Oです。

測定データのサンプル位置を優先するため、欠損した音声は補間しません。欠損区間は同じ長さのゼロで置き換え、データ欠損として画面に表示します。

## 共通機能

このウィジェットは Detachable Wrapper の共通機能をサポートしています。詳細は [Detachable Wrapper](detachable_wrapper.md) のドキュメントを参照してください。

## リモートPCでの準備

1. Settingsで、リモート測定に使用する物理入力・出力デバイス、サンプルレート、バッファサイズ、チャンネルを設定します。
2. Remote Audio I/Oを開きます。
3. **Provide Local I/O**タブを選択します。
4. 待受アドレスと制御ポートを指定します。すべてのIPv4 LANインターフェースで待ち受ける場合は`0.0.0.0`を使用します。
   Windowsでは、共有を開始する前にWindows Defender ファイアウォールの受信規則で、選択したポートへのTCPおよびUDP接続を許可してください（既定: `40100`）。
5. リモート出力も使用する場合に限り、**Allow remote playback**を有効にします。
6. **Start Provider**を押します。

Providerの動作中は、測定データへの意図しない混入を防ぐため、同じPC上の他の測定モジュールはAudioEngineを使用できません。

## メインPCからの接続

1. Remote Audio I/Oの**Use Remote I/O**タブを開きます。
2. リモートPCのIPv4アドレスまたはホスト名と制御ポートを入力します。
3. 固定ネットワークバッファを設定します。通常は100 msから開始してください。
4. リモート出力も必要な場合は、**Request remote output (duplex)**を有効にします。
5. **Connect**を押します。
6. 接続後、通常の測定モジュールを開始します。

Providerがリモート出力を許可していない場合、クライアントがデュープレックスを要求しても入力専用になります。
接続中に**Allow remote playback**を無効にすると出力は直ちにミュートされます。入力専用として接続済みのセッションで後から有効にした場合は、安全のため次回接続から適用されます。

校正プロファイルはネットワーク経由で自動転送されません。物理単位を使用する測定では、メインPC側でリモートPCのオーディオインターフェース、ゲイン設定、測定系に対応する校正プロファイルを選択してください。

## データ完全性表示

Connection Integrityには次の情報が表示されます。

- 受信・送信パケット数
- 欠損フレーム数
- 遅着、重複、破損パケット数
- 現在のバッファ量
- 欠損した方向、絶対サンプル位置、フレーム数、原因

`DATA LOSS DETECTED`が表示された測定区間は、完全な測定データとして扱わないでください。表示を確認してからバッファを増やすか、有線LANへ切り替えて再測定してください。

## 通信と安全性

- 制御にはTCP、非圧縮float32 PCMにはUDPを使用し、Providerは両方で同じポート番号を待ち受けます。
- 制御チャネルはハートビートを使用し、応答不能になったクライアントがProviderを占有し続けることを防ぎます。
- UDPパケットにはセッションID、シーケンス番号、絶対サンプル位置、CRCが含まれます。
- リモートPCのオーディオクロックがセッションのサンプル時間基準になります。
- 再生位置には固定の先行バッファを使用し、ストリーミング中に遅延量を自動変更しません。
- 通信は暗号化・認証されません。信頼できるLANでのみProviderを有効にしてください。
- 初期実装はIPv4、mono/stereo、1クライアントに対応します。
- 安定した測定には有線LANを推奨します。

接続や切断の前には、実行中の測定モジュールを停止してください。ネットワーク切断時にローカルのマイクや出力へ自動的に切り替わることはありません。
