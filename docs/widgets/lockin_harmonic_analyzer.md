# Lock-in Harmonic Analyzer

![Lock-in Harmonic Analyzer](../assets/widgets/lockin_harmonic_analyzer.png)

**Lock-in Harmonic Analyzer (ロックイン高調波解析)** は、ロックインアンプの原理を利用して極めて低ノイズかつ高精度に全高調波歪（THD）およびTHD+Nを測定するモジュールです。

従来のFFTベースの歪み測定では窓関数を使用するため、微小な成分がノイズに埋もれがちでした。このウィジットでは、基本波および最大200次までの高調波に対して**多重並列のIQ検波（ロックイン測定）**を同時に行うことで、目的の周波数成分のみをピンポイントで抽出します。これにより、FFTの限界を超える超低歪み領域（-160dBc以下など）の測定が可能になります。

## ☕ コーヒーブレイク：極微小な歪みを測定するアプローチ

オーディオ機器を通った音には、元の音にはなかった「倍音（高調波）」という不純物が混ざり、これが「歪み」となります。
従来の歪み計（FFT）では、超高性能な機器の微小な歪みはノイズフロアに埋もれてしまい、測定の限界に達します。
Lock-in Harmonic Analyzerは、FFTのように全体を見るのではなく、「特定の倍音周波数のみ」を狙って多重にロックイン検波を行います。これにより、ノイズフロアに埋もれた極限まで小さな歪み成分だけを、ノイズの影響を排除して正確に抽出・数値化することができます。

## 測定原理の特徴

本ウィジットの最大の特長は、**多重並列のロックイン検波**（数学的には行列表射として実装）による解析アプローチです。

1. **正確な周期の切り出し**: 入力されたリファレンス信号（参照信号）のゼロクロス点（立ち上がり）を高精度に検出し、正確に整数サイクル分のデータを切り出します。
2. **参照信号の生成**: 検出された基本周波数 $\omega$ に基づき、DC（直流）成分と、基本波および設定された任意の高調波成分（最大$n\omega$）に同期したサイン波(I)とコサイン波(Q)の参照信号を内部で生成します。
3. **並列IQ検波（ロックイン）**: 測定対象の信号ベクトル $Y$ に対して、生成したすべての参照信号を同時に掛け合わせて積分する（行列表射を用いた連立方程式を解く）ことで、各高調波の振幅と位相成分を一括して直読します。
   $$ \text{Coefficients} = (B^T B)^{-1} B^T Y $$
4. **高調波と残留ノイズの分離**: 得られた各高調波の成分を元の信号から差し引くことで、純粋な残留ノイズ（Residual）成分をきれいに分離します。

この「見たい周波数にだけ極細のフィルターをかける」ロックインの特性により、FFT測定で必須となる窓関数による周波数の滲み（リーケージ）を根本的に回避し、強大なノイズの中から極小の歪み成分だけを正確に拾い上げることができます。

## 操作方法

左側のコントロールパネルはタブ構成になっており、用途に合わせて切り替えて使用します。

### 1. Settings (設定) タブ

基本的な測定パラメータを設定します。

* **Output Ch (出力チャンネル)**: テスト信号を出力するチャンネルを選択します（Left / Right / Stereo）。
* **Buffer (Integ. Time) (バッファサイズ / 積分時間)**: 解析に使用するデータの取り込み長を選択します。バッファサイズが大きいほど積分時間が長くなり、ランダムノイズが平均化され、測定のS/N比が向上します。超低歪み測定には大きなバッファ（例：262,144 や 524,288）を推奨します。
* **Frequency (周波数)**: 出力するテスト正弦波の基本周波数を指定します（Hz）。
* **Amplitude (振幅)**: 出力するテスト正弦波のレベルを指定します（dBFS）。クリップを避けるため、適切なレベル（例：-6.0 dBFS ～ -1.0 dBFS）を設定してください。
* **Harmonics (高調波次数)**: 解析対象とする最大高調波次数を指定します（最大200）。なお、サンプリングレートおよび基本周波数に応じて、ナイキスト周波数を超えない範囲で動的に制限されます。
* **Start Analysis / Stop Analysis**: 測定の開始と停止を切り替えます。開始すると、バッファが満たされるまで「Buffering...」と表示され、その後解析結果が更新されます。

### 2. Compensation (高調波補正) タブ [NEW]

測定系（オーディオインターフェースの出力段など）自体が持つ歪みをキャンセルするための機能です。

* **Enable Compensation**: このチェックボックスをオンにすると、現在保持されている補正データ（振幅と位相）に基づいて、出力信号に逆相の歪み成分を重畳し、系全体の歪みを低減します。
* **Comp. Max Harmonic**: 補正の対象とする最大高調波次数を指定します。なお、この上限は解析対象の最大高調波次数または50を超えることはできません。
* **Auto-Calibrate**: 現在の測定結果を「系の歪み」としてキャプチャし、補正テーブルを自動的に更新します。
    * **手順**: ループバック状態で本ボタンを押すと、THDが最小化されるまで自動的にキャリブレーションが行われます。これにより、外部機器の測定用に極めてクリーンなテスト信号を生成できます。
* **Clear**: 現在の補正テーブルをリセットし、純粋な正弦波出力に戻します。

### 3. Compensation Data (補正データ) タブ [NEW]

* **Save as Reference**: 現在の補正データをリファレンスとして保存します。
* **Clear Reference**: 保存されたリファレンスデータをクリアします。
* **Show Difference**: 補正データとリファレンスデータの差分（ΔAmp, ΔPhase）を表示します。

### 4. Routing (ルーティング) タブ

* **Signal Input (測定信号入力)**: 高調波歪みを測定したい対象の信号が入力されているチャンネルを選択します。
* **Reference Input (参照信号入力)**: ロックイン解析の基準となる信号が入力されているチャンネルを選択します。これはテスト信号源そのものであり、測定対象系（DUT）を通る前の信号、あるいは波形歪みの少ない安定した信号である必要があります。信号の基本周波数と位相はこのリファレンスから高精度に抽出されます。

## 解析結果の表示

### Overview (結果概要)

* **THD (全高調波歪)**: 測定された全高調波歪みの値を表示します（dB および %）。
* **THD+N (全高調波歪＋ノイズ)**: 測定された全高調波歪みと残留ノイズの合計値を表示します（dB および %）。
* **Fundamental (基本波振幅)**: 測定された基本波（第1高調波）の振幅レベル（dBFS）を表示します。

### 詳細解析タブ

画面右側のエリアでは、より詳細なデータをタブで切り替えて表示できます。

* **Harmonics Table (高調波データ表)**: 各次数の高調波について、絶対振幅(Amp dBFS)、基本波に対する相対レベル(Level dBc)、および位相(Phase deg)を数値で一覧表示します。
* **Harmonics Plot (高調波スペクトル棒グラフ)**: 各高調波の成分レベル（dBFS）を視覚的に確認できるバーグラフです。
* **Residual (残留ノイズ波形)**: 入力信号から、計算された基本波とすべての高調波成分を差し引いた「残留成分（ノイズ＋その他の非高調波成分）」の波形（間引き表示）です。
* **Compensation Data (補正データ)**: 現在適用されている補正係数（各高調波の振幅と位相）の一覧表です。「Save as Reference」ボタンで基準状態を保存し、「Show Difference」をチェックすることで、時間経過や温度変化による歪み特性の微細な変動（ΔAmp, ΔPhase）を監視できます。
