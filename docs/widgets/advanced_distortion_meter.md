# Advanced Distortion Meter (高度な歪み率測定)

## 概要
通常の「THD（全高調波歪）」測定では分からない、より複雑で実践的な歪み（ひずみ）を分析するためのツールです。
「THDは良いのに聴感上の音が濁る」といった現象の原因を探るのに適しています。

## 測定モード

*   **MIM (Multitone Intermodulation Distortion)**: 
    多くの音(31音など)を同時に鳴らし、それらが混ざり合うことで発生する「濁り」を測定します。音楽信号に近い複雑な負荷をかけた時の性能評価に最適です。
*   **SPDR (Spurious Free Dynamic Range)**: 
    1kHzの信号を基準とし、それ以外の余計なノイズや「スプリアス（偽信号）」がどれだけ低い位置にあるかを測ります。
*   **PIM (Passive Intermodulation)**: 
    2つの異なる音（1.8kHz, 2.1kHzなど）を鳴らし、その相互干渉によって発生する歪みを精密に分析します。

## 操作方法

1.  **Measurement Mode** から測定したい項目を選びます。
2.  **Start Measurement** ボタンを押すと測定信号（テストトーン）が出力されます。
3.  **Results** 欄にメインの数値（TD+NやSPDR値）が表示されます。

## 設定項目
*   **Amplitude**: 信号の大きさです。測定対象を壊さないよう、最初は低めの値から始めてください。
*   **Tone Count (MIM)**: マルチトーンの密度を設定します。
*   **Freq 1 / 2 (PIM)**: 干渉させる2つの周波数を指定します。

## 使用例
*   **アンプの動的な歪みチェック**: MIMモードを使用して、複雑な信号を再生した際も歪みが低く抑えられているかを確認します。
*   **電源や回路の不要輻射（ノイズ）探し**: SPDRモードで、本来存在しないはずの鋭いノイズピークがないか監視します。
