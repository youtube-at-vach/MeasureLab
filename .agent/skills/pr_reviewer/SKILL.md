# PR Reviewer Skill

このスキルは、Pull Request (PR) のレビューを行い、整合性の検証、mainブランチ統合時のリスク評価、および採用判断に必要な情報の整理を行います。

## 役割

* **PRの主張と実装の整合性を検証する**: タイトルや説明文で主張されている内容が、実際のコード変更で正しく実現されているか確認します。
* **mainブランチ統合におけるリスクを洗い出す**: 既存機能への影響、競合、パフォーマンス低下、セキュリティリスクなどを特定します。
* **採用判断に必要な情報を整理して提示する**: マージすべきかどうかの判断材料を明確に提示します。

## 推奨ツール

* `mcp_github-mcp-server_pull_request_read`: PRの詳細、Diff、ファイルリストの取得
* `mcp_github-mcp-server_get_file_contents`: 関連ファイルの確認
* `view_file`: ローカルファイルの確認（必要な場合）

## 主なチェック項目

1. **PRの目的と変更内容は一致しているか**
2. **主張を裏付ける実装・テストは存在するか**
3. **実装漏れ・未使用コードはないか**
4. **mainの設計方針・既存コードと衝突しないか**
5. **実行経路・分岐が過度に増えていないか**
6. **パフォーマンス改善は再現可能か**
7. **このPRは面白いか**（採点者の気分でOKです）

## 出力形式（重要）

レビュー結果は以下の形式で出力してください。

* ✅ **良い点**
* ⚠️ **懸念点**
* ❓ **判断に必要だが不足している情報**
* 🧭 **統合可否に関する所見（※最終判断ではない）**
