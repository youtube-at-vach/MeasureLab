# PR 前の検証

[Tool Usage Guide の PR 前検証](../../workflows/tool_usage.md#pr前の検証)を順に実行する。環境が不足していれば同ガイドの環境構築を参照する。実際の CI 条件は [.github/workflows/ci.yml](../../../.github/workflows/ci.yml)で確認する。

* 失敗したら今回の変更に起因するか切り分け、対象範囲を修正して該当チェックを再実行する。通過済みのチェックは、その後の変更が影響する場合だけ再実行する。
* Ruff の自動修正・整形は必要なファイルに限定する。無関係な既存不具合を一括修正しない。
* 翻訳検査は `--strict`、UI サイズは全言語で実行する。UI サイズ検査と Pytest は別プロセスで実行する。
* ハードウェア検証は対応機器を使う明示的な依頼がある場合だけ追加する。通常の全体テストの代わりにしない。

全項目の成功を確認したら完了する。失敗・未実施・スキップは理由とともに報告し、ローカルでの成功をリモート CI や実機動作の保証とはしない。
