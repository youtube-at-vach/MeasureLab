# 翻訳を整える

## 調査・修正

1. [Tool Usage Guide の翻訳検査](../../workflows/tool_usage.md#翻訳キー)を実行し、対象の `tr()` と画面上の文脈を確認する。調査だけの依頼なら結果を報告して終了する。
2. `src/assets/lang/en.json` を基準に、必要なキーと全言語の対応する翻訳を修正する。既存用語をそろえ、置換フィールド、書式指定、単位、改行、HTML を維持する。
3. 未使用・重複キーは利用箇所を確認して整理する。英語と同じ値でも妥当な単位・固有名などは、`scripts/translation_whitelist.json` の既存規則を確認する。追加する場合は必要最小限とし、未翻訳を隠すための除外はしない。

少数の修正は JSON を直接編集する。`scripts/update_translations.py` は不足キーの追加に加えて未使用キーも削除し、他言語には英語の仮訳を入れる。使う場合は削除対象を確認し、実行後に差分を読み、仮訳を各言語へ翻訳する。`check_trn_keys.py --fix` も全言語からキーを削除するため、調査目的では使わない。

## 検証・完了

厳格な翻訳検査と、[全言語 UI サイズ検証](../../workflows/tool_usage.md#uiサイズ検証)を実行する。終了コードだけでなく、重複キーなどの警告も確認する。チェックが通っても翻訳の意味や置換フィールドの整合性は差分で確認する。

[Agent Guide](../../../AGENTS.md)の終了時チェックを行い、修正した言語・内容、検証結果、残る問題を報告する。既存警告を残した場合は翻訳全体の修正完了とはしない。
