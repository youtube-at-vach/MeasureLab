更新日：2026-10-13。状態：4.5bの生成コアと固定容量制御、4.5cの通常GUI・内部入力接続・CPAL実出力を実装済み。4.5全体の受け入れ試験は未完了。[現在の方針](../CURRENT_DIRECTION.md) と [PLAN](PLAN.md#次のマイルストーン) に従い、正弦波の生成からMeasureLab内の観測までを通常ビルドで完成させる。以下の受け入れ目標は、実装済みコアの数値確認を除き、実測済みの性能・精度ではない。

## 信号・単位・変更の定義

* 内部サンプル、振幅、周波数、位相はf64。整数サンプル連番を別に持ち、位相を有限範囲へ折り返す発振器を使う。巨大な絶対連番をf64へ変換して毎回角度を作らない。
* 正弦波は`x[n] = A[n] × sin(θ[n] + φ[n])`、`θ[n+1] = wrap(θ[n] + 2π f[n] / Fs_out)`とする。`Fs_out`は出力デバイス／内部出力時計の公称値で、入力FsやUI時刻を使わない。
* 振幅は`A = 10^(dBFS / 20)`のpeak基準。0 dBFSは1 FS peak、正弦波のRMSは`A / √2`、P-Pは`2A`。既存Spectrumの正弦波振幅表示と照合し、RMS値へ同じdBFSラベルを無条件に流用しない。
* 初期UI範囲は周波数0.1 Hz以上・`0.45 × Fs_out`未満、振幅−120〜0 dBFS、位相−180〜180°とする。0°と360°は同じ位相。既定は1 kHz・−20 dBFS・0°・出力OFF。低レベルの有効分解能と物理帯域はPCM形式・機器に依存し、設定可能範囲を物理精度保証にしない。
* OFFは出力サンプルのゼロであり、振幅設定は保持する。NaN／無限大・範囲外は適用せず、理由と最後の適用値を表示する。Nyquist以上への丸め込みや別Fsへの暗黙の切り替えをしない。
* 周波数変更では蓄積位相をリセットせず、適用サンプルから増分を変更する。開始／停止・CHのON／OFF・振幅変更は10 msのraised-cosine遷移を初期仕様とする。遷移長は出力サンプル数で定義し、コールバック境界をまたいでも継続する。
* 位相設定は発振器に対するオフセットで、正は進み。ライブ変更は最短方向へ10 msのraised-cosine補間で移し、180°の同距離は正方向に固定する。遷移中は一時的な位相変調を伴うため`TRANSITION`と表示する。上限周波数付近では遷移中の位相増分もNyquist未満となるよう遷移時間を延ばし、実際の長さを条件に残す。
* 2chは同じ出力時計・開始サンプルから生成する。片CHのOFF中も位相は進め、再ONで他CHの位相をリセットしない。独立した周波数変更の履歴が異なると、同じ周波数へ戻しても相対位相は自動的には揃わない。補助操作`Align phases`で共通の位相基準へ滑らかに揃える。同一周波数・位相整列後の相対位相は設定差と一致させる。
* Vrms／Vppは、将来の出力デバイス・CH・Fs・ゲイン設定・負荷条件に対応する出力校正を前提にする。初期版はdBFSのみを操作可能にする。ノイズや多波形へ正弦波のRMS換算を適用しない。

## GUI構成

添付のTektronix AFG31000画面から「CHごとに同じ順序で並ぶ数値と操作」、Moku画面から「波形と周波数・振幅・位相の関係が近くで分かる配置」を採用する。機器の機能・性能は画像から推測せず、外観の参考として扱う。

### 基本レイアウト

既存の測定器選択へ`Generator`を追加し、単独表示と`Generator + Scope`／`Generator + Spectrum`／`Generator + Lock-in`を選べるようにする。主要な数値編集を左Settingsへ分散させず、Generatorの同じカード内で完結させる。

```text
Generator   [Internal loopback / Audio device]   [Stop all outputs]
Device [選択]   Fs [48 kHz]   PCM [f32]   OUTPUT: STOPPED
┌──────────────────────────────┬──────────────────────────────┐
│ GEN 1 → OUT [1]  Sine   [OFF] │ GEN 2 → OUT [2]  Sine   [OFF] │
│ FREQUENCY                    │ FREQUENCY                    │
│          1 000.000 Hz         │          1 000.000 Hz         │
│ AMPLITUDE          PHASE     │ AMPLITUDE          PHASE     │
│    −20.00 dBFS       0.00°   │    −20.00 dBFS      90.00°   │
│ [設定波形プレビュー・2周期]  │ [設定波形プレビュー・2周期]  │
│ ±0.1 FS peak / 2 ms          │ ±0.1 FS peak / 2 ms          │
└──────────────────────────────┴──────────────────────────────┘
[Align phases]   Pending / Applied / Transition   [Start output]
──── 同じワークスペース内のScope／Spectrum／Lock-in ────────────
```

上図は停止中の設定例。カードのON／OFFは出力対象の選択で、停止中にONにしても信号を出さない。`Start output`は選択したCHを共通サンプルから開始する。動作中は同じ位置の`Stop output`へ変わり、各カードの切り替えでそのCHだけをフェードする。`Stop all outputs`は出力先と状態にかかわらず常に同じ場所に置く。

* 出力先は初期版では内部ループバックか1台の音声デバイスのどちらか。同時に両方へ出さない。`GEN 1/2 → OUT n`を明示し、入力側の`CH n`と混同させない。内部は2ch、音声デバイスは対応する1〜16chの出力構成から最大2chを選び、1ch機器では2つ目を選択不能にする。同じ出力CHへの二重割当は拒否し、未選択CHにはゼロを出す。16ch同時生成は後続とする。
* 既存画面の濃紺背景（panel `#0f161d`、plot `#070e13`）、文字`#d9e4ea`、GEN 1の緑`#38f2ad`・GEN 2の青`#57a6ff`を使う。色だけに依存せず、番号・出力先・状態を文字で表示する。立体的なベゼルや常時アニメーションは追加しない。
* 周波数は28〜32 pt、振幅・位相は24〜28 ptを初期の検討値とする。等幅数字と明確な単位、揃えた小数点、既存と同じ余白・境界線を使う。範囲・精度に応じて桁を決め、表示桁数を発振精度の保証として扱わない。Scope等の既存数値領域は移動しない。
* 数値のクリックで直接入力し、Hz／kHz、dBFS、°を欄の近くに表示する。Enter／フォーカス確定で適用、Escで編集取消。矢印キーとドラッグの刻みを見える位置で選び、連続操作は最新要求へ集約する。入力途中の符号や小数点を出力へ流さない。
* 2ch横並びは十分な幅があるときだけ使い、狭幅ではカードを縦に並べる。さらに高さが足りなければCHタブ＋両CHの固定状態行へ切り替え、選択CHの3値と全出力停止をスクロールなしで操作できるようにする。既存のAutomatic／Side by side／Stacked配置と整合させる。
* プレビューは「設定波形」と明記し、同じ式・適用条件から作る2周期程度の静止波形とする。周期の時間、FS peak目盛、位相原点を示す。振幅で縦倍率を変えた場合は倍率を明示する。停止中でも見えるが、実測・DAC後のモニターとは扱わない。実波形はScopeで観測する。
* `STOPPED / STARTING / RUNNING / STOPPING / ERROR`、CHのOFF、設定の`PENDING / APPLIED / TRANSITION`を区別する。実行側の応答が来る前に`RUNNING`や`APPLIED`を表示しない。非表示化しても出力状態と全出力停止は上部に残す。

## 実行構造と状態管理

`generator.rs`と`generator/control.rs`、`app/generator_panel.rs`と`output.rs`の内部生成ワーカー・共通入力接続は実装済み。`output/device.rs`は出力専用の列挙・設定再確認・PCM変換とCPALコールバック、`output/runtime.rs`は非UIの管理・期限付き停止・失敗保持を実装する。内部とAudio deviceの同時出力は行わず、接続中もコールバックと管理が同じ優先Stopを共有する。内部経路は44.1／48／96／192 kHz・2chのf64に限定し、生成・測定・描画を独立させる。起動時はOFF、停止中の復元・Fs変更もOFFを維持する。入力Stop後は出力を継続し、出力Stop後は取得中の新しい無音サンプルを供給する。macOSのスケジューリング活動も入力と出力で別に保持する。

```text
egui Generatorパネル（app/generator_panel.rs）
  → 検証済み設定要求 → 出力管理（output.rs、UIとは別スレッド）
  → 容量固定の制御転送 → generator.rs（f64、egui／CPALに非依存）
                           ├ Audio device: CPAL出力callbackが状態を所有
                           │  → 形式変換 → DAC → DUT／ケーブル → 既存CPAL入力
                           └ Internal loopback: 専用生成ワーカーが状態を所有
                              → 連番付き固定容量転送 → 共通測定ワーカー
共通測定 → Scope／Spectrum／Lock-in等 → UI／条件付き結果保存
出力実行側 → 適用世代・サンプル境界・状態／失敗 → UI／出力管理
```

### 実装済みコアと接続時の契約

* `generator::Engine`は2信号のf64サンプルを生成し、1〜16の出力CHへ最大2信号を割り当てる。未割当CHはゼロ。設定の全検証が成功するまで適用値・ランプを変更せず、動作中のCH割当変更を拒否する。起動・デコード・設定適用だけでは出力しない。
* 振幅と位相は適用境界の現在値から補間する。遷移区間は`[applied_sample, transition_end)`で、終端サンプルは目標値。周波数だけの変更ではcarrierをリセットしない。位相遷移中の周波数変更は現在の位相から残りの補間を再構成し、必要なら終端を延長する。Stopは現在の位相オフセットを固定し、振幅をゼロへフェードする。
* `Start`は共通carrier原点と新しい出力世代を作り、整数連番を巻き戻さない。出力管理は再構成時に`Engine::with_clock`へ前の世代・入力時計の次連番を引き継ぐ。入出力が別時計の実デバイスでは、入力連番を出力時計として流用しない。`STOPPED`のStop応答は最終ゼロフレームを生成してから返し、`stopped_at`はそのフレームを含む排他的終端とする。
* `generator::control`は要求・応答を各4件のSPSCで転送する。出力管理が`Controller::flush`を継続して呼び、飽和時の最新スナップショットを再送する。未送信のStart／Alignを後続の編集で失わない。実行側はブロック先頭のフレーム境界で最大4要求を処理し、`begin_block → next_frame → end_block`を使う。
* Stopは独立したatomic経路で、未送信要求を取消し、Stop以前のキュー済みStart／編集を適用しない。停止フェード中のStart／編集は拒否し、フェード終了後の明示Startを必要とする。設定のenqueue成功を適用応答とせず、`Report`の実行状態・適用版・サンプル境界を使う。
* `Report`は最新状態であり、全設定履歴ではない。合流した要求・Stopで破棄したキュー済み要求・応答の飽和を計数する。結果保存へ出力条件を接続する際は別途履歴を保持し、対応条件が追跡できない区間を定常結果として比較しない。
* 波形生成・設定適用・制御受信は固定サイズの値だけを扱い、ロック・待機・動的確保・ファイルI/Oをしない。初期化とSPSC／Arcの破棄は管理側で行う。非有限・過大出力と連番オーバーフローは固定サイズの失敗状態へ移し、再Startで解除しない。PCM無音化・ストリーム解放・通知タイムアウトは出力管理が担う。

数値確認は`src/generator/tests.rs`に保持する。44.1／48／96／192 kHz、0.1／750／997.1 Hz／`0.45 × Fs − 0.1 Hz`、0／−20／−120 dBFS、0／±90／180°の192条件を各100万サンプルまで独立した解析式と照合し、誤差1e-9 FS以下を確認する。振幅・位相遷移、半周の正方向選択、Nyquist制限による遷移延長、同じ適用境界での可変ブロックの完全一致、2^53超の連番、急速編集・Stop・再開始・異常値を回帰対象にする。

48 kHz・750 Hz・0.125／0.0625 FS peak・+30°の生成サンプルを既存Scope統計、8k Spectrum、Lock-in演算へ直接渡し、振幅誤差1e-8 FS、位相誤差1e-6°、REF周波数誤差1e-7 Hzの目標を確認する。この直接照合と独立ワーカー・通常GUIの内部統合確認は分け、PCM・外部I/Oの確認には流用しない。設定／結果は版2を追加し、版1の読み込みを維持する。設定には内部出力Fs・2信号の設定・入力としての選択を保存し、Start命令は保存しない。結果の`generator_output`は実際に受信した整数区間・出力世代・設定版・適用サンプル・carrier位相・遷移終端を最大128区間保持する。欠落・履歴から退役した区間は対応不明とし、最新UI値を後付けしない。Scope RMS・PSD帯域電力・Lock-inの数値差は両方の寄与区間が定常で、設定と同一周波数の相対carrier位相が一致するときだけ表示する。

### リアルタイム境界

* 正弦波は出力コールバック内で、事前確保した状態を用いて必要なフレーム数だけ生成する。定数時間のCHごとのf64演算とPCM変換に限定し、測定ワーカーの負荷やUIの停止を待たない。FFT、波形ファイル読み込み、将来のバッファ波形準備は非リアルタイム側へ置く。
* 設定・CH識別・ルーティングは上限16chを扱える型とし、初期版の有効な発振器を2つに制限する。未使用CHの波形演算は行わない。波形の種類、遷移用包絡、出力先の責務を分け、スイープ等のための汎用処理グラフは先行実装しない。
* コールバック内で待機・ロック・動的確保／解放・ログ・デバイス列挙をしない。エラー通知は固定サイズの状態として渡し、文字列化・ストリーム破棄・再接続処理は管理側で行う。将来の可変サイズデータも解放をコールバックへ持ち込まない。
* 設定はCH群を含む一つの不変スナップショットとして転送し、周波数・振幅・位相を混在した版で読まない。適用はフレーム境界、処理する制御数に上限を設ける。急速な編集では最新要求を保持し、Stopは通常の編集キューとは独立した優先経路を持つ。
* 出力実行側は`output_generation / revision / applied_sample / transition_end`を返す。UI要求時刻を適用時刻にしない。表示通知を省略しても出力を止めず、設定履歴の欠落は追跡不能として残す。
* f32／整数PCMへの変換、整数の非対称な端点、無音値を形式ごとに定義する。能力外の形式は開始前に拒否する。非有限値や予期しない範囲超過は検出・記録し、無音化して失敗状態へ移す。通常の量子化と異常クリップを区別する。

### 内部ループバック・時計・測定条件

* Software Loopbackへ新Generatorの実サンプルを受け取るモードを追加し、既存の既知DUTモード・旧保存条件は維持する。独立に再計算した同設定の正弦波を観測用に使わず、実際の生成フレームを共通入力へ渡す。リアルタイム編集に対応しない既知DUTの解析的遅延式は、そのまま新経路へ使わない。
* 内部出力と入力は同じ整数サンプル時計を共有する。出力を進める責務は測定・描画から分離し、測定側の停止や転送飽和で待たない。欠落区間と生成の進行を記録し、受信できなかった試料を取得済みとして補完しない。
* 内部入力が取得中なら出力OFF後も時計を進め、新しく生成した無音フレームを渡す。出力停止による無音と入力Stopによる保持を区別する。再Startは新しい出力世代の位相原点を定め、入力の連番を巻き戻さない。
* 実デバイス出力時は既存の実入力を観測する。出力先、入力先、公称Fs、PCM形式、CH割当、出力世代、入力世代を別に保持する。同じ公称Fsでも入出力時計・時刻の一致を仮定しない。DAC遅延や別デバイス間の自動同期補正は今回の対象外。
* 同一機器の入出力が公称Fsの設定を共有する場合も検出する。取得中の入力Fsを出力開始で暗黙に変更せず、両ストリームが成立する設定を確認する。不一致は理由を表示し、Fsを変えて再開するときは入力・出力とも新しい世代にする。
* Lock-inは従来どおり同時取得した入力REFを使用する。生成器の内部位相を物理REFへ置き換えない。同一周波数の2ch、または出力を分岐したREF／応答で確認し、異周波数・微小REFでは既存の無効／整定条件を維持する。
* 内部経路は設定遷移の正確な入力区間を付与し、窓をまたぐSpectrum平均・Lock-inの整定をリセットする。Scopeは遷移も実サンプルとして表示する。外部経路では出力適用サンプルとADC入力の対応は未確定と明記し、出力変更時に平均を無効化して、安定した入力REFと新しい完全窓から再評価する。保存結果へUIの最新値を後付けしない。
* 設定保存には波形・周波数・peak振幅・位相・出力先・Fs・CH割当・遷移条件を含める。結果には寄与区間の出力条件と対応の確実性を含め、外部経路の遷移をまたぐ／対応不明の結果を単一の定常条件として比較しない。設定／結果の版2を使用し、版1を既定OFFとして読み込む。実出力先・PCM・外部の対応確実性のスキーマはCPAL接続時に追加する。

### 開始・停止・切断

* 起動・設定復元・再接続後は出力OFF。設定復元は入力・出力の両方が停止した状態で行う。出力先／デバイス／Fs／CH割当を変えるときは停止完了後に再構成し、再出力には明示的なStartを必要とする。デバイス不在で既定のスピーカーへ代替しない。
* `Start input`と`Start output`は別操作。入力Stop／Singleの完了は測定結果を保持し、出力は継続するため、上部の出力状態を常に残す。アプリ終了と出力エラーでは出力を停止する。
* 通常Stopはフェード終了の応答後に音声出力ストリームを解放し、その間は`STOPPING`とする。内部入力用の無音フレーム供給は取得中だけ継続する。切断やコールバック停止などで応答が得られない場合は管理側の有期限処理で解放し、失敗として記録する。OSへ提出済みのバッファによる停止遅延は別に測定する。

### 実デバイス接続の現在の境界

出力は安定IDと選択した公称Fs・CH数・PCMの一致を開始時に再確認し、既定デバイス・別形式へ暗黙に切り替えない。コールバックはf64コアからPCMへの変換だけを行い、未割当CHを無音にする。f32は通常の丸め、整数はsignedの`2^(bits-1)`基準でゼロ方向へ切り捨て、+1 FSを正の最大値へ飽和させる。unsignedはその整数値へmidpointを加える。24-bitも正の最大値を明示的に制限する。

ストリーム通知は接続直後も失敗として保持する。通知時は以後のコールバックを無音にし、管理側でストリームを解放する。コールバックが2秒進まない場合、またはStopから500 ms以内に終端ゼロの応答がない場合はERRORで解放する。実行側が停止を通知した有限終端だけを成功扱いし、DACに到達した実時刻とは扱わない。再開には停止中の明示Resetが必要で、設定復元だけで開始しない。

外部入力と出力は別の整数時計で、同じ公称Fsや機器名だけではサンプル位置を対応付けない。同期REFは既存Lock-inの入力2chから取得する。外部出力設定は版2の設定JSONに保持するが、外部入力結果へ内部接続用の出力区間を付けない。出力遷移と入力窓の対応、外部結果の出力履歴・失敗条件の保存は4.5dに残る。条件付き確認は [実出力の検証](validation/GENERATOR_DEVICE_2026-10.md) を参照する。
