# MeasureLab Rust 開発計画

[現在の方針](../CURRENT_DIRECTION.md) に従う。Rust版は`main`で開発する。この文書は実装の範囲と次の完了条件を保持し、操作は [README](README.md)、テストの入口と実機確認の範囲は [VALIDATION](VALIDATION.md)、配布は [公開準備](RELEASE_PREPARATION.md) に分ける。

## 現在の到達点

| 対象 | 実装済みの範囲 |
| --- | --- |
| 入力・実行分離 | CPAL、1〜16ch同期フレーム、f64履歴、固定容量転送。取得・測定・各解析・描画・ファイルI/Oを分離 |
| Scope | 任意4ch、独立した表示・縦軸と下部CHバー、全CHトリガー、Auto／Normal／Single、Autoset、生サンプル統計・カーソル |
| Spectrum | 共通FFT・軸の最大4ch重ね表示、独立ON/OFF・下部CHバー、Auto／Manualレベル、1,024〜524,288点、振幅／PSD・帯域電力／ESD・窓エネルギー、f64数値、平均・保持、Live／Continuous／Latest |
| Spectrogram／XY | 独立STFT、欠落表示、同期XY、任意CH割当 |
| 校正・結果再利用 | CH校正、版付き設定、停止中復元、条件付きJSON／CSV・参照比較。Scope／SpectrumのPNG |
| Software Loopback／Lock-in | 既知DUT、同期入力REFによる基本波f64 Lock-in、専用ワーカー・数値GUI |
| Generator | 2信号の正弦波、ライブ編集、内部接続／CPAL実出力、独立Stop、出力条件の保存、切断時のERROR・OFF復元 |
| 同期2ch比較 | 専用f64ワーカー、自己／クロスPSD、H1、コヒーレンス、位相／遅延、GUI、条件付きJSON／CSV・保存復元 |

段階1〜3は実装済み。段階4はmacOS・利用可能なBlackHole／UAC-232・未校正FS／公称Fsの限定条件で受け入れ済み。Generatorと同期比較は実装済みだが、下記の統合評価を残す。mainへの統合は実機精度・配布の完了判定ではない。

数値定義・容量・互換性・許容差の正本は実装とテストに置く。完了した工程、テスト件数、過去のfmt／ビルド成功はこの計画へ追記しない。

## 次のマイルストーン

番号は版番号・期限ではなく、既存の段階4.5・5・6の識別を維持する。

### GUI再構成：単独表示を基本にした計器選択（実装・自動統合確認済み、手動受け入れ待ち）

[GUI再設計計画](GUI_REDESIGN.md) の表示モデル、7計器の単独表示、構成を保持するコンソール、選択中の詳細、共通入出力画面と設定版1〜4から版5への移行を実装した。取得・解析・生成と表示を分離し、Generator出力状態・停止を共通バーに置く。操作は [README](README.md) を正本とする。

* 狭幅のタブ退避は希望配置・比率を保持する。計器の追加・除去、単独との往復、構成置換の取消、表示状態の保存復元を扱う。
* G4の操作回帰は実際の共通枠・メニュー・詳細欄へのeguiイベントで行う。内部と指定した外部経路の保持・保存・別プロセス復元・再測定を同じrunnerで実行する。区画内の追加詳細はスクロールで保持し、前面画面の操作で背後の選択を変えない。
* 内部経路、BlackHole 2ch／16ch、UAC-232の関連QAと画像確認を終えた。物理経路は利用した機器・Fs・接続条件に限る。QA撮影はウィンドウを前面に保ち、Metalの遮蔽によるフレーム省略を記録する。
* G4の最終受け入れには通常ビルドの手動操作と実モニター間のDPI切り替えを残す。未実施と過去の旧GUI確認を現在の受け入れへ代用しない。
* 段階4.5／5の数値・機器評価を新構成で進める。新しい測定機能は基本操作の受け入れ後に扱う。

### Spectrum GUI：4ch重ね表示

単一グラフ、Scopeと同色の下部CHバー、独立した選択・表示ON/OFF、右側のFFT／Frequency・Scale／Measurement／Averaging、ピークマーカーを実装した。振幅／PSD／過渡信号（ESD）切り替えはFFTグループの先頭に置き、A／B周波数カーソルとΔf・ΔLを表示する。ESDは既存FFT・描画・結果保存を共用し、窓エネルギー補正を行わない独立した正規化と全帯域エネルギー読み出しを持つ。矩形窓・平均OFF・DC除去OFFを選択時の初期条件とする。非表示CHのFFTを停止する。4画面分割は対象外、ESDとシングルショット・トリガーの連携は後続とする。

自動確認の正本は`measurement.rs`の4ch既知正弦波・独立ON/OFF・設定／世代変更、`settings.rs`の版6往復・旧版移行、`app/gui_qa.rs`の実ウィジェット操作。物理4chの数値照合と通常ビルドの手動操作は受け入れを残す。

### Spectrogram MVP改善（S1〜S3を実装、履歴操作の統合受け入れ待ち）

[Spectrogram MVP改善計画](SPECTROGRAM_MVP_PLAN.md) に従い、①カラースケール、②ズーム・表示範囲、③測定を続けたままのHold／履歴閲覧を先に完成させ、④Spectrumとの時刻A／B連動、⑤FFT Overlap調整へ進む。左の計器選択・中央のプロット・右の設定を維持し、既存のSTFT・Spectrum・Pair配置を再利用する。Blue／Heat／Grayscale、Min／Max／Autoとカラーバー、周波数ズーム・横パン・ダブルクリックリセット、5／10／30／60秒の表示幅を実装した。表示操作で解析条件・世代を変更しない。

数値履歴はf64線形スペクトルと入力／解析世代・実サンプル区間を保持する120秒・96 MiBの有界リングを使い、UI更新から結果回収を分離した。表示準備も独立ワーカーへ移し、要求・応答各1件、最大512行・1,024列のピーク／欠落を残すラスタで全保持範囲を表示する。Hold／Live、縦パン・時間ホイールと実フレームへの時間A／B固定を接続した。Hold中も収集と最新履歴を更新し、Live復帰で保持・時間選択を解放する。表示色・ズーム・スクロールでは再解析しない。

数値フレーム合計192 MiB、処理中・公開・表示中のラスタ合計8 MiBを制限する。最新・Hold各96 MiB、作業領域を含むCPU224 MiB・GPU32 MiBの最終ゲートは、設定変更・反復操作時のピーク容量の統合評価を残す。S3の容量・実時間負荷・操作の受け入れを先に行い、S4のSpectrum連動とS5のOverlapは未着手。
通常ビルドの手動操作、実モニター間DPI、実時間・外部I/Oの比較負荷評価は未確認。完了条件は、上限内での履歴保持とピーク容量、Live復帰、任意の有効時刻の精密なSpectrum読み出し、Overlap変更後の時間・周波数・振幅の正確さ、既存操作・測定性能の維持。GUI基本操作の受け入れとGenerator／同期比較の統合評価を完了済みとは扱わない。

### 4.5：Generatorの統合評価

[Generator設計](GENERATOR_DESIGN.md) の契約を、通常Generatorの経路で確認する。

* 最大利用可能Fs、反復起動／再接続、通常幅・狭幅・DPI切り替えで、編集・出力状態・停止・復元を確認する。
* 外部出力観測履歴を通常GUI・実機の状態変更と照合し、入力Stop／Single／失敗で保持したJSON／CSVを確認する。出力時計と入力窓の対応は未校正のまま明示する。
* UI停止中の入出力・解析継続、100回編集、連続出力→有限Stop→最終数値照合→解放後通知監査を、公開候補の条件で確認する。48 kHzの過去の300秒試験を最大Fsや反復起動の成功へ広げない。
* 別プロセスの設定復元でもOFFを維持し、明示Start後の再測定を照合する。実USB切断の一条件の成功を、反復切断・再接続後の測定保証にしない。

完了条件は、通常GUIから周波数・peak振幅・位相を設定し、内部・外部の両経路でScope／Spectrum／Lock-inとの照合と結果再利用が成立すること。起動時Xrunの原因と機器・Fsごとの安定性は引き続き評価する。

### 5：同期2ch比較の統合評価

AC比較、複素値・符号・無効条件は [同期比較設計](COMPARISON_DESIGN.md) を参照する。

* コヒーレンス軸・文字・微小値の表示修正後のGUIを確認する。
* 通常Generatorの内部接続、BlackHole 2ch／16ch、UAC-232 LL／RR TRSで、同じ入力窓の独立DFT照合、欠落時の無効化、有限Stop、保持／保存／復元／再測定を確認する。
* 段階4.5の出力評価と合わせて受け入れを判定する。GeneratorやUSB切断の過去の成功を比較演算の実機照合へ流用しない。

最初の用途は同じ入力時計の2chのゲイン・位相・遅延比較。CH間の物理校正がない結果には、その制限を表示・保存する。

### 6：最小の応答測定フロー（未着手）

段階4.5の出力制御と段階5の同期比較を使い、2ch REF／応答の最小FRF／Bode用途を作る。

* 測定フローへ入出力の所有権を渡し、手動操作との競合、完了・停止・失敗時の出力停止を定義する。設定復元だけで出力を開始しない。
* 周波数点ごとの励振→整定→取得から始め、既知ゲイン・フィルターを内部→仮想I/O→物理系の順で照合する。
* 条件付き結果、校正・欠落・時計の識別、保存・再実行までを完了条件にする。基本Generatorを再実装せず、THD／IR・連続スイープは個別に計画する。

## 継続する制限

* 公称Fs・未校正FSを基準とする。実時計、物理振幅・CH間位相校正、出力校正、DAC／ADC絶対遅延は未確認または未実装。Scopeの波形軸・トリガーとSpectrogram／XYはFS。
* 外部I/Oの可変コールバック、接続直後のSingle、全起動・再接続の安定性、物理16ch、Windows／Linux・他機器の実機評価は未確認。設定上限768 kHzは動作保証ではない。
* GPU実行時間・実表示／scanout、反復操作応答、最大Scope区間のコピー・ディスクI/O負荷は評価を残す。通常GUIの約270秒の受け入れは600秒完走・終了監査の成功を意味しない。
* Live／Latestは最新完全窓の観察で、過渡捕捉を保証しない。512k・48 kHzの完全窓は約10.92秒。表示間引きと入力・解析欠落、窓時間と処理遅延を区別する。
* Spectrogram／XY・カーソル・全CH長時間記録・Spectrum窓の全生入力は結果保存の対象外。PNGはScope／Spectrum。
