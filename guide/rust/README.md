# MeasureLab — Rust Audio Measurement Lab

CPALで実際のオーディオ入力を取り込み、egui / eframeと`wgpu`で波形・FFTスペクトル・スペクトログラム・XY / Lissajousを同時に描画するRustプロトタイプです。この文書は現在使える操作と構成を説明します。目的・設計原則は [現在の方針](../CURRENT_DIRECTION.md)、実装状態・制限と次の完了条件は [PLAN.md](PLAN.md) を参照してください。

GUIの`View → Language`（日本語では`表示 → 言語`）で9言語から選び、次回起動へ保存できます。英語を基準に、日本語・フランス語・ドイツ語・スペイン語・ポルトガル語・ロシア語・中国語・韓国語の全グループを初回翻訳しました。訳語と表示の読みやすさの視覚レビューは継続中です。狭幅では`Menu → View → Language`を開きます。初回・未知の言語設定は英語です。未翻訳・未確認・古い訳は英語へフォールバックします。言語は表示設定で、測定条件・保持結果・出力状態とは独立しています。I5の基盤受け入れは完了し、以後の差分翻訳は変更キーを抽出して追加します。以下の操作名は英語表示です。翻訳担当が訳文欄だけを編集する標準手順は [開発・翻訳手順](I18N.md) を参照してください。

## 起動

Rust 1.95以上と各OSのビルドツールが必要です。開発・検証にはRust 1.99を使用しています。

新しいmacOS／Linux環境では`./scripts/setup_dev_env.sh --install-os-deps --verify`でRust・サイト・文書用ツールを導入できます。前提条件と導入先、手動設定は [開発環境のセットアップ](SETUP.md) を参照してください。

### デバッグ時の簡単な起動

リポジトリのルートにある **Debug-MeasureLab.command** をmacOSのFinderでダブルクリックすると、開発用の`dev-fast`ビルドを更新して実入力を選ぶ画面で起動します。ターミナルからは以下を使います。

```sh
./scripts/debug.sh
./scripts/debug.sh --demo
./scripts/debug.sh --compact
./scripts/debug.sh --full-debug
./scripts/debug.sh --release
```

引数なしでは実入力を選ぶ画面で停止した状態から始まります。デバイスを選んで **Start input** を押します。`--audio`も同じ動作です。`--demo`を明示すると、検証用の`qa`機能を有効にして内部信号で起動します。通常は差分ビルド向けの`dev-fast`を使い、panic時のファイル・行番号付きバックトレースを有効にします。`RUST_BACKTRACE`を指定済みならその値を使います。デバッガーで型・変数情報が必要なときは`--full-debug`、CPU処理時間や実時間の性能確認には`--release`を使います。

`dev-fast`は既存devのアプリ最適化レベル1・依存ライブラリ2、インクリメンタルコンパイル、debug assertion・整数overflow検査を引き継ぎ、デバッグ情報を行番号中心に絞り、LTOを無効にします。出力は`target/dev-fast/measurelab`です。devの完全なデバッグ情報とreleaseのThin LTO・codegen-units=1は維持します。切り替えとビルド時間の調べ方は [Tool Usage Guide](../../.agents/workflows/tool_usage.md#開発ビルドと時間計測) を参照してください。

初回は依存関係のビルドに時間がかかり、以後は変更した部分を再ビルドします。スクリプトは作業ディレクトリに依存せず、`scripts/cargo.sh`経由でPATH上または`.tools/`のRust環境を使います。アプリを閉じるまでターミナルにビルド結果と実行時の出力が残ります。Finderからの起動に失敗した場合はEnterを押すまでエラーを確認できます。

画面確認は次の1コマンドで実行できます。`--ui-smoke`の指定時は`qa`機能を自動的に有効にし、撮影後に終了します。画像は`dist/ui-smoke.png`へ保存されます。

```sh
./scripts/debug.sh --ui-smoke
./scripts/debug.sh --ui-smoke --compact
./scripts/debug.sh --gpu-smoke
./scripts/debug.sh --help
```

`--compact`などのアプリ引数も渡せます。`--`以降はすべてアプリへ渡すため、アプリ自体のヘルプは`./scripts/debug.sh -- --help`で確認できます。

### Cargoからの起動

```sh
cargo run --release
```

この作業環境ではプロジェクト専用のRust環境を`.tools/`に用意しています。通常の`cargo`がPATHにない場合も、次のコマンドで起動できます。

```sh
./scripts/cargo.sh run --release
```

入力を設定済みの起動直後は、Scope中央に控えめな **Input stopped** だけを表示します。**Audio I/O → Input / output** から入力を選び、上部の **Start input** を押してください。開始すると停止表示は消え、開始待ち・サンプル待ち・トリガー待ちは状態文字だけで示します。入力デバイス未設定や取得・設定エラーでは必要な説明と **Open input settings** を表示します。CH数の確定前は範囲外と表示しません。取得済みの波形には案内を重ねず、エラー・欠落情報を残します。停止すると最後の波形が保持されます。再開時は新しい入力で履歴を作り直します。音声ファイルへの保存は行いません。Generatorでは内部ループバックまたは音声デバイスへ正弦波を出力できます。

**Audio I/O → Input / output** の **SAMPLE RATE · INPUT + OUTPUT** は、入力と現在の出力CH数・PCMの両方が対応する公称Fsを一か所で選びます。入力・出力を停止して適用し、保持結果のFsは変えません。**Separate sample rates** をONにすると、Input欄で **Device default** または対応する公称レート、Output欄で個別のFs／CH数／PCMを選べます。選択肢の上限は768 kHzで、44.1／48／88.2／96／176.4／192／352.8／384／705.6／768 kHzなどから対応する値と、デバイス固有のレートを表示します。入力CH数を維持できる設定を使います。入力デバイスを明示的に変更するとDevice defaultへ戻ります。Refresh devicesは保存したID・CH数・Fsを再照合し、同じ入力の設定と校正を保持します。個別設定での入力取得中の変更は新しい入力世代で再開始し、履歴・平均・保持・カーソルをリセットします。停止中の変更は次回Startに適用し、保持結果のFsと時間・周波数軸は変えません。開始時に対応設定を再確認し、失敗時はエラーを表示します。

**Audio I/O → Input / output** は共通の入出力設定です。広幅ではInput／Outputを左右に、狭幅では上下に表示します。Inputで入力元・入力デバイス、Outputで出力デバイス・CH数・PCMを設定し、Fsと **Refresh devices** は共通欄にまとめます。レートが異なる既存設定を開くだけでは変更せず、共通の値を明示選択するまで両方の値を表示します。**Separate sample rates** で個別設定に切り替えられます。GENカードの追加・信号条件・ON／OFF・OUT割当はGeneratorで操作し、Output欄には表示しません。内部接続はInputの **Generator loopback** を選び、OUT 1／2を入力CH 1／2へ対応させます。Calibrationは同じAudio I/Oメニューの別画面です。

通常の起動はユーザー単位のファイルロックで重複を防ぎ、2つ目は既に起動中と表示して終了します。意図的に複数起動する場合は`--new-instance`を追加してください。音声を取得するQAコマンドも同じロックを使い、デバイス列挙とGPU読み戻しは対象外です。起動制御は測定コアから分離しています。ロックファイルは残りますが、[OSのファイルロック](https://doc.rust-lang.org/std/fs/struct.File.html#method.try_lock)はプロセス終了時に解放されるため、異常終了後にファイルを手で削除する必要はありません。旧ビルドにはこの制御がないため、旧版との重複は防げません。

通常ビルドの **Audio I/O → Input / output → Software Loopback** から、マイクを使わず共通入力経路で既知信号を測定できます。条件の詳細は下記のSoftware Loopback節を参照してください。旧QA専用の内部デモは、`qa`機能を有効にしたビルドへ`--demo`を明示して使います。この起動時だけ左側の **Demo signal (QA) / Audio input** で入力を切り替えられます。`qa`ビルドでも、通常起動ではデモの選択肢を表示しません。

```sh
./scripts/cargo.sh run --release --features qa -- --demo
```

`--compact`を追加すると、小さなウィンドウで起動します。複数区画の寸法が不足する場合はタブ表示へ退避します。コンソールで追加の測定詳細や4数値表示が区画高を超える場合は、その区画内を縦にスクロールできます。共通の入出力状態・停止操作と区画名はスクロールの外に残ります。

デモでは周波数、振幅、ノイズを変更し、正弦波／高調波付き正弦波／帯域制限した矩形波を比較できます。CH 2の位相と振幅比も変更できます。**0° / 90° / 180°** ボタンはノイズなし・同振幅の正弦波を設定し、XYの同相・円・逆相を確認できます。CH 2 gainを下げると楕円になります。デモ信号は内部だけで使い、スピーカーには出力しません。

通常起動は入力・出力停止の **Scope単独表示** です。左の計器一覧からScope／Spectrum／Spectrogram／XY／Lock-in／Synchronous 2ch／Generatorを選ぶと、その計器だけを表示します。同じ名前を再選択しても解除しません。名称・用途で検索できます。狭幅では上部の **Instrument** メニューから選びます。表示操作で取得・解析・出力を開始／停止しません。

一覧は1計器1行のアイコン＋名称で、選択行全体を強調します。上部の切り替えボタンでアイコンだけのコンパクト表示にすると、幅が縮まりプロット領域が広がります。7計器は常に同じ順序で並び、クリックで選択、ホバーで名称と実行状態を確認できます。選択中は背景、実行状態は右下の点で区別し、緑は実行中、黄は開始・停止処理中や入力待ち、灰は停止、橙は出力エラーです。最下部の4区画アイコンは **Multi-instrument view** です。通常表示ではMonitorの共通入力状態を見出しにまとめ、解析と出力の状態を各行の右端へ表示します。保持結果や測定の有効性は各計器内で確認します。

表示モードは自動保存し、次回起動時に復元します。測定設定ファイルとは独立した表示の設定で、起動時の入出力は停止のままです。狭幅ではサイドバーを一時的に隠し、**Menu → View → Compact sidebar** でもモードを変更できます。広げると選んだモードへ戻ります。

単独表示の **Split view with…** は現在の計器と選んだ計器の2区画を作ります。既存コンソールを置き換える場合はメニューで案内し、コンソールの **Arrange view… → Undo replacement** で直前の構成へ戻せます。**Multi-instrument view** は保持した構成を開き、**Add instrument…** で追加します。同じ計器は複製せず選択します。区画のクリック、名前付きタブ、Ctrl＋左右キーで対象を選び、**Open single** で単独表示へ戻ります。**Remove from view** は表示からだけ外し、解析やGenerator出力は続きます。最後の区画を外すと追加案内を表示します。

配置は **Arrange view…** の **Side by side / Stacked / 2 × 2 / Tabs** を選びます。同時表示できる区画は見出しのクリックで選択し、上段の選択行はタブ表示や区画数超過時だけ表示します。各区画の **⋯** に **Open single / Remove from view** をまとめます。2区画／4区画を超えた計器は名前付きタブで選択します。寸法が不足するとタブ表示へ退避し、広げると希望配置へ戻ります。**View** の **First pane share** で分割比率、**Display scale** で表示倍率を調整できます。倍率は75／90／100／110／125／150／175%から選び、クリックで確定したときだけ画面へ反映してメニューを閉じます。候補へのホバーやEscで閉じる操作では倍率は変わりません。100%を選ぶと標準倍率へ戻ります。狭幅では **Menu → View → Display scale** から選びます。単独表示とコンソールの往復・リサイズで構成と比率は消えません。

右の詳細欄は選択中の計器だけを扱い、ホバーでは対象を変えません。**View / Selected instrument details** で表示を切り替えます。狭幅では中央の **Measurement / Details** へ退避します。ScopeのCH選択と表示ON/OFFは波形直下の4chバー、カーソルは本体で操作します。取得・トリガー状態とカーソルを同じ行にまとめ、時間軸・選択CHの縦軸倍率・Autosetと倍率方式はその下の操作行で調整します。時間軸の重複ラベルを省き、狭幅では必要に応じて折り返します。停止したNormal／Singleでは保持波形の時間軸と次回Startに適用する設定を区別して表示します。

Scopeの見出しは単独表示で一つにまとめ、複数計器表示では区画名を残します。詳細欄の **Scope settings** はAcquisition／Trigger／Horizontal／Verticalの枠で区切り、Verticalには選択CHと同じ色を付けます。Acquisitionは取得モード・Start single capture・Autoset、Triggerはエッジ・入力CH・レベル、Horizontalは時間軸・水平位置、Verticalは選択CHの振幅・オフセット・Fit amplitude・入力割当を扱います。時間軸と振幅は対数スライダー、位置・レベルは線形スライダーで調整し、値のドラッグやダブルクリックによる数値入力も使えます。

波形の **Amplitude [FS] · CH… axis** は選択CHのraw FS、**Time [ms]** はトリガー基準からの時刻です。**FS** はデジタルのフルスケール、**Fs** は公称サンプルレート、**div** はグリッドの1目盛りを表します。RMS／P-Pは取得時のCH校正を適用した数値で、各値に単位を表示します。波形軸・トリガーレベルのraw FSと区別してください。時刻・周波数は取得時の公称Fsに基づき、実時計の校正済み値ではありません。

**Per-channel scale** は各CHの独立した倍率とオフセットを使います。振幅が異なっても同じ高さに見える場合があります。**Common scale** は選択CHの縦軸設定を全CHへ適用し、その後のCH選択でも共通軸を保ちます。共通モードの倍率・オフセット・Fit amplitude・Shift＋ホイールは全CHへ作用し、Fit／Autosetは表示中CHの最大Peakに合わせます。独立モードへ戻すと元のCH別設定を復元します。倍率方式と共通軸は設定ファイルへ保存します。各CHのRMS／P-Pと単位は波形の近くに併記します。Autoset通知は **Last Autoset** として前回の結果を示し、入力元の切替・再開始時に解除します。周波数変更後の現在値を連続検出する表示ではありません。

上端の **T** は時刻0 ms、右端の **T** はトリガーソースCHのraw FSレベルを示します。右端の位置はソースCHの縦軸設定に従い、選択CHの振幅軸と異なる場合があります。未取得やトリガー未成立では **T markers: settings only**、トリガー成立済みの区間では **T markers: captured** と表示します。マーカーへのホバー、Scope settings、Helpで意味を確認できます。

ポインターが波形内にある間だけ、読み取り位置を示す薄い縦ガイド線を表示します。プロット外へ移動すると消え、配置したA／Bカーソルと取得データは保持します。Tマーカーは短い印で、縦ガイド線やA／Bカーソルとは別です。

XYの詳細欄も枠で区切り、Observationで観察時間幅とスケールのリセット、X Axis／Y Axisでそれぞれの入力CHと振幅範囲、CursorsでFree／Trace Snapを設定します。Trace SnapではScopeと共通のTriggerも同じ詳細欄で編集できます。狭幅では **Details** で開きます。**Place cursor: A / B**・**Clear cursors** と読み値はグラフ側に残ります。

**Place cursor: A / B** は次にクリック／ドラッグで配置する対象です。A／Bを選ぶだけでは配置せず、**Placed: none / A / B / A, B** が配置済みの対象を示します。Scope・Spectrogram・XYの **Clear cursors** は共通の時間・周波数・XY自由配置とSpectrogramフレーム選択を解除します。Spectrumの **Clear cursors** と履歴Spectrumの **Clear frequency** は周波数だけを解除し、時間・フレーム選択・XY自由配置を保ちます。取得済みのデータは消去しません。

FFT・窓・平均なども各計器の詳細欄です。Generatorの周波数・振幅・位相・波形・OUT・カード管理・ON／OFF・Start outputは本体、刻み幅・Noiseのseed・選択カードの適用値は詳細欄です。出力開始付近には出力先と現在選択中の入力元を併記し、**Open input settings** で接続設定を開けます。内部出力ではGenerator loopbackの選択状態とOUT→CH対応を示します。外部出力は物理・仮想経路の接続を別途行い、入力・出力はそれぞれ明示的に開始します。

上部は左のメニューと右の入出力操作を1行にまとめ、**Start input / Stop input** を右端に置きます。狭幅ではメニューを **Menu** にまとめ、状態の接頭辞を **IN / OUT** に短縮します。**Audio I/O** の **Input / output** と **Calibration** は共通設定画面を開きます。**Back to instruments** またはEscで元の計器・選択区画へ戻ります。**Start input / Stop input** は共通入力、**Stop output** は独立したGenerator出力を扱います。出力状態と停止操作は計器や設定画面に関係なく常設です。**Stop output** は完全停止時だけ無効になり、開始待ち・設定適用待ち・停止処理中やエラー時には停止要求を送れます。**Analysis status…** で非表示のLock-in／同期比較の解析状態を確認・停止できます。入力待ち、解析停止、取得状態、有効性を区別します。

**File** は設定・保持結果の保存／復元と **Compare saved reference**、**View** は配置・詳細欄・倍率、**Help** はショートカット・単位・診断を扱います。Ctrl＋1〜7で一覧順に計器を選択し、Tab／Shift＋Tabで編集へ移動できます。Spaceによる入力操作は入力ボタンが使える場合に限り、一押しで一度だけ切り替えます。入力欄・メニューの操作中、修飾キー付き・長押しの反復では取得状態を変えません。

計器・区画選択のショートカットも一押しで一度だけ扱い、Ctrl以外の修飾キーを併用した場合や、入力欄・メニュー・Help・File paths & statusの操作中は背後の選択を変えません。Help・File paths & statusを開いている間はSpaceによる共通入力ショートカットを無効にします。入出力画面ではCtrl＋左右キーで背後の区画を選択しません。Escは編集中の項目や前面メニュー／ウィンドウで扱い、同じ一押しで背後の入出力画面・狭幅の詳細から戻りません。編集や前面表示を終えた後の一押しで元の計器へ戻ります。

各測定器は取得状態を **LIVE / HELD / WAITING / NOT ACQUIRED / FINISHING** で示し、トリガーやREF・比較の有効性を別に表示します。起動直後のFsは未取得、停止後は保持入力の公称Fsです。Scopeは波形・トリガーがraw FS、RMS／P-PがCHごとの校正単位であることを同じ領域に表示します。主要数値は読みやすい桁数へ整え、詳細のホバーとJSON／CSVにはf64の精度を残します。

macOSではマイクへのアクセスを許可する必要があります。許可がない場合は「システム設定 → プライバシーとセキュリティ → マイク」で、起動に使うアプリ／ターミナルを確認してください。独立したアプリとして起動するには以下を使います。

```sh
./scripts/bundle-macos.sh
open dist/MeasureLab.app
```

DMGを作る場合は`./.venv/bin/python scripts/macos_package.py build`を使います。Intel／Apple SiliconそれぞれのMacで通常版をビルドし、Applicationsへのコピー用リンクとマイク権限の説明を含めます。署名・公証の制限と検証手順は [macOS配布](RELEASE_PREPARATION.md#macos配布) を参照してください。

LinuxではALSAおよびウィンドウシステムの開発ライブラリが必要です。Ubuntuの場合:


画面は横10分割・縦8分割です。トリガーは横20%位置で、交差が見つからない場合は最新の波形を表示するAuto動作です。コアは1〜16chを保持し、Scopeの4本のトレース、Spectrum、Spectrogram、トリガーは取得した全chからソースを選択できます。Scope下部CH1〜CH4の既定入力は入力CH 1〜4です。Vertical / Input sourceで同じ入力を複数トレースへ割り当てることもできます。波形・選択表示・測定値の色はトレースごとに統一し、縦軸目盛は選択CHのFSレンジとオフセットを示します。16chを超える入力は切り捨てずエラーを表示します。

RMS・Peak・P-PはScopeの整数サンプル区間内に取得した生のf64サンプルから計算します。欠落は観測数へ含めず、部分区間であることを表示します。統計値の説明には対象区間と取得サンプル数を表示し、描画倍率・幅・トレースの非表示化では同じ区間の値を変えません。時間幅やトリガー条件を変えると測定区間も変わります。カーソルは割当先CHの実サンプルを読み、描画時の極値集約やトリガー補間から振幅を逆算しません。

入力CH数が減ったときもScope・XY・トリガーの割当IDを保持し、存在しないCHを別CHへ置き換えません。取得済みの2ch入力では既定CH3／CH4、モノラルではCH2〜CH4をOut of range（狭幅では—）で示します。未取得の理由は中央の案内にまとめます。選択・表示ON/OFFの設定は保持し、別の入力へ自動で置き換えません。停止中のScope／XYのCH変更は次回Startに適用し、保持中のトレース・統計・カーソルは取得時のCHを表示します。

Scope settingsの **TRIGGER / Display** で、**Markers**（既定）は位置とレベルのオレンジの「T」だけ、**Guides** はTと縦・横の点線、**Off** はどちらも非表示にします。レベルの三角マーカーは波形領域の右外側に表示します。どの表示モードでもLevelをドラッグ・数値入力している間は、編集中のレベルに水平の点線を一時表示します。表示モードは測定設定JSONのWorkspaceへ保存し、項目のない旧設定はMarkersで復元します。

生サンプル・波形軸・トリガー閾値の振幅は、CPALから取得したデジタル音声のフルスケール（FS）です。サンプルレートは取得に使った公称値で、デバイスの時計を校正した実レートではありません。768 kHzは設定上限であり、実際に選べるレートはデバイス・OSの対応範囲に依存します。外部ADCの制御、音声デバイス以外の入力は未実装です。

**Audio I/O / Calibration** ではCH 1〜16のScope数値読み出しとSpectrumに `y = gain × x(FS) + offset` を適用できます。Gainは物理単位/FS、Offsetは同じ物理単位です。V、mV、Aなどの単位と、基準信号・デバイスレンジ・日付・不確かさなどの参照条件を入力し、**Queue calibration** を押して次回Start用に設定します。負のゲインも使えます。ゲイン0・非有限の係数・空の単位や参照条件は拒否します。**Queue uncalibrated FS** はそのCHの次回用校正を解除します。入力CHの位置をIDとして扱い、トレースを入れ替えても校正は入力CHへ対応します。

ScopeではRMS・Peak・P-Pと時間カーソルの数値に校正を適用します。RMSは各実サンプルを換算してから計算するため、オフセットを含みます。Scopeの波形軸・カーソル点の位置・Fit amplitude・トリガー閾値とSpectrogram／XYはFS基準です。Spectrumは選択CHの校正を振幅・PSD・ESD・平均・ピーク保持・カーソル・帯域電力・窓エネルギーへ適用します。数値と軸の単位をそれぞれ表示します。校正による非有限値やP-Pのオーバーフローは **invalid value** とし、正常値へ置き換えません。欠落や存在しないCHは従来どおり利用不可・部分区間として扱います。

校正のID・版・係数・単位・参照条件は取得世代のスナップショットへ固定します。Scope統計の説明、**Captured readout condition**、Spectrumの校正表示・カーソルの説明で確認できます。取得中や停止後に新しい定義を設定しても、保持中のScope／Spectrum値と校正版は変わりません。Startで適用するまで **Queued for next Start** と区別します。入力ソース・デバイスを選び直したときと **Refresh devices** の再列挙では次回用の校正を解除し、別入力へ持ち越しません。校正は下記の測定設定ファイルへ保存・復元でき、保持したScope／Spectrum結果の書き出しにも含めます。ユーザーが与えた係数による換算であり、ADCや物理基準の校正精度を検証済みとは扱いません。

### 起動設定の自動保存・復元

入力・出力デバイス、個別／共通Fs、各計器の測定条件・CH校正・表示範囲・画面配置、サイドバー表示と言語を自動保存し、次回起動時に復元します。変更を約2秒ごとに確認し、変更があるときだけ専用I/Oワーカーで原子的に保存します。通常終了時は最後の変更を書き終えます。入力・出力は停止状態で復元し、Startはそれぞれ明示操作です。取得データ・保持結果・カーソル・一時ウィンドウは自動保存しません。入力未選択など測定条件が未確定の間は直前の有効な測定条件を保持し、まだ一度も確定していなければ表示設定だけを保存します。

| OS | 自動保存先 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\MeasureLab\startup-preferences.json` |
| macOS | `~/Library/Application Support/MeasureLab/startup-preferences.json` |
| Linux | `$XDG_CONFIG_HOME/MeasureLab/startup-preferences.json`（未指定・空・相対パスなら`~/.config/MeasureLab/startup-preferences.json`） |

OS標準のディレクトリAPI（[dirs](https://docs.rs/dirs/6.0.0/dirs/fn.config_local_dir.html)）で保存先を解決します。Windowsでは機器IDを他PCへローミングさせないローカル領域を使います。実行ファイルの場所や作業フォルダーから設定を探さず、Python版の`config.json`や手動保存した測定設定を自動取り込み・上書きしません。言語とサイドバーは既存の起動設定を初期値として引き継ぎます。QAのデモ・UI smoke・プロファイル実行は通常の起動設定を読み書きしません。

入力を名前や列挙順で代用しません。保存した機器の不在・ID重複・CH数や対応Fsの変化ではその入力を未選択にし、条件と校正を残して理由を表示します。停止・ストリーム解放後に接続を戻して **Refresh devices** を押すと同じ条件を再照合します。別機器や変更後の条件を使う場合はデバイスを明示選択してください。出力先が不在でも選択と信号条件を保持し、Start output時に対応を再確認します。

**File / File paths & status… / STARTUP PREFERENCES** で実際の保存先を確認できます。保存失敗や破損・未対応版は下部の **Startup preferences error** から確認します。読み込めないファイルは自動上書きせず、初期値で利用できます。設定を作り直す場合はアプリを閉じ、表示されたファイルを別名へ退避して再起動してください。設定フォルダーを解決できない場合も作業フォルダーへ暗黙に保存しません。

### 測定設定の保存・復元

上部 **File / Save settings…** で保存先を選びます。**Restore settings…** は入力・出力停止中にファイルを選んで復元します。従来の **File / File paths & status… / MEASUREMENT SETTINGS** のパス指定も使えます。次回Start用の入力デバイス・CH割当・トリガー・観察幅・Spectrum／Spectrogramの解析設定・PSD帯域・校正定義を版11のJSONへ保存します。Generatorの出力先・Fs・信号条件・内部入力選択、Audio deviceの安定ID・CH数・PCMも保存し、版1〜10の読み込みを維持します。取得中の保持結果や未確定の校正エディター入力を保存する操作ではありません。単独表示／コンソール、計器順・選択区画・希望配置・比率・詳細欄の表示と軸・表示範囲は別のWorkspaceブロックへ保存します。旧2トレース設定は入力割当と倍率を保持して4トレースへ移行し、追加CH3／CH4は表示OFFにします。CHごとのレンジ・オフセット、選択CH、水平位置も保存します。SpectrumのCH別表示・入力割当・選択、Autoレベル・マーカーも保存し、版5以前は従来の1本表示を維持します。旧設定の表示順を引き継ぎ、単一計器は単独表示、複数計器はコンソールへ移行します。Spectrogramの色・Manualレンジ・Auto・時間幅も保存し、新フィールドがない旧設定はBlue・Manual・Overlap 75%で復元します。Hold履歴・時間選択・一時的なSpectrum履歴データ源は保存しません。読込だけで旧ファイルを上書きしません。生サンプル・測定結果・カーソル位置・表示倍率は含めません。Software Loopbackの仮想DUT条件、Scope取得モードと実験段階Lock-inの設定も保存します。これらを含まない版1ファイルはAuto・Lock-in無効として読みます。QA専用内部デモは保存対象外です。

既定の保存先はmacOSで `~/Library/Application Support/MeasureLab/measurement-settings.json`、Windowsで `%APPDATA%/MeasureLab/measurement-settings.json`、Linuxで `$XDG_CONFIG_HOME/MeasureLab/measurement-settings.json`（未設定時は `~/.config/MeasureLab/measurement-settings.json`）です。別のパスも指定できます。この手動保存ファイルは自動保存・起動時読み込みの対象外です。

再起動後、入力と出力を停止した状態で同じパスを指定し、**Restore settings** を押します。Stopの解析完了・デバイス操作・Scopeの保留操作も完了するまで待ちます。復元だけでは取得・出力・記録を開始しません。校正と解析条件は次回Start用に適用し、保持結果のCH・公称Fs・入力世代・校正版は維持します。軸や観察幅などの表示操作は保持した生サンプルから再表示します。復元中はStartを受け付けません。

入力は名前や列挙順でなくCPALの安定したデバイスIDを照合します。不在・重複ID、CH数の変化、指定レートの非対応、Device defaultで保存した既定Fsの変化では復元全体を拒否し、別のデバイスやレートへ置き換えません。接続を戻して **Refresh devices** を行い、再度復元してください。対応しない版・旧形式・不正値・64 KiBを超えるファイルや、セッション内で既知の校正ID／版と異なる定義も拒否します。保存失敗では以前のファイルを維持し、成功・失敗はパネルと下部の **Settings status / Settings error** から確認できます。デバイスIDの保証範囲はOS・バックエンドに依存します。

### Generatorの出力と内部ループバック

計器一覧で **Generator** を選び、**Split view with… / Scope**（またはSpectrum／Lock-in）で並べます。**+ Add signal**で最大16枚まで追加し、各カードの**Duplicate／Remove／Up／Down**で複製・削除・並べ替えます。GEN IDとOUTは独立し、他カードの削除・並べ替えでも出力先を保ちます。複製は新しいID・OFF・空きOUT（なければ未割当）になります。カードの**Waveform**でSine／Square／Triangle／Noise、**OUT**で出力先、**ON**で出力対象を選びます。使用中のOUTは選べません。**Audio I/O → Input / output**の共通欄でFsを選び、周波数・振幅・位相を直接入力してEnterまたはフォーカス移動で確定します。入力途中の値は適用せず、Escで取り消します。詳細欄の**EDIT STEP**で刻みを選び、＋／−／上下キーで値を調整できます。周波数は0.1 Hz以上・出力Fsの45%未満、振幅は−120〜0 dBFSのpeak基準、位相は±180°です。カード構成・波形・seed・出力CHは出力停止中に変更し、二重割当はOFFのカードも含め拒否します。

**Start output**で選択した信号を生成します。**Audio I/O → Input / output → Generator loopback**で共通入力を選び、上部の**Start input**で実際のf64出力サンプルを取得します。両方を個別に開始します。周期波形のプレビューは設定の2周期、Noiseはseedからの設定スケッチで、振幅に合わせた縦倍率とFS上限を表示します。実波形はScopeで確認してください。中央は従来の3行編集と小さなプレビューを保ち、十分な幅ではカードを2列に並べ、狭幅ではGEN ID・OUT・ON／OFFを残すカード選択へ切り替えます。GEN見出しでカードを選び、刻み幅・Noiseのseed・適用詳細は右の詳細欄で操作します。**Hide signal controls / Show signal controls**で編集欄とプレビューを開閉し、閉じた状態でも全カードの設定概要を確認できます。上部の出力停止操作は常設です。

Square／Triangleは定常状態で0.45 Fs未満の奇数次高調波を最大16本使い、SquareはFejer重みでpeakを抑え、Triangleはpeakを正規化します。peak欄はFS上限で、RMSとSquareの実peakは周波数で変わります。Triangleの0°は正のpeakです。Noiseはseed付きの連続一様白色雑音で、Startで再生します。Noiseの周波数・位相欄は値を保持して無効表示とし、右側でseedを編集します。Sweep・同期／グループ・リンク・複数OUT・Mixは未実装です。

出力状態は実行側の応答に基づくSTOPPED／STARTING／RUNNING／STOPPING／ERROR、設定はPENDING／APPLIED／TRANSITIONで表示します。詳細で最後の適用値と整数サンプル境界を確認できます。振幅・位相・ON／OFFは原則10 msの遷移で、周波数変更はcarrier位相を保持します。異なる周波数履歴の後は相対位相が自動では揃わず、同期操作はMVPのGUIに含めません。内部接続では遷移中の実サンプルをScope／Spectrogramへ渡し、Spectrum平均・Lock-inは遷移終了後の完全窓から再開します。

入力Stop／Single完了は結果を保持し、出力は続きます。**Stop output**はフェード後に停止し、入力が取得中なら無音の新しいフレームを続けます。Generatorを隠しても上部の出力状態と**Stop output**は残ります。起動・復元・Fs変更で自動出力せず、アプリ終了時も停止します。

内部出力は44.1／48／96／192 kHz・2chのf64です。**Audio I/O → Input / output**のOutput欄で音声デバイスを選び、共通の **Refresh devices** で入出力を再取得できます。出力先・Fs／CH数／PCMは入力と出力を停止して選びます。Generatorカードでデバイスの1〜16ch構成へ各信号を1対1で割り当て、未割当CHは無音にします。開始時に選択した安定IDと形式を再確認し、使えない設定は開始しません。**Audio I/O → Input / output**のInput欄で接続先の実入力を選び、個別に**Start input**してください。**Generator loopback**は内部接続で使います。ストリーム通知・コールバック停止はERRORとなり、**Reset output (stays OFF)**後の明示Startで再開します。出力校正は未実装です。既存Software Loopbackの既知DUTとは別の入力モードです。設定は版11、結果は版7で保存し、旧設定版1〜10・結果版1〜6も読み込めます。内部接続の結果には受信した最大128区間の出力条件を含め、履歴外・欠落した区間は対応不明とします。保持後のGenerator編集では結果を変更しません。Generator結果のRMS・PSD帯域電力・Lock-inの参照との数値差は2カードのSine構成に限り、両寄与区間が定常で設定・同一周波数の相対carrier位相が一致するときだけ表示します。

**Audio I/O → Input / output → Output** の **Enable dithering (TPDF)** で外部出力のディザを有効にし、**DITHERING BIT DEPTH** で8／16／24 bitを選べます。既定はOFF・24 bitです。選んだ深度のTPDF雑音を加えて丸め・クリップし、f32／f64出力でもその深度へ量子化します。整数PCMでは出力形式で表現できる深度だけを選べ、PCMの精度を下げると深度も対応範囲へ下がります。変更は入出力停止中に行い、次の明示Startで適用します。停止・OFF・未割当CHは無音を維持し、内部ループバックには適用しません。設定と外部出力の観測履歴にディザ条件を保存し、旧設定・旧結果の欠落項目はディザOFFとして読みます。

出力デバイスやCH数を変更したときは、範囲外になるOUT割当を未割当・OFFにします。GEN ID・信号条件と利用可能なOUT割当は保持し、出力は自動開始しません。デバイス再取得・入力停止処理・設定復元の待機中は入出力の接続設定を変更できません。

外部入力と出力の連番は別の時計です。外部Generator編集の遷移は入力窓と自動対応せず、Spectrum／Lock-inの入力解析を自動リセットしません。同期REFは実入力2chを使い、編集後は整定を待ってください。外部Generatorが選択・観測された実入力結果のJSON／CSVには、入力開始時と保持時の最新観測、取得中に管理ワーカーが観測した最大128件の出力状態変更、出力ID・Fs・CH数・PCM・実適用設定・出力世代・整数境界・失敗を保存します。ホスト観測時刻は出力ワーカー作成からの単調時間で、DAC／ADC時刻や入力サンプルとの対応ではありません。履歴退役数、報告された応答欠落数と出力通知のワーカー開始以来の累計を保持し、未観測区間を補完しません。入力Stop／Single／入力失敗で固定し、その後の編集・Reset・出力停止で変更しません。入力窓への対応は未校正として、これらの結果のRMS・PSD帯域電力・Lock-inの数値差を表示しません。出力の有限Stop・解放後の通知監査を完了した証拠とは分けます。

macOSの実入出力は、コールバックの時間的余裕を確保するため、約20 ms以上に相当する2のべき乗のフレーム数を機器の対応範囲内で要求します。48 kHzで対応していれば1,024フレーム（約21.3 ms）です。上限・下限で制限される機器や対応範囲が不明の機器では、この時間を保証しません。Fs・CH数・PCMは選択値を維持します。バッファは応答遅延との交換条件であり、出力編集やStopの適用を次のコールバックまで待つことがあります。公称Fs・演算精度・DAC／ADCの校正とは別の条件です。

### Software Loopbackと実験段階Lock-in

通常ビルドの **Audio I/O → Input / output → Software Loopback** を選び、Startを押すと2chの同期f64入力を生成します。CH 1はREF、CH 2は既知ゲイン・位相・整数サンプル遅延・DC・雑音を適用した正弦波DUTです。雑音は指定RMSの独立な一様乱数です。周波数・振幅・REFの有効／無効と応答周波数ずれも設定でき、条件は次回Startに適用します。公称Fsは44.1／48／96／192 kHzです。整数遅延は正弦波を解析的に遅らせ、開始直後の未到達応答は0とします。スピーカーや物理出力は使いません。

計器一覧の **Lock-in** で単独表示します。**Split view with… / Scope** で波形と並べます。表示を外しても有効な解析は継続します。

本体の **Start analysis / Stop analysis** とSIG／REF CHを使い、詳細欄でREF周波数ヒント、時定数、積分サンプル数、REFのAC RMS閾値を指定します。入力停止中の有効な解析は **WAITING FOR INPUT** と表示し、入力は **Start input** で明示的に開始します。取得中の変更は平均をリセットして再整定し、停止中の変更は次回Start用です。保持中は取得時の条件を表示し、変更があると **Next Start settings changed** を併記します。REFは常に入力サンプルを使用します。Trackingはヒントの±10%に限定し、REFのAC RMS不足・単一正弦波への適合率98%未満・一窓3周期未満は無効になります。既定のREF閾値は0.001 FS RMSです。同じCHをREF／応答へ選ぶ自己検査も可能です。

画面の **R / θ**、**X / Y**、**All four** で大きな数値表示を切り替えます。数値下のバーは表示専用の自動スケールで、入力感度や測定演算を変更しません。FS／校正後の単位、peak定義、REF周波数、Gain、取得時のτ・積分窓を併記します。Gainの単位は応答単位／REF単位です。**REF VALID**、**SETTLING** と10τの進捗、**REF LOST / UNSTABLE**、入力欠落・無効状態、**HELD** を区別し、無効値はゼロで代用せず「—」とします。**Measurement details** で整数サンプル区間、REF強度・適合率、処理窓数・欠落数、校正ID／版を確認できます。Lock-inの表示選択・座標表示は測定設定JSONのWorkspaceへ保存され、旧版1ファイルでは非表示・R／θが既定です。

基本波のX／Yは同じ非重複整数窓で測ったREF位相を補正してから二段の複素EMAで平均します。周期Hannの重み付きDC／sin／cos適合を使い、DCオフセットと校正オフセットはACから除外します。校正ゲインはREFと応答の両方へ適用します。Rはpeak振幅、正のY／位相は応答の進みです。複素応答/REFも平均してGainを表示します。フィルター係数は `1 − exp(−N/(Fs×τ))`、整定判定は連続有効入力10τで、UI時刻・壁時計には依存しません。窓平均も応答帯域・遅延に寄与し、τだけで帯域を決めたとは扱いません。欠落・非有限・REF喪失では古い平均と数値を破棄し、回復後に整定し直します。

**Lock-inは実験段階です。仮想系の精度確認は必須ですが、実機でREF・タイミングを含めて使用できるまで完了としません。** 高調波REF、広範囲PLL、異なる入出力時計の補正や、Lock-inから励振を管理する測定フローは未実装です。

### Scopeの取得とAutoset

Scopeを選択し、詳細欄の **ACQUISITION** でモードを選びます。Autoは従来の最新区間観察です。Normalは指定エッジの交差を取得サンプルごとに検出し、前20%・後80%の完全な整数区間だけを更新します。トリガー待機中は最後の捕捉値を明示して保持し、まだ捕捉していないときは波形を代用しません。Normal／SingleでFree runを選ぶと次回の取得にはRising edgeを設定します。

Singleは最初の有効区間を捕捉して共通入力を自動停止します。**Start single capture** またはStartで新しい世代を開始し、一回取得を待ち直せます。Scopeの区間は専用バッファで保持するため、UI更新の合間の単発現象も捕捉し、共有履歴の周回後も失いません。Spectrumは独立しているため、Singleが短く終了した場合はFFT窓が未充填になることがあります。

**Autoset** は選択したトリガーCHの直近最大200 msの生サンプルから安定した周期・振幅を評価し、約3周期の観察幅、トリガー入力を割り当てたCHのFS振幅軸、立ち上がり・中央レベルを設定します。DC・無信号・低振幅・クリップ・不安定な周期・欠落・存在しないCHでは設定を変えず理由を表示します。Normal／Singleの停止中は捕捉条件を固定し、時間軸・トリガーの変更を次回Startへ適用します。

### Spectrumの測定定義

Spectrumは単一グラフに最大4本を重ねます。下部CH1〜CH4はScopeと同色で、クリックによる選択とチェックによる表示ON/OFFは独立しています。既定はCH1のみON、入力割当はCH1〜4です。右側Measurement / Input sourceで各トレースへ1〜16chの入力を割り当てます。入力のないCHはNo inputとして区別します。選択CHのピーク・カーソル・PSD帯域・ESD窓エネルギーを読み出し、JSON／CSV／PNGも選択トレースを対象にします。異なる校正単位を重ねた場合はMixed level referencesを表示し、CHバーに各単位を示します。

右側はFFT／Frequency・Scale／Measurement／Averagingの順に並びます。全CHで点数・窓・平均条件と表示軸を共有します。FsとΔf、取得結果のFFT条件・平均窓数はグラフ付近に表示します。Frequency / Scaleで上下限、Linear／Log、レベル軸Auto／Manualを設定でき、上限はNyquist以下に制限します。Autoは表示ONのCHの表示帯域を共通範囲へ収めます。MeasurementのPeak markersは表示ONの各CHの最大ビンを示します。測定量・窓関数・FFTサイズはFFT、精度・Live／Continuous／LatestはAdvanced analysis / diagnostics、ピーク保持はFrequency / Scaleで設定します。

AveragingのON/OFF、Weight 4／16／64、Reset averagingを使えます。進捗は有限回数の完了ではなくEMAの整定目安で、処理窓数とαを併記します。OFFにしたCHへの転送・FFTは停止し、他CHの平均は継続します。再ONはそのCHの新しい完全窓から始めます。FFT条件・入力条件変更とReset averagingは平均をリセットします。入力停止後の表示変更は取得済み結果を再描画し、解析条件変更は次回Startへ予約します。

524,288点は実入力の窓長です。48 kHzではΔf ≈ 0.091553 Hz、周期HannのRBW ≈ 0.137329 Hz、窓時間 ≈ 10.9227秒、ContinuousのN/4 hop ≈ 2.7307秒です。開始・解析条件変更・欠落後は完全な窓の充填を待ち、未取得分をゼロで代用しません。Liveの高速観察でも完全窓の充填時間と窓時間は変わりません。Latestの100 ms観察では隣接窓が約99.1%重なります。同じEMA αでも解析間隔が変われば秒単位の応答が変わります。BIN幅・RBW・周波数読み値の精度・入力時計の誤差は区別します。Spectrogramは独立した1,024〜32,768点の上限を維持します。

未校正のSpectrumの既定モード **Bin amplitude** は片側ビン振幅のdBFSです。窓のcoherent gainを補正し、ビン中心の1 FS peak正弦波を0 dBFSとします。DCとNyquistのビンは2倍しません。振幅ビンを積算して雑音電力とは扱いません。**Δf** はFs/N、**RBW** は窓の等価雑音帯域です。48 kHz・8,192点・HannではΔf ≈ 5.86 Hz、RBW ≈ 8.79 Hz、窓時間 ≈ 170.7 ms。ピークは最大ビンの値なので、1 kHzの信号が1002.0 Hzのビンに表示される場合があります。

ビンの間にある信号は複数のビンに分散するため、ピークの読み値が実振幅より低くなることがあります。

**Power spectral density** は片側PSDをFS²/Hzで測定し、表示は10 log10(PSD / 1 FS²/Hz)の **dB re FS²/Hz** です。周期窓w、正規化前のFFTをXとすると、PSDは`c × |X|² / (Fs × Σw²)`です。cはDC／Nyquistで1、その他で2です。Remove DCは窓を掛ける前に各窓の算術平均を引きます。振幅からPSDへ切り替えると平均・保持をリセットします。Spectrogramの振幅表示は変更しません。

**Transient (ESD)**（過渡信号・エネルギースペクトル密度）は、打撃・インパルス・減衰振動を一つのFFT窓に完全に収めて解析するモードです。同じ窓付きFFTを使い、`ESD[k] = c × |X[k]|² / Fs²`とします。PSDの窓エネルギー補正を適用しません。未校正はFS²·s/Hz、電圧校正時はV²·s/Hzです。既存の縦軸は`10 log10(ESD / 1 単位²·s/Hz)`のdB表示を共用し、カーソル・JSON／CSVにはf64線形密度も保持します。**Window energy** は全ビンの`ΣESD[k] × Δf`で、FS²·sまたはV²·sを表示します。負荷抵抗を使ったJへの換算ではありません。

ESDへの切り替え時は **Rectangular / Average OFF / Remove DC OFF** を設定します。その後の手動変更・保存復元は維持します。矩形窓では全帯域エネルギーが`Σx[n]² / Fs`に一致し、完全に含まれた単発パルスは窓長を変えても同じ周波数で同じ密度になります。Hann等では`Σ(w[n]x[n])² / Fs`となり、信号の窓内位置に応じてエネルギーが減衰します。DC除去も信号のエネルギーを変えるため、意図した場合だけ有効にしてください。定常ホワイトノイズのPSDは窓長に対し平均的に一定、矩形窓のESDは窓時間N/Fsに比例します。平均をONにすると窓エネルギーのEMAであり、複数打撃の累積エネルギーにはなりません。

ESDでも取得は既存のLive／Continuous／Latestです。シングルショット・トリガー連携は未実装で、過渡捕捉を保証しません。Live／Latestは途中の窓を観察しない場合があります。窓の全長と実際のサンプル区間を確認し、入力停止後は保持したESDを読み出せます。

PSDの **Power in band** は、From〜Toの両端を含む中心周波数のビンを選び、`ΣPSD[k] × Δf`をf64で計算します。To = 0は取得時のNyquistです。実際に含めた最初／最後のビン周波数、電力FS²、平方根のRMS FSを表示します。電力とRMSは微小値も読める指数表記を使います。DC／Nyquistも全Δfの重みで含めます。半端なビンの補間や台形積分は使いません。範囲が不正、範囲内にビンがない、完全なPSD窓がない場合は利用不可とし、別範囲の値を代用しません。帯域指定と表示Spanは独立し、帯域を変えても平均はリセットしません。

単一窓の全帯域積算はParsevalにより`Σw²(x−μ)² / Σw²`に一致します（DC除去なしはμ = 0）。Rectangularでは生サンプルの平均二乗、他の窓では窓付きの平均二乗です。定常正弦波・雑音の電力評価と短い過渡の窓位置依存を区別し、Scopeの観察区間のRMSと常に同一とは扱いません。ビン間正弦波では漏れを含む十分な帯域を選んで評価します。dBm・負荷インピーダンス換算は未実装です。

Spectrumの校正CHは、振幅を物理単位peak、PSDを単位²/Hz、帯域積算を単位²とRMS単位で読み出します。dB表示はそれぞれ `20 log10(振幅 / 1 単位peak)`、`10 log10(PSD / 1 単位²/Hz)` です。たとえばVでは **dB re 1 V peak** と **dB re 1 V²/Hz** を使い、未校正CHは従来のdBFS／FS²/Hzを維持します。負のゲインも電力へ正しく反映します。Remove DCなしでは `y = gain × x + offset` を窓掛け前に計算し、校正したDCが窓によって隣接ビンへ広がることも含みます。Remove DCありでは `gain × (x − mean(x))` をf64で計算し、オフセットを相殺してから窓掛け・任意のf32変換を行います。全帯域PSD積算は校正した信号の窓付き平均二乗に対応します。Spectrumワーカーの入力、校正値、FFT電力が非有限なら **Invalid FFT window** とし、平均と保持をリセットして次の有効な完全窓から回復します。この無効窓数と入力欠落数を別に表示します。

平均は **EMA α = 1/指定値** による指数的な線形電力平均です。最初の完全窓で初期化し、次の窓から`P ← P + α(Pnew − P)`を適用します。α = 1では最新窓だけを使います。処理窓数と最初〜最新の寄与区間を結果に保持しますが、均等な積算回数や区間全体の一様なRMSを意味しません。Live（既定）は全サイズでN/4の進行を要求せず、最大60回/秒の最新窓観察です。解析総時間の2倍と16.67 msの大きい方を周期の下限にし、遅い処理では直ちに延長、回復時は徐々に短縮します。対象は新しい終端の完全窓だけで、描画回数や表示の開閉に依存しません。ContinuousはN/4の全完全窓を処理します。Liveと省負荷のLatestは観察時点の最新窓だけを使い、過渡の捕捉を保証しません。Latestの32,768点以下は33 ms以上かつN/4以上、新4サイズは100 msでN/4の制限を外します。カーソルの説明で最新窓・寄与区間・CH・設定・入力世代・欠落を確認できます。

ピーク保持は平均後の各ビンの最大値を保持します。有効化またはClear holdで現在のスペクトルから保持を始めます。入力・FFT設定・測定モード・入力CHの変更やデータ欠落で平均と保持をリセットします。取得停止中の解析設定変更は次回開始に適用し、保持値のモード・単位・設定を変えません。停止中の表示・帯域変更では同じサンプルを繰り返し平均しません。

数値電力・保持値・帯域積算・カーソル／ピークはf64で保持・読み出し、描画用のf32 dB配列から逆算しません。描画には−180 dBの下限がありますが、数値は下限で切り詰めません。電力0は数値上−∞ dBです。32-bit FFTは入力のDC除去後にf32へ変換し、複素結果の二乗と平均はf64で行います。f32 FFT自体の丸めや混在する強弱信号の制限は残り、微小信号の既定は64-bitです。

スペクトログラムは専用ワーカーの連続STFTを表示し、新しい行が上に来ます。縦軸は表示上端からの相対秒、見出しのEndは入力開始からの表示上端の秒です。Liveは描画途中の先端を枠の上に隠すため、1行間隔＋約250 ms遅らせた位置を表示します。上端は公称Fsと経過時間で進み、画像の更新間隔やFPSによらず一定の速度でスクロールします。表示の待ち時間を超える遅延では未到着の区間を空白のまま残します。Holdはその時点の表示位置を固定し、入力停止中のLiveは最新窓の終端に揃えます。各行の位置はサンプル番号とFsから計算し、1行は取得時のhop区間に対応します。**Analysis / FFT Overlap** は50／75／87.5%（hop = N/2／N/4／N/8）で、既定は75%です。窓時間N/Fs・行間隔hop/Fs・ビン間隔Fs/Nは別です。Overlapを増やすと解析回数と履歴生成量が増え、容量内で保持できる秒数は短くなります。取得中の変更では旧行・Hold・履歴連携を解除して新世代の完全窓を待ち、停止中の編集は次回Start用です。SpectrumのContinuousのN/4は変えません。各窓のビン振幅を表示し、電力平均とピーク保持は使いません。欠落によって解析できなかった区間はオレンジの縞、まだ取得・保持していない過去は空白です。

配色の初期設定は **Viridis、−120〜0 dBFS、Auto OFF** です。保存済みの配色・表示レンジ・Autoは維持し、配色の項目がない旧設定は従来のBlueで復元します。暗騒音・微弱成分を見るときは、配色を切り替える前にMin／Maxで表示レンジを絞ってください。[説明書の配色比較図](../../docs-rust/quickstart.md#時間周波数の変化を読む)では−110〜−80 dBFSも使っています。ノイズ床付近の成分は、配色だけで確実に判別できるわけではありません。

右側の **Display** で色・Min／Max・**Auto color range**・Log／Linear・周波数範囲・Time Rangeを編集し、**Analysis** でFFTを設定します。Autoは表示中の時間・周波数範囲にある有効なビンからレンジを求め、無音・非有限値・欠落を除外します。有効なデータが不足する場合は最後の有効レンジ、未確定なら−120〜0 dBFSを使います。手動のMin／Max編集でAutoを解除し、不正な範囲では直前の有効値を保持します。画像と右端のカラーバーは同じ色定義です。

プロット内のホイールはポインターの周波数を中心にズームし、背景の横ドラッグは周波数をパンします。背景の縦ドラッグ、Shift＋ホイール、時間軸上のホイールは過去の履歴へ移動し、LiveからHoldへ入ります。カーソル線付近からのドラッグはカーソル移動を優先します。ダブルクリックはLinearの0〜Nyquist／Logの20 Hz〜Nyquistと現在モードの最新端へ戻し、Time RangeとLive／Holdを保持します。表示操作はSTFT設定・世代・履歴値を変えません。

**Hold**は表示中の履歴を固定し、入力・STFT・最新履歴の更新を続けます。保持中に取得したデータは混ぜず、固定した保持範囲を閲覧できます。**Live**でHoldと時間A／Bを解放して最新へ戻ります。共通入力のSTOPPEDと表示のHoldは別の状態です。入力停止中のLiveは停止時の最新履歴を表示し、入力を開始しません。

数値履歴は独立ワーカーでf64線形スペクトルと実サンプル区間を120秒・96 MiBまで保持し、UIの更新・受信が止まっても回収を続けます。表示準備は別ワーカーで行い、可視範囲を最大512行・1,024列へ縮約します。細いピークを残し、縮約行に欠落があれば縞を併記します。画素は表示用で、ホバー・カーソルは元のf64フレームを検索します。Time Rangeは表示幅であり、実際に保持できている秒数とは別です。不足した時間を補完しません。情報欄とPerformanceで保持秒数・容量制限を確認できます。

非表示でもSTFTの履歴を更新し、再表示時に保持範囲を描画します。停止後は遅着結果を除外して履歴を保持し、既にHoldしている表示も維持します。時間・周波数・色範囲は停止中も変更でき、解析CH・窓長などの変更は次の入力開始時に適用します。入力再開・入力切り替え、取得中の解析条件変更で旧履歴・Hold・時間選択を解除します。Holdの実データ・過去への表示位置・実行中の時間選択は設定に保存しません。

Spectrogramの **Analysis** で **Cepstrogram** を選ぶと、同じ1ch・窓長・窓・DC除去・Overlapを使った実ケプストラムへ切り替わります。前段FFT・対数・逆FFTはf64固定で、Spectrogramのf32選択は保持します。相対対数下限は既定−160 dB、整数−300〜−60 dBです。窓利得で正規化した両側相当の振幅へ相対下限を適用し、自然対数の逆FFTを1/N正規化します。数値履歴は符号付きの`c[q]`を保持し、色は`20(log10(abs(c)) + log10(2))`、**Cepstral power (dB re 1)**です。FS²・音響パワー・dBFSとは異なります。Praat互換は保証しません。

横軸は線形の **Quefrency (ms)** で、格子は公称Fsによる`1/Fs`、表示範囲は`1/Fs〜N/(2Fs)`です。0番目は数値として保持し、プロットとAutoから除外します。要求範囲の初期値は0〜20 msで、窓長・Fsに応じた実表示範囲を別に示します。両モードの軸・色・Autoは独立保存し、時間幅だけを共有します。Cepstrogramの初期色はViridis・Auto ON、未確定時は−80〜0 dB re 1です。負の係数も有効で、縮約は絶対値のピークを残します。全ビン0は **No signal** の中立色、非有限窓と欠落は縞、未取得は空白です。対数下限で置き換えたビン数と設定値を詳細欄に示します。

時間A／B・Hold・Live・履歴閲覧は共通です。クリックすると時間と専用のケフレンシーA／Bを配置し、最寄りq・ms・符号付きc・dB re 1・Δτを読みます。Spectrumの周波数カーソルは動かしません。Cepstrogramから履歴Spectrumへは連動できず、隣への通常Spectrum配置は可能です。停止中のモード予約では保持中のタイトル・軸・単位を維持し、次回Startで適用します。実行中の解析条件変更は旧履歴・この履歴由来の選択を解除して新しい完全窓を待ちます。未校正FS・公称Fsを使い、ピッチや反射経路の自動判定、同期2ch遅延の代用、結果JSON／CSV／PNG出力は行いません。

XY / Lissajousは共通履歴の同じフレームから、X/Yへ割り当てたCHを時間順に接続します。既定はX = CH 1、Y = CH 2で、全入力CHから独立に選択できます。独立した観察窓と振幅範囲を使い、ScopeのCH割当や表示切り替えに影響されません。Freeは最新区間を表示し、Trace SnapはScopeと共通のトリガーソース・エッジ・閾値で区間を選びます。正方形の8 × 8分割プロットで両軸を同じスケールにすると、同振幅・90度位相差の正弦波が円になります。同相は右上がり、逆相は右下がりの直線です。モノラルまたは割当先CHが存在しない場合は無効にして理由を表示します。

XYの残像保持は未実装です。保持範囲内の実サンプル組を使い、欠落の前後を接続しません。描画量は最大32,768フレーム分／32,767線分に制限し、超える場合は間引かず最新の最大点数分を表示します。欠落位置も時間幅に含みます。XY下部の時間幅・サンプル区間（終端は含まない）と`point limit`で実際の範囲を確認できます。停止中も観察窓・振幅範囲を変更でき、設定や入力に変更がなければXYの線分生成・GPU線分転送を省略します。

Scopeで置いた時間カーソルA/Bは、プロット内のX位置を保持します。入力の更新・循環履歴の折り返し・時間幅の変更・画面サイズの変更でも同じ横位置に残り、各スイープの最寄り実サンプルから振幅・トリガー基準の時刻・Δtを読み直します。時間幅を変更すると時刻とΔtも変わります。Scopeを非表示にしても現在のスイープに対応するサンプルを他の測定器と共有します。取得不足でスイープがない間はカーソル線を残して待機を表示し、カーソル位置が欠落しているときは生サンプルが利用できないことを表示します。古いサンプルは代用しません。

SpectrogramをクリックするとHoldへ入り、時間カーソルA／Bがその時点の実フレームへ固定されます。ダブルクリックと区別してから選択するため、単クリックの反映には短い判定待ちがあります。カーソルは整数サンプル・元のf64スペクトルと窓区間（終端は含まない）を保持し、履歴周回・表示幅の変更・パンで別のフレームへ置き換わりません。画面外でも選択と読み値を保持し、線は表示範囲内だけに描画します。欠落・未取得では理由を表示し、隣のFFT窓の値を代用しません。Live復帰・Clear cursors・入力再開で時間選択を解除します。Spectrogramから **Split view with… / Spectrum** を選ぶとHoldへ入り、時間A／Bの最大2本を元のf64値で重ねます。取得時刻、窓区間、CH、Fs、窓・精度、Δtを表示し、**Time A／Time B** でピーク・周波数カーソルの対象を選びます。時間選択と **Place frequency cursor: A / B** は独立し、**Clear frequency** は時間選択を消しません。未選択・欠落・無効窓には理由を表示します。

XYの**Free**ではクリックした位置のX・Y振幅を保持し、軌跡の更新に追従しません。A/BのX・Y値、B−AのΔX・ΔYを表示します。振幅スケールを変えると同じFS値に対応する画面位置へ移動し、範囲外の点はその旨を表示します。自由配置の点は時間サンプルを選びません。

**Trace Snap**では最も近い実サンプル組を選び、XYスイープのトリガー位置（観察窓の20%）からの整数サンプル差を保持します。重なる点は最新サンプルを選びます。各更新で同じトリガー基準の時間差にある割当先X/YのCHを読み直すため、周期信号をトリガーできている間は位置が安定します。実際の交差をオレンジの`T`で示し、`Triggered`を表示します。交差が見つからない場合は最新区間を使う`Auto (no crossing)`、フリーランの場合は`Free run (moving reference)`となり、マーカーが動く場合があります。Stopで取得を止めるとその区間と読み値を保持します。観察窓を短くして選択時刻が範囲外になった場合は実サンプルを代用しません。

FreeとTrace SnapはXYの右側詳細欄の **Cursors**（狭幅では **Details / Cursors**）で切り替えられます。自由配置の点と共通時間カーソルは別に保持し、切り替えて戻すとそれぞれの選択を再利用します。Clear cursors、入力再開、ソース変更では両方を解除します。ScopeとTrace Snapの実振幅は同じ共通履歴から読みます。XYのトリガー区間は独自の観察時間幅で選ぶため、Scopeの区間と同じ交差になるとは限りません。Scope・Spectrogram・Trace Snapは現在解決した整数サンプルを他の測定器と共有し、範囲外では理由を表示します。STFTの履歴だけが残って生サンプルがない場合は、Scope／Trace Snapの値を読み出せません。

周波数カーソルはSpectrumとSpectrogramで共有します。各測定器が自身のFFTサイズ・Fsから最寄りビンを選ぶため、設定が異なる場合はビン周波数も異なります。Spectrumは表示中の電力平均と最新の寄与窓を読み、任意の時間カーソル位置でFFTを再実行しません。カーソルが最新窓の内側か外側かはSpectrum上の説明で確認できます。Spectrogramは時間カーソルに対応する行を読み、時間カーソルがない場合は最新行を読みます。

上部のStopは全測定器の共通入力履歴・解析済みSpectrum・取り込み済みSTFT画像を保持します。Stopは有限の入力終端を固定し、SpectrumとLock-inの処理完了まで停止処理中の状態を表示します。UIは待機中も操作でき、Continuousは終端までの全完全窓、Latestは最後の完全窓を一度だけ処理します。停止中は遅着STFTを除外し、同じサンプルを再平均しません。表示範囲・色・配置・カーソルは変更でき、Scope／XYのCH割当、FFTの解析設定とデモ信号の変更は次回開始時に適用します。再開・入力ソース／デバイスの切り替えでは履歴とカーソルを無効化します。操作がない停止中は連続再描画せず、表示寸法が変わらないカーソル移動ではGPUの波形・テクスチャ・表示寸法を転送し直しません。

履歴SpectrumはBin amplitude・未校正FS／dBFS・平均なしの読み取り専用表示です。通常Spectrumの設定・校正・CH表示・平均・保持とワーカーを維持し、再FFTしません。**Normal Spectrum**、SpectrogramのLive、PairのUndo、単独表示への移動・対象区画の除去、入力再開・解析世代変更で通常表示へ戻ります。同じコンソールの **Time A/B from Spectrogram** で再接続できます。他のPairや既存配置を開くだけでは履歴に切り替えません。履歴SpectrumのJSON／CSV／PNGは対象外なので通常の複合出力を無効化し、File内の **held Scope** 出力は維持します。Scopeのみの結果では既存形式のSpectrumをUnavailableとし、通常Spectrumや履歴の数値を書き出しません。

### 保持結果の書き出し

**Stop** の解析完了を待ち、上部 **File / Export results JSON… / CSV… / PNG…** で保存先を選べます。従来のパス指定は、**File / File paths & status… / HELD MEASUREMENT RESULTS** で保存先を確認して **Export held results** を押します。入力開始前、取得中、StopやScopeの条件更新・設定復元が未完了の間は書き出せません。書き出し後は同じ場所に成功・失敗を表示し、下部の保存通知 から開けます。既定の保存先は設定ファイルと同じディレクトリの `measurement-results.json` です。ファイルは同じディレクトリの一時ファイルへの書き込みと同期後に置換し、失敗時は以前のファイルを残します。

結果の形式は `format = measurelab-results`、`version = 7` のJSONです。旧版1〜6の読み込みを維持します。復元用の測定設定JSONとは別の形式で、**File / Load reference result…** から参照として読み込み、**Compare saved reference** で現在の保持結果と並べて確認できます。入力世代・取得時のデバイスID／名前／入力形式・実際に選ばれた公称Fs・CH数を保持し、次回用の入力選択や解析設定・校正で保持結果を再ラベルしません。CH IDは0始まり、サンプル区間は開始を含み終端を含みません。サンプル時計は公称値です。

Scopeは書き出し時に表示する整数区間・観察サンプル数・トリガー条件・補間した横位置と、2本の割当CHの生f64サンプル（FS）、生統計・校正後の統計を保持します。配列の位置 `i` は `sample_range.start + i` に対応し、欠落位置は `null`、存在しないCHは配列全体を `null` として状態を付けます。未取得・欠落・非有限の校正結果を正常なゼロと扱いません。校正はID・版・ゲイン・オフセット・単位・参照条件を含み、物理量は `gain × raw_fs + offset` から再現できます。Autoの停止後の観察幅・トリガー変更は保持サンプルから新しい区間を選ぶため、書き出すScope区間・条件もその選択に対応します。Normal／Singleの捕捉区間・トリガー条件は停止後も固定し、編集は次回Startに適用します。

Spectrumは独立した最新FFT区間・解析設定・モード・観察間隔・Δf・RBW・校正・EMA係数／処理窓数／寄与区間・ピーク保持の対象スペクトル数／寄与区間を含みます。全ビンのf64線形値と保持値を保存し、配列の位置 `k` の周波数は `k × bin_width_hz` です。DCとNyquistを含み、振幅は平均したビン電力の平方根（単位peak）、PSDは平均した密度（単位²/Hz）、ESDは平均したエネルギー密度（単位²·s/Hz、`quantity: esd`）です。表示用f32のdB値・表示下限へ変換せず、真のゼロは線形値0のまま保存します。PSDの指定帯域は書き出し時の範囲と両端を含む対象ビン・電力・RMSを保持します。帯域が不正・ビンを含まない場合や振幅／ESDモードではPSD帯域結果は `null` です。ESDの窓エネルギーは全線形ビンとΔfから再現できます。未取得／非有限のSpectrumは状態を付け、ビン・平均・保持・帯域の値を `null` とします。

取得時に有効化したLock-inは、X/Y・R（peak）・REFに対する進み位相・Gain、REF周波数／生AC RMS／正弦波適合率／校正後peak、τ・積分窓・追従設定・閾値、両CHの校正と単位を含みます。平均の寄与区間と最新完全窓は独立した整数区間です。整定中の値にはSettling状態を付け、未充填・REF喪失・欠落・非有限では数値を `null` とし、旧値を保存しません。停止中の次回用CH・Fs・校正・フィルター変更は保持結果を変更しません。保存・参照読み込みでは単位・状態・完全窓数・整定時間・区間・REF診断・X/Y/R/位相の整合を検証します。Lock-inを含まない旧版1の結果JSONも読み込めます。

ScopeとSpectrumの区間は同時刻とは限らず、EMAとピーク保持の寄与区間は一様な重みや連続的な捕捉を示しません。取得欠落、Scope区間内の欠落、Spectrum入力欠落／無効窓／非有限窓／観察省略、ワーカー開始以来の表示スナップショット省略、入力失敗を分けます。外部Generatorの観測履歴は入力区間に対応する内部接続用の`generator_output`と分け、`external_output`へ保存します。Spectrogram、XY、カーソル、全CHの長時間記録やSpectrum窓の全生入力は含めません。書き出し用データは固定の上限を持つ保持区間とFFT全ビンから一度だけコピーし、JSON化・ファイルI/Oは専用ワーカーで行います。書き込み中に入力を再開しても書き出し対象は変わりません。

参照結果は一件・128 MiB以下に制限します。版・配列長・CH・単位・校正・整数区間・有限値・欠落・Spectrum状態の整合を全体検証し、不正ファイルを一部だけ適用しません。読み込みは取得を開始せず、現在の保持結果を上書きしません。**Keep held result as reference** で現在の結果を参照へ固定することもできます。比較画面はScope生FS波形と統計、Spectrum線形ビンとPSD帯域・条件を併記します。Scopeの統計差は同じCH・単位、PSD帯域差は同じFs・CH・単位・解析設定・モード・対象ビンの場合だけ表示します。独立記録のサンプル時計を同期した波形差として扱いません。

CSVは条件を含む `metadata_json` 行に続き、Scopeの整数サンプル番号・公称秒・生f64・校正値・単位・欠落、Spectrumのビン番号・周波数・線形値・保持値を出力します。PNGは1600×1160の独立したレポートで、主要統計・CH・単位・区間・FFT／窓／EMA・校正・欠落を付けます。PNG内にも数値配列を除いた条件を埋め込みます。精密な数値の正本はJSON／CSVです。

Lock-inを含むCSVには `lockin` 行を追加し、整数区間・CH・完全窓数・欠落数・f64のX/Y/R/位相/Gain・REF診断値・単位・状態を出力します。無効値は空欄です。参照比較ではLock-inの取得条件・状態・校正版と数値を左右に表示し、両結果がValidで、公称Fs・CH・REF／フィルター設定・両CHの校正が一致し、入力失敗がない場合だけX/Y/R/Gainと位相の差を表示します。位相差は±180°へ折り返します。独立記録の入力時計は同期しません。PNGの描画対象はScope／Spectrumです。

## 現在の取得・解析・描画の構成

取得・共通履歴・Scope統計は専用測定ワーカー、FFT・Lock-in・同期比較・STFTはそれぞれ独立ワーカー、デバイス管理・ファイルI/Oは非UIの担当で実行します。UIは結果受信と描画を行い、非表示や受信停止で測定・生成を止めません。

```text
CPAL callback → 固定容量SPSC → 測定ワーカー ← Software Loopback / Generator内部接続
                               ├→ 共通f64履歴 / Scope捕捉・統計
                               ├→ 選択CH → Spectrumワーカー
                               ├→ 同期2ch → Lock-in / Comparisonワーカー
                               └→ 選択CH → STFTワーカー → 固定容量行プール
各結果 → 世代・整数区間・条件付きスナップショット → UI / 非同期保存
STFT行（f64線形値） → 履歴収集ワーカー → 不変フレーム公開
  → 表示準備ワーカー（有界要求・縮約・Auto） → GPUラスタ
                                         → UI描画キャッシュ → 循環GPUテクスチャ
```

各転送・履歴・結果プールは固定容量です。入力・解析の欠落を結果へ伝え、表示更新・STFT表示行の省略と分けます。Stopは有限の入力終端まで処理して保持し、旧世代・遅着結果を除外します。具体的な容量と境界は下記の各モジュールとテストを参照してください。

高密度の波形・Spectrumは物理ピクセルごとの極値を保ち、細いピークを残します。Scope／Spectrum／XYと同期比較の横軸ラベルは文字幅と表示幅に応じて間引き、目盛線とデータの位置は維持します。WGSLで線分を展開し、STFTは変更行だけを循環テクスチャへ転送します。数値測定は表示集約・描画用f32から逆算しません。停止中は連続再描画と不要なGPU転送を省略します。

通常はVSync、`--low-latency`で無効化します。PerformanceのUI fpsはUI更新頻度、Scope prep／Worker FFT／Spectrum prepはCPU処理時間で、GPU実行・実表示の遅延ではありません。残る評価は [PLAN](PLAN.md#継続する制限) に保持します。

## 同期2chの比較

計器一覧の **Synchronous 2ch** で単独表示します。**Split view with… / Scope** で波形と並べます。本体で異なるREF／SIG CHを指定し、**Start analysis** と **Start input** をそれぞれ開始します。入力は同じデバイスの同期フレームで、外部信号でも測定できます。既定N=4,096、平均8窓では48 kHzで初回に約0.683秒必要です。

ゲイン・進み位相・コヒーレンスの曲線を表示し、**Read at** またはグラフのクリックで最寄りビンを選びます。主要数値を独立した読出しに表示し、選択した実ビンの周波数と有効transferビン数を示します。**Display range**は**Around reading**（既定）／**Valid band**／**Full / Nyquist**／**Custom**、軸は**Linear Hz / Log Hz**を選べます。Log HzはDCを除きます。範囲は表示だけを変更し、解析条件・位相傾斜の帯域・保存結果を変更しません。欠損ビンや位相の折返しを曲線でつなぎません。生REFのPSD下限、平均窓数、窓、コヒーレンス下限、位相傾斜の帯域は選択中の詳細欄で設定します。曲線のゲインは20 log10(|H1| / 1ゲイン単位)で−60〜+20 dBの表示範囲に制限しますが、数値・保存値は制限しません。低REF・低コヒーレンス・未充填・欠落では「—」を表示し、ゼロで置き換えません。正の位相はSIGの進み、正の遅延はSIGの遅れです。

曲線は実際の傾きのまま表示枠で切り、Customの端では隣接ビン間の線も枠まで描画します。密集したビンは線で表示し、疎なビン・孤立したビンと選択ビンには丸印を残します。

位相遅延は1/fの周期で曖昧です。位相傾斜は帯域内の最長の連続励振区間を使い、コヒーレンスとREF PSD（最大の10%以上）が有効な8ビン以上を必要とします。正弦波1本から広帯域遅延を表示しません。直線回帰の使用帯域と残差RMSを併記し、隣接位相差がπ未満という仮定と、CH間位相・時間校正が未確認であることを保持します。

非表示でも解析は続きます。Stop後は最後の完全平均を保持し、停止中の解析・CH変更は次回Start用です。**File**から条件付きJSON／CSVを保存・読み戻して参照と比較できます。外部出力の観測履歴を含む結果は励振と入力窓の対応が未校正なので、両方の値を示して数値差を抑止します。AC比較・平均・単位・符号の定義は [同期比較設計](COMPARISON_DESIGN.md) を参照してください。

- `src/audio.rs`: CPALデバイス管理、入力コールバック、SPSC転送。

- `src/settings.rs` / `src/settings/preferences.rs`: 版付き測定設定・校正と表示設定のJSON、デバイスID照合、容量制限付き読み込み・原子的保存。起動設定はOS標準パスと専用I/Oワーカーを使い、`src/app/preferences.rs`で自動保存・停止中復元を扱う。

- `src/acquisition.rs`: サンプル時計のNormal／Single捕捉とAutoset。
- `src/comparison.rs` / `src/comparison_worker.rs` / `src/app/comparison_panel.rs`: 同期2chの自己／クロスPSD、H1、位相・遅延、専用ワーカーと表示。
- `src/loopback.rs` / `src/lockin.rs` / `src/lockin_worker.rs`: 通常ビルドの仮想DUTと実験段階の同期REF Lock-in、固定容量の独立演算。
- `src/generator.rs` / `src/generator/control.rs`: GUI非依存の最大16カード・4波形コア、滑らかな設定変更、固定容量の制御・優先Stop。
- `src/output.rs` / `src/app/generator_panel.rs`: 内部生成ワーカー、出力条件付き共通入力、Generator GUI。`src/app/io_panel.rs`は入力元と出力デバイス・形式を一画面で扱うI/O設定。信号ごとのOUT割当はGeneratorカードで行う。`src/output/device.rs` / `runtime.rs`は通常CPAL出力・PCM変換・非UIデバイス管理。`src/output/history.rs`は独立時計の外部出力観測履歴と保持時の固定。
- `src/app/lockin_panel.rs`: Lock-inのR／θ・X／Y・4値表示、参照状態・整定・保持、測定条件の操作と表示専用のバー。
- `src/export.rs` / `src/file_io.rs`: 保持したScope／Spectrumと測定条件の版付きJSON、欠落・無効状態とf64線形値、専用I/Oワーカー、設定保存と共有する原子的ファイル置換。
- `src/calibration.rs`: ID・版・参照条件付きのCH校正、Scope実サンプルの換算・RMS／Peak／P-P、非有限値の無効化。
- `src/measurement.rs`: GUI非依存の入力消費・共通履歴・デモ・Scope統計・解析への供給、入力世代・欠落付きの容量固定スナップショット。
- `src/signal.rs`: 固定容量履歴、トリガー、集約、測定。
- `src/cursor.rs`: 入力世代付きの共通A/B時間カーソル、ScopeのX固定と履歴のサンプル固定、Δt、最寄りFFTビン。
- `src/xy.rs`: 任意の2chを同じフレームから読む軌跡、割当付きの観察区間、独立した表示範囲、描画量の上限。
