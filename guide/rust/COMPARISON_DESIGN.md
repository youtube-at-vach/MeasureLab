# 同期2ch比較の定義

更新日：2026-10-14。段階5の最初の用途は、同じ入力時計で取得したREF／SIGのゲイン・位相・遅延比較である。Generatorや描画へ依存しない。現在の確認範囲と完了判断は [PLAN](PLAN.md)、条件付きの証拠は [同期比較検証](validation/COMPARISON_2026-10.md) に保持する。

## 入力・窓・平均

入力は共通取得のf64同期フレームから任意の異なる2chを選ぶ。1〜16ch基盤を維持し、1ch入力や存在しない割当はUnavailableとする。同一CHへの割当は設定エラー。入力世代、解析版、公称Fs、CH、窓、校正と整数区間を結果へ保持する。

FFTはf64、Nは1,024／2,048／4,096／8,192／16,384、窓は既存の周期Rectangular／Hann／Blackman-Harrisを使う。各CHの窓内平均を引いてから校正ゲインと窓を適用するAC比較で、校正オフセットは相殺する。符号付き校正ゲインは複素スペクトルへ適用する。CH間位相・時間校正は未実装で、ゲイン校正があっても位相精度を保証しない。

hop=Nの重複しない連続窓をM=2〜256個の有限バッチに分け、自己／クロス電力を算術平均する。既定はN=4,096、M=8で、48 kHzの初回完全平均に約0.683秒を要する。単一窓の見かけのコヒーレンス1を測定結果として出さない。M窓が揃うまではFilling／Averagingで値を表示しない。次のバッチが揃うまで、最後の完全平均とその寄与区間を保持する。Stopの不完全な余りは補間・ゼロ埋め・再平均しない。

## 複素値・符号・無効条件

正規化前のFFTをX=REF、Y=SIG、窓をwとし、DC／Nyquistはc=1、その他はc=2とする。

```text
Pxx = mean(c × |X|² / (Fs × Σw²))
Pyy = mean(c × |Y|² / (Fs × Σw²))
Pxy = mean(c × conj(X) × Y / (Fs × Σw²))
H1  = Pxy / Pxx
γ²  = |Pxy|² / (Pxx × Pyy)
gain = |H1|
phase_lead = arg(H1)                         [−180°, +180°]
wrapped_phase_delay = −arg(H1) / (2πf)       [s]
```

複素数の実部／虚部を平均してからH1・位相・コヒーレンスを求める。H1は入力雑音が小さいと仮定する推定量で、任意の雑音条件で真の伝達関数を保証しない。定義は [SciPy CSD](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.csd.html) と [コヒーレンス](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.coherence.html) の一次資料に合わせるが、窓の重複は使わない。

正の位相はSIGがREFより進む方向、正の遅延はSIGが遅れる方向。正弦波1本の位相遅延は1/fの整数倍だけ曖昧で、絶対遅延に置き換えない。DC／Nyquistには位相遅延を付けない。ゲインの単位はSIG単位／REF単位、同単位ならratio。自己PSDは各単位²/Hz、複素クロスPSDは両単位の積/Hzである。

| 条件 | 結果 |
| --- | --- |
| 生REF PSDが設定した下限未満 | ReferenceLost。H1・位相・遅延をnullにする |
| REFがありSIGの電力が0 | ResponseLost。ゲイン0、位相・コヒーレンス・遅延はnull |
| コヒーレンスが閾値未満 | Incoherent。コヒーレンスを残し、ゲイン・位相・遅延を抑止 |
| 入力・転送の欠落 | Missing。バッチと以前の値を消し、欠落数を累計して新しい完全平均を待つ |
| 非有限入力・演算 | NonFinite。バッチと値を消し、無効数を保持する |
| CH・解析・入力世代の変更 | 新しい解析版で初期化。旧版の遅着結果を除外 |
| 内部Generatorの遷移 | 実サンプル境界で初期化し、遷移後の窓から再評価 |

REF下限は校正前のFS²/Hzで、既定1e−12。コヒーレンス下限は既定0.8。結果のValidは完全平均があることを示し、すべてのビンが有効という意味ではない。

## 位相傾斜による遅延

要求帯域内で、励振・コヒーレンスが有効な最長の連続ビン列を選ぶ。さらにREF PSDが全ビンの最大PSDの10%以上である8ビン以上を要求し、正弦波の窓漏れを広帯域の遅延へ流用しない。穴をまたいで位相を接続しない。コヒーレンスを重みにしてアンラップ位相を周波数へ直線回帰し、`delay = −slope / 2π`、使用ビンと位相残差RMSを保存する。

隣接ビンの実位相差がπ未満であることを仮定する。純遅延のアンビギュイティ範囲は±N/(2Fs)未満で、窓周期以上の遅延は識別できない。任意のフィルターの群遅延やDAC／ADCの絶対遅延とは扱わない。残差が大きい場合は純遅延モデルから外れることを読み取れるようにする。

## 実行・保存

共通取得→262,144フレーム固定容量SPSC→専用Comparisonワーカー→不変の結果→GUIという分離を使う。FFT計画・バッファ・平均は取得／音声コールバックに置かない。解析設定の要求は最新の一件へまとめ、取得側は待機しない。有限Stopは解析終端のバリアで転送を処理し、末尾欠落も無効化する。非表示・UI受信停止で解析や平均を止めない。

設定は版3、結果は版4。旧設定版1／2は比較無効・非表示、旧結果版1〜3は比較なしとして読む。JSON／CSVへ全ビンのf64自己／クロスPSD、H1、コヒーレンス、状態、符号・校正制限と各整数区間を保存する。数値参照差は、入力・解析・校正・励振条件が一致し、両結果とビンが有効で欠落／失敗がない場合に限る。外部Generator観測履歴では入力窓の励振対応が未校正なので数値差を抑止し、個別の測定値を並べる。PNGは既存のScope／Spectrumだけを対象とする。

共有するのは検証済みの窓係数と共通取得である。独立Spectrum／Lock-inの窓・更新・平均条件へ暗黙に結合しない。相互相関、汎用計算グラフ、自動FRF測定フロー、多波形の製品Generatorはこの工程に含めない。
