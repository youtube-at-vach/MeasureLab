# Lock-in結果の保存・参照比較の検証

対象：2026-10-12、`a6994f7c`上の作業差分（`codex/lockin-result-reuse`）。Rust／Cargo 1.99、macOS 14.8.9、x86_64。段階4aの内部演算とSoftware Loopbackを対象とし、外部I/O・物理REF・長時間試験の成功とは扱わない。

## 数値・ファイル境界

`src/results.rs`の数値試験では48 kHz・750 Hz、非重複1,024サンプル窓×64、絶対連番`2^54＋7`以降を使用する。REFは0.125 FS peak、応答はDC 0.1 FSと1.25e-8 FS peak・位相30°。REF校正はgain −2・offset 0.4・単位A・版3、応答校正はgain 4・offset 0.8・単位V・版7で、物理校正を代用しない。

| 照合対象 | 結果・許容差 |
| --- | --- |
| 微小応答と校正 | R=5e-8 V peakとの差<1e-15、θ=−150°との差<1e-6°、Gain=2e-7 V/Aとの差<1e-14。ACに校正オフセットを含めない |
| JSON往復 | f64値・整数区間・CH・REF診断・設定・校正ID／版／係数／単位と状態が完全一致 |
| CSV再利用 | 整定済み・整定中・REF喪失の22列を照合。全数値セルのf64往復、u64区間、単位、状態が一致。無効値は空欄 |
| 無効状態 | 未充填・連番欠落6サンプル・NaN・CH利用不可・無効化を保存／読み込み。数値と平均を破棄し、旧値やゼロを保持しない |
| 不正ファイル・保存失敗 | 単位、区間、完全窓数と乗算overflow、整定、CH、R／位相、負Gain、REF周波数／強度／適合率／peak、欠けた診断値を拒否。不正値・NaNの保存失敗で以前のファイルを維持 |
| 旧形式 | Lock-inブロックを含まない版1の結果JSONを受理 |
| 参照差 | 位相179°→−179°を+2°として照合。振幅差0.0625 FS peak・Gain差0.5との誤差<1e-12 |
| 比較の条件 | Fs・CH・τ・積分窓・Tracking・REF／応答校正が異なる結果、整定中、入力失敗、Lock-inなしでは数値差を作らない |

X/Y・R・位相は保存された値の定義を検証する。Gainは窓ごとの複素応答/REFを二段EMAで平均した値であり、Rと最新REF peakの商へ置き換えない。平均の寄与区間は完全窓数×Nに一致し、Valid／Settlingを連続有効サンプル10τの境界と照合する。

## アプリSoftware Loopback

`MEASURELAB_UI_SMOKE_STAGE3F=1`と別プロセスの`MEASURELAB_UI_SMOKE_REPLAY=1`を用いる。48 kHz・750 Hz・REF 0.125 FS peak・DUT gain 0.5・位相30°・τ 0.02秒・積分4,096サンプル・8k FFTが基準条件。R=0.0625 FS peak、θ=30°とFFT振幅を独立した理論値と照合する。

通常幅1440×860で保存・停止中の次回用CH／Fs／校正／τ変更・設定復元・参照読み込み・再測定の数値照合が通過した。別プロセス・狭幅1040×780でも前回の設定／参照JSONから再測定し、X/Y/R差<1e-8 FS peak、位相差<1e-6°、Gain差<1e-7を満たした。Singleは480サンプルで有限停止し、未充填512k FFTとLock-inに数値を作らないことを照合した。

保存した通常測定のRは0.0625000000000002 FS peak、θは30.000000000018737°、Gainは0.5000000000000007。寄与区間は`[0, 45056)`、最新完全窓は`[40960, 45056)`。CSVのX／R・状態がJSONと一致することも別のCSVパーサーで確認した。

**画面撮影QAは失敗。** 上記の数値照合後、通常幅の比較画面、狭幅の再起動後比較、比較画面なしのSoftware Loopback（caffeinateあり）、既存の通常`--ui-smoke --compact`はいずれも`UI screenshot was not received`で終了コード1になった。撮影を成功扱いせず、現行リビジョンのGUI視覚確認は未完了とする。原因は未特定。オフスクリーンGPU読み戻しの`--gpu-smoke`はMetal / AMD Radeon R9 M290Xで通過し、ネイティブ画面撮影と区別する。

ログと生成結果は`dist/lockin-results-qa/`および`dist/stage3f-*`へ分離した。撮影失敗のため今回のスクリーンショットは提供しない。各アプリ実行は約1秒の通常測定とSingle捕捉であり、長時間評価ではない。
