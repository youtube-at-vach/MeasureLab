# CHルーティングとScopeの生サンプル測定の検証

検証日：2026-10-07。対象は`0045b52ea`を基点とする`codex/channel-routing`の作業ツリー。Scopeの2本とXYのX/Yへ任意の入力CHを割り当てた状態の確認。取得・解析分離の以前の実測は [測定コアの検証](CORE_2026-10.md) と分けて扱う。

## 環境と範囲

macOS 14.8.9（23J631）、x86_64、Rust/Cargo 1.99、Metal / Intel Iris Pro Graphics 6200。内部のf64既知入力、デスクトップUI、BlackHole 16ch／2chの外部仮想I/Oを確認した。物理入力の校正や実サンプルレートの保証は含めない。

## 数値・入力ワーカー

* 16ch履歴のCH 16／CH 8へ異なるDCと1サンプルのスパイクを置き、履歴周回と欠落を含む整数区間でRMS・Peak・P-P・取得サンプル数を理論値と照合。欠落はゼロ値や観測数に含めない。
* 同一区間を2／8／1,000ピクセル、0.125／0.5 FS/divへ投影しても生サンプル統計が一致する。CHを入れ替えると測定値の順序だけが入れ替わる。実サンプル固定カーソルは選択したCHの値を読み、欠落位置のサンプルは取得できない。
* モノラルの1 ± 1e−9 FSから、f32へ丸められる2e−9 FSのP-Pをf64で保持。存在しないCH、範囲外の区間は取得数0となり、別CHを代用しない。同じCHをScopeの2本へ割り当てた場合は値が一致する。
* CH 16／CH 7の既知正弦波から、同相・逆相・90度・振幅比0.5のXYを照合。割当の入れ替え、同一フレームのTrace Snap、欠落前後の線分分離、存在しないCH、モノラルでの無効化を確認。
* 16ch取得ワーカーへビン中心正弦波を送り、CH 16のトリガー、1,024サンプルのRMS、Scope／XYの割当付きスナップショットを照合。取得中の入れ替えはSpectrumの寄与窓数を変えない。Stop後のCH変更要求は保持値と割当を変えず、次の2ch入力世代では存在しないCH 16を利用不可のまま保持する。

全ターゲット・全機能の77テストとベンチマーク実行は成功。GUIなしの74テストも成功し、1ch／2ch／16ch・最大FFT・表示受信停止・飽和・停止／再開の既存回帰試験を含む。

## GPU・UI

`--gpu-smoke`は成功。Scope・Spectrum・Spectrogram・XYの読み戻し、保持時の転送省略、Spectrogramの折り返し・欠落・Nyquistの既存確認を維持した。

`MEASURELAB_UI_SMOKE_ROUTING=1`の通常幅ではScope設定、狭幅ではXY設定を開いて画像を確認。ScopeのTrace 1 = CH 16（0.375 FS peak）、Trace 2 = CH 8（0.25 FS peak、90度位相差）、トリガーCH 16、XYのX = CH 16／Y = CH 8が表示される。ScopeのRMSはそれぞれ約0.265／0.177 FS、P-Pは0.750／0.500 FS、時間カーソルの振幅・CHラベルも同じ履歴に対応する。Spectrogramはこの撮影モードでは独立した信号を使う。

モノラルの狭幅画像ではScopeの既定Trace 2 = CH 2が利用不可となり、偽の統計や線分を表示しない。XYはモノラルの理由を表示する。

デモのライフサイクルQA（計測5秒＋起動待ち2秒）は成功。既存の保持・固定位置カーソル・Trace Snap・非表示・再開・待機中の再描画停止を確認。仮想入力のライフサイクルQA（計測12秒＋起動待ち2秒）はBlackHole 16ch→デモ→BlackHole 2chで、取得中の割当、停止中の入れ替え要求と保持、次回開始時の適用、CH数減少での利用不可、カーソル世代の無効化を確認した。両実行とも取得／STFT入力／STFT結果の欠落は0。

これらのライフサイクルQAは操作変更を含む条件であり、通常の性能基準値と比較しない。eframe処理p95はデモ5.390 ms、仮想入力5.100 msで、CPU 4 msの目安の達成とは扱わない。

## 外部仮想I/Oの既知信号

`--multichannel-smoke`はBlackHole 16ch、96 kHz、0.5秒の起動待ち、2秒の測定区間、192,512取得フレームで成功。全16chへ異なるビン中心周波数の0.125 FS peak正弦波を送り、全CHの対応・周波数・振幅とCH 16 STFT（−18.062 dBFS）を照合した。

最新8,192フレームのCH 16／CH 8と、その入れ替えでScopeとXYを確認した。RMSの期待値は0.125 / √2 FS、Peakは0.125 FS、P-Pは0.25 FS。許容差はそれぞれ1e−8／1e−5／2e−5 FSで、f32の仮想出力を含む条件。XYは両CHを同じ取得フレームから読み、Trace Snapの選択値も一致した。測定区間の取得／STFT入力／STFT結果欠落は0。起動待ちと終了時のCoreAudio underrun/overrun通知は測定区間と分ける。
