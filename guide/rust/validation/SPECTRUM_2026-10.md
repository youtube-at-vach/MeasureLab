# Spectrumの振幅・PSD・帯域電力の検証

検証日：2026-10-08。対象は`c149fc9e0`を基点とする`codex/spectrum-psd`の作業ツリー。段階3cの定義・数値検証と条件付きのデスクトップ／仮想I/O確認を保持する。以前の取得・CH割当の実測は [測定コア](CORE_2026-10.md) と [CHルーティング](ROUTING_2026-10.md) の記録に分ける。

## 環境と定義

macOS 14.8.9（23J631）、x86_64、Cargo 1.99、Metal / Intel Iris Pro Graphics 6200。入力は公称Fsと未校正のFS。内部f64の既知入力とBlackHoleのf32仮想出力を区別し、物理系の精度・校正は保証しない。

* 振幅：窓のcoherent gainで補正した片側ビン振幅。1 FS peakのビン中心正弦波を0 dBFSとし、DC／Nyquistは2倍しない。
* PSD：正規化前FFTをX、周期窓をwとし、`c × |X|² / (Fs × Σw²)` FS²/Hz。cはDC／Nyquistで1、その他で2。表示は10 log10(PSD / 1 FS²/Hz)。この正規化は [SciPyのperiodogram](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.periodogram.html) の片側化・density定義を参考にし、試験では独立した全長複素FFTと時間領域Parsevalを基準にする。
* 帯域：両端を含むビン中心を選び、PSD × Fs/Nを全ビン重みで積算する。DC／Nyquistも全Δfを使い、台形積分・部分ビン補間・振幅ビンの単純積算はしない。不正範囲・ビンなし・未取得は利用不可。
* 全帯域の単一窓：`Σw²(x−μ)² / Σw²`。μはDC除去有効時の算術平均、無効時は0。Rectangular以外は窓付き平均二乗であり、Scopeの生サンプルRMSと常に同一ではない。
* EMA：最初の完全窓で初期化し、以後α = 1/指定値で線形電力を更新する。α = 1では寄与区間は最新窓のみ。処理窓数は均等な平均回数ではない。保持は平均後のビン最大値。設定・入力・欠落で平均と保持をリセットする。
* 数値：電力・保持・帯域・ピーク／カーソルはf64。f32描画の−180 dB下限を数値へ戻さず、0電力は−∞ dB。f32 FFTの複素結果はf64へ変換してから二乗する。

## 内部数値・測定ワーカー

| 対象 | 条件・基準 | 許容差 |
| --- | --- | --- |
| FFT参照比較 | 全6サイズ（1,024〜32,768）、3窓、DC除去有／無、振幅／PSD、f64／f32。全長複素FFTと各ビンを照合 | 線形値の平方根の絶対誤差：f64 < 1e−13、f32 < 2e−7 |
| PSD Parseval | 全6サイズ・3窓・両精度・DC除去有／無。ビン間正弦波・2トーン・DC・Nyquist・単発スパイクを含む入力 | 全帯域FS²の絶対誤差：f64 < 2e−13、f32 < 5e−8 |
| 既知トーン電力 | 全6サイズ・3窓、48／96 kHz。0.5と0.25 FS peak、DC 0.125 FS、Nyquist 0.0625 FS | 個別帯域・全帯域FS² < 1e−13。トーン中心PSD < 1e−14 FS²/Hz |
| 端点・範囲 | Rectangular、DCとNyquistの各1ビン積算、全帯域、中心なし、逆順・負・Nyquist超過・NaN／∞ | FS² < 1e−14。不正値とビンなしはNone |
| 既知雑音 | 固定seedの一様白色雑音、振幅±0.2 FS、理論分散0.04/3。1,024／8,192／32,768、3窓、各32窓 | 全帯域平均電力の相対誤差 < 3%、6〜12 kHz平均密度 < 8% |
| 描画下限との分離 | 1e−12 FS peak、EMA α = 1/4、無信号への遷移、結果コピー・保持クリア・リセット | f64電力と保持を維持。帯域FS²の相対誤差 < 1e−13 |
| f32微小PSD | 1e−24 FS peak、1,024点、Hann。f32での二乗アンダーフローを回避 | 全帯域電力の相対誤差 < 2e−6 |

雑音の許容差はこの有限・固定seedの試験条件に対する値で、任意の1窓や全機器の雑音測定精度を保証しない。f32 FFTの丸め・混在する強弱信号への制限は残る。DC上の微小ACはDC除去後にf32へ変換し、既存のf64／f32回帰試験を維持する。

1ch／2ch／16ch、1,024／32,768点で振幅とPSDのN/4連続解析を照合し、スナップショット受信の省略・重複で電力・保持・処理窓数が変わらないことを確認する。入力欠落では結果を無効にし、欠落窓を数え、完全窓からEMAを初期化し直す。最大FFTのPSDでは、取得キュー容量の2倍以上に相当する表示受信停止中も入力を継続し、Stop後の振幅モードへの変更要求が保持PSD・設定・寄与区間を変えないことを確認する。

単発過渡の試験はRectangular、PSD、1,024点、hop 256、EMA α = 1。4,096サンプル中の1点の0.5 FS入力をContinuousの保持が捕捉し、最後の窓のみを読むLatestでは捕捉しないことを照合する。連続解析の過渡捕捉と、観察モードの限界を分ける。

## デスクトップ・外部仮想I/O

`--gpu-smoke`は成功。Scope・Spectrum・Spectrogram・XYの読み戻し、保持時の転送省略、STFTの折り返し・欠落・Nyquistを維持した。`MEASURELAB_SPECTRUM_PSD=1`、Spectrum設定と共通カーソルを開いた通常幅／狭幅の画像を確認し、PSD単位・全帯域電力・RMS・カーソルと4画面の配置が表示される。画像はローカルの`dist/spectrum-psd-normal.png`と`dist/spectrum-psd-compact.png`へ保存した。

内部デモのライフサイクルQA（5秒＋起動待ち2秒）は成功。PSDで開始し、Stop後に次回用の測定モードを変更しても保持窓・単位・設定を維持する。既存の固定位置カーソル・非表示／再表示・待機中の再描画停止・再開時の選択無効化も確認した。取得／STFT入力／結果の欠落は0。

仮想入力のライフサイクルQA（12秒＋起動待ち2秒）はBlackHole 16ch→デモ→BlackHole 2chで成功。PSDの保持・CH割当・入力世代の無効化と、96→48 kHzの変更を確認し、取得／STFT入力／結果欠落は0。GUIなしテストのビルドと並行する条件であり、性能比較には使わない。

BlackHole 16ch・96 kHz・解析CH 16・PSD・Hann・EMA α = 1/4・f64・FFT 32,768・4画面・VSync有効で、UIを1,000 ms停止した試験は成功。停止中に96,256フレームと11 FFT窓を処理し、取得欠落・連続Spectrum無効窓は0。全実行の表示省略は27回、STFT入力／結果欠落は0。入力は無音であり、取得・解析継続の確認と既知信号の数値照合を分ける。

`--multichannel-smoke`はBlackHole 16ch・96 kHz・8,192点・Hann・EMA α = 1、0.5秒の起動待ち後に2秒・192,512フレームで成功。全16chの異なる0.125 FS peak正弦波で、トーン±4ビンと全帯域の電力を0.0078125 FS²（絶対許容差1e−9 FS²）、中心PSDを0.0078125/RBW（許容差1e−10 FS²/Hz）と照合した。振幅・CH対応・CH 16 STFT（−18.062 dBFS）・既存Scope／XY照合も成功。測定区間の取得／STFT入力／結果欠落は0。起動待ちと終了時のCoreAudio underrun/overrun通知は、この成功範囲と分ける。

これらは機能QAの条件であり、通常の性能基準値とは比較しない。デモライフサイクル／最大FFTのUI停止／入力ライフサイクルのeframe処理p95は5.290／4.990／2.070 ms。入力ライフサイクルはFFT長や表示が変わる条件で、他の値と直接比較しない。測定とSTFTワーカーの処理時間を別に出力しており、UI CPU 4 msの目安を達成したとは扱わない。
