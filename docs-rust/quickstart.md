# クイックスタート

## ソースから起動

Rust版を含むチェックアウトとRust 1.95以降が必要です。統合先はmainへの切り替えまでは`rewrite/rust`です。macOSではXcode Command Line Tools、LinuxではALSA／X11／Waylandの開発ライブラリ、WindowsではMSVCとVisual Studio C++ Build Toolsを用意します。詳細はリポジトリの`guide/rust/SETUP.md`を参照してください。

リポジトリのルートで実行します。

```sh
cargo run --release --locked
```

macOS／Linuxのローカルセットアップ環境では`./scripts/cargo.sh run --release --locked`も使えます。通常は入力を停止した状態で起動します。

## 機器なしで最初の測定

1. **I/O / Input** で **Software Loopback** を選びます。これは通常ビルドで使え、物理出力は行いません。
2. 上部の開始ボタンで取得を開始し、**View** で **Scope + Spectrum** を選びます。
3. 各グラフの **Adjust** で時間軸・振幅、FFT・窓・CHを調整します。最初は既定の8,192点を使ってください。
4. **Stop** で結果を保持し、カーソルやRMS、ピーク、PSDの帯域値を読みます。
5. **File** から設定と保持結果を保存します。JSONは測定条件を含む正本、CSVは数値の再利用、PNGは表示の共有に使います。
6. 再起動後、停止中に設定を復元し、参照JSONを読み込んで再測定結果と比較できます。設定復元だけで取得は始まりません。

524,288点では48 kHzで完全窓の取得に約10.92秒必要です。Live表示を速くしても、この観測時間は短くなりません。ContinuousはN/4ごとの全窓を解析し、Live／Latestの最新窓観察は過渡の捕捉を保証しません。

## Generatorで正弦波を観測する

1. **View / Generator + Scope** を選びます。通常ビルドで使える2chの内部出力です。
2. **I/O / Output**で **OUT 1／2** を割り当て、中央の各GENを **ON** にして周波数（Hz）・振幅（dBFS peak）・位相（発振器に対する進み、°）を入力します。Enterまたはフォーカス移動で適用し、Escで編集を取り消します。**Adjust**から **Generator / EDIT STEP**で刻みを選び、±ボタンや上下キーでも調整できます。
3. **I/O / Output / Observe Generator** で内部出力を入力に選び、**Start output** と **Start input** をそれぞれ押します。設定プレビューと実測波形は別です。
4. **Generator + Spectrum／Lock-in** へ切り替えて解析できます。動作中の編集では振幅・位相を滑らかに遷移し、Spectrum／Lock-inは遷移後に平均・整定をやり直します。
5. **Stop input** は結果を保持し、出力は継続します。**Stop output／Stop all outputs** で出力を停止すると、取得中の入力には新しい無音サンプルが届きます。

中央はコンパクトな数値編集と設定プレビューです。広い画面は2ch横並び、狭い画面は両CHの状態を残すタブ表示になります。位相同期と適用詳細は**Adjust**から開きます。

出力Fsは**I/O / Output**で44.1／48／96／192 kHzから、入力・出力を停止して選びます。設定の復元には両方の停止が必要で、復元後も出力はOFFです。内部接続のJSON／CSV結果には受信区間に対応する出力条件を保存します。

実デバイスへ出力する場合は、停止中に**I/O / Output**でデバイスを選び、対応するFs・CH数・PCMとOUTを設定します。未割当CHは無音です。**I/O / Input**で接続先の実入力を選び、**Start output**／**Start input**を個別に開始します。**Observe Generator**は内部接続専用です。出力通知・コールバック停止はERRORとして保持し、**Reset output (stays OFF)**と明示Startで復帰します。設定は出力先・形式を保存し、復元後はOFFです。

外部入出力は別の時計で、出力遷移と入力解析窓は自動対応しません。編集後は入力側の整定を待ち、Lock-inは同期REFの実入力2chを使ってください。外部Generatorを観測した結果のJSON／CSVには、実適用設定・出力状態・失敗と最大128件の観測履歴を保存します。入力Stop／Single／失敗後の編集では履歴を変更しません。履歴と入力窓の対応は未校正として参照との数値差を表示しません。ホストで応答を観測した時刻はDAC／ADC時刻ではなく、欠落・退役した履歴も補完しません。結果形式は版4で、旧版1〜3も読み込めます。出力校正・DAC／ADC遅延は未確認です。

## 実入力を使う

入力デバイスと対応するサンプルレートを選び、**Start input** を押します。macOSでは起動したアプリ／ターミナルへのマイク許可が必要です。CH数やFsは機器に依存します。CH校正を使う場合も、Scopeの波形軸とトリガーはFSのままです。

macOSの実入出力は、起動処理やスケジューリングに余裕を持たせるため、機器の対応範囲内で約20 msの音声バッファを要求します。48 kHzで対応していれば1,024フレーム、約21.3 msです。出力編集・停止の応答はこのバッファ長にも依存します。サンプルレート・CH数・PCMの選択値や測定単位は変わりません。

停止中に入力・解析・校正を編集した場合は、次回Start用の条件です。保持中の結果の取得条件は変わりません。入力変更・再開時は古い世代の結果を混ぜず、新しい履歴を取得します。

## 実験段階のLock-in

Software LoopbackでREFと応答を用意し、Lock-in表示のREF／Signal CHを指定します。X/YとRはpeak単位、正の位相は応答の進みです。整定中・REF喪失・欠落を有効な測定値と扱わないでください。実機確認は未完了です。

Stopの解析完了後、**File** からLock-inの条件・校正・状態とf64値をJSON／CSVへ保存できます。無効値はJSONの `null`、CSVの空欄になります。参照比較には両結果の数値・取得条件を表示し、整定済みで公称Fs・CH・REF／フィルター設定・校正が一致する場合だけ数値差を表示します。PNGの表示対象はScope／Spectrumです。

## 同期2chのゲイン・位相・遅延を比べる

1. Software Loopbackまたは実入力で同期2chを用意し、**View / Comparison only** を選びます。
2. **Adjust** で **Analyze synchronous pair** と異なるREF／SIG CHを設定します。既定N=4,096・平均8窓では48 kHzで約0.683秒の充填が必要です。
3. **Read at** またはグラフをクリックして周波数ビンを選び、ゲイン・進み位相・コヒーレンスを読みます。正の位相はSIGの進み、正の遅延はSIGの遅れです。低REF・低コヒーレンス・欠落では数値を表示しません。
4. Stop後にJSON／CSVへ保存し、停止中に設定を復元して再測定します。復元だけで入力・出力は始まりません。参照との差は条件・校正・励振が一致する有効結果に限ります。

窓内平均を除去するf64のAC比較です。自己／複素クロスPSDを重複しない有限窓で算術平均し、H1とコヒーレンスを求めます。位相遅延は1/fだけ曖昧です。傾斜は8ビン以上の連続した十分な励振・コヒーレンスを必要とし、正弦波1本には広帯域遅延を表示しません。公称Fsを使用し、CH間位相・時間校正やDAC／ADCの絶対遅延は未確認です。PNGはScope／Spectrumの表示を対象とします。

確認範囲と未実装機能は [概要](index.md) を参照してください。
