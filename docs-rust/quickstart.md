# クイックスタート

バイナリからの導入・OS別の権限・署名状態は [配布版の導入](install.md) を参照してください。現在は公開準備中で、Rustのダウンロードは未公開です。

## ソースから起動

Rust版を含むチェックアウトとRust 1.95以降が必要です。Rust版は`main`にあります。macOSではXcode Command Line Tools、LinuxではALSA／X11／Waylandの開発ライブラリ、WindowsではMSVCとVisual Studio C++ Build Toolsを用意します。詳細はリポジトリの`guide/rust/SETUP.md`を参照してください。

リポジトリのルートで実行します。

```sh
cargo run --release --locked
```

macOS／Linuxのローカルセットアップ環境では`./scripts/cargo.sh run --release --locked`も使えます。通常は入力を停止した状態で起動します。

表示言語は **View → Language**（狭幅では **Menu → View → Language**）で9言語から選び、次回起動へ保存できます。初回と未知の設定は英語、未翻訳・未確認・古い訳も英語表示になります。言語変更は表示だけに適用され、取得・出力・測定条件・保持結果を変えません。このマニュアルの操作名は英語表示です。各言語の翻訳本文は段階的に追加します。

## 機器なしで最初の測定

起動直後のScope中央には、現在の入力元・未取得理由と **Open input settings** ボタンを表示します。入力を選んだら、上部の **Start input** を押します。開始待ち・サンプル待ち・トリガー待ち・CH範囲外・取得エラーを区別し、停止後の波形と欠落情報は保持します。

**Audio I/O → Input / output** で入力と出力を一画面に表示します。Input欄は入力元・デバイス、Output欄は出力デバイス・CH数・PCMを扱います。共通の **SAMPLE RATE · INPUT + OUTPUT** で両方が対応するFsを停止中に一度選び、**Refresh devices** で両方を再取得します。**Separate sample rates** ではFsを個別に設定できます。信号条件・ON／OFF・OUT割当はGeneratorカードで設定します。広幅は左右、狭幅は上下に並びます。

1. **Audio I/O → Input / output** で **Software Loopback** を選びます。これは通常ビルドで使え、物理出力は行いません。
2. **Back to instruments** で戻り、**Scope** の **Split view with… / Spectrum** で並べ、**Start input** を押します。
3. 区画をクリックして詳細欄の対象を選びます。CH選択・表示ON/OFF・カーソルは計器本体、時間軸・振幅・Autosetは **Scope settings**、FFT・窓・平均はSpectrumの詳細欄で調整します。最初は既定の8,192点を使ってください。
4. **Stop input** で結果を保持し、カーソルやRMS、ピーク、PSDの帯域値を読みます。
5. **File** から設定と保持結果を保存します。JSONは測定条件を含む正本、CSVは数値の再利用、PNGは表示の共有に使います。
6. 再起動後、停止中に設定を復元し、参照JSONを読み込んで再測定結果と比較できます。設定復元だけで取得は始まりません。

![現行RustのScopeとSpectrum](assets/workspace.png)

*現行QAビルドの合成入力による保持画面。ScopeとSpectrumを並べた操作例で、物理デバイスの精度を示すものではありません。*

524,288点では48 kHzで完全窓の取得に約10.92秒必要です。Live表示を速くしても、この観測時間は短くなりません。ContinuousはN/4ごとの全窓を解析し、Live／Latestの最新窓観察は過渡の捕捉を保証しません。

通常起動は入力・出力停止のScope単独表示です。計器一覧を選ぶと常に単独表示し、**Multi-instrument view / Add instrument…** で最大7計器を保持します。左右・上下・2×2・タブを選べ、狭幅では保存した配置を変えずタブへ退避します。**Open single** で単独表示へ戻ってもコンソール構成は残ります。**Remove from view** は解析・出力を停止しません。右の詳細欄は選択区画へ追従し、狭幅では **Measurement / Details** で切り替えます。**Analysis status…** で非表示の解析を確認・停止し、**Stop output** はすべての画面にあり、完全停止時だけ無効です。開始待ち・設定適用待ち・停止処理中やエラー時も停止要求を送れます。LIVE／HELD／WAITING／NOT ACQUIREDは取得状態、有効性は別表示です。設定は版10で旧版1〜9を読み、復元後の入出力は停止状態です。

左の計器一覧は上部の切り替えボタンで、アイコン＋名称の通常表示とアイコンのみのコンパクト表示を選べます。コンパクト表示ではプロット領域が広がり、ホバーで計器名と状態を確認できます。選択中は背景、実行状態は右下の点で区別します。表示モードは自動保存して次回起動に復元します。狭幅では一覧を一時的に隠し、**Menu → View → Compact sidebar** からも変更できます。

Scopeは波形直下のCH1〜CH4バーでCHを選び、チェックボックスで波形の表示を個別に切り替えます。選択と表示ON/OFFは独立し、取得済みの2ch入力では範囲外のCH3／CH4を **Out of range**（狭幅では **—**）で示します。未取得の理由は中央の案内にまとめます。詳細欄の **Scope settings / Acquisition / Trigger / Horizontal / Vertical** で取得・トリガー・時間軸・選択CHのFSレンジとオフセットを編集します。停止中の **Start single capture** は入力を開始して1回の捕捉を待ち、完了後は自動停止して波形を保持します。時間軸は波形付近に常時表示し、波形上のホイールで変更できます。Shift＋ホイールは選択CHの縦軸です。各CHの入力割当は **Vertical / Input source** で1〜16chから選べます。旧設定は2本の割当と倍率を保持し、追加CH3／CH4を表示OFFにして読み込みます。

**Amplitude [FS]** は選択CHのraw FS、**Time [ms]** はトリガー基準の時間です。**FS** はフルスケール、**Fs** は公称サンプルレート、**div** はグリッドの1目盛りを表します。RMS／P-Pは取得時の校正と単位を使い、波形軸・トリガーレベルとは区別します。上端の **T** は0 ms、右端の **T** はソースCHのレベルで、未成立時は **T markers: settings only**、捕捉済みは **T markers: captured** と示します。薄い縦ガイド線はポインターが波形内にある間だけ表示し、外へ動かしても配置済みA／Bカーソルと取得データは保持します。

Spectrumは単一グラフに最大4chを重ねます。下部のCHバーで選択と表示ON/OFFを別々に操作します。右詳細欄はFFT→Frequency / Scale→Measurement→Averagingの順です。最上部の**Amplitude / PSD / Transient (ESD)**で測定量を切り替え、共通のFFT条件・表示軸を設定します。細かな周波数範囲は**Custom frequency range**、手動レベルは**Manual**を選ぶと表示します。既定はCH1のみ表示です。

**Transient (ESD)** は過渡信号のエネルギー密度です。選択時に矩形窓・平均OFF・DC除去OFFへ切り替わります。打撃・減衰応答の全体を一つのFFT窓へ収めてください。電圧校正時はV²·s/Hz基準のdB表示、カーソル・JSON／CSVは線形値も扱い、**Window energy**は全周波数の積算V²·sです。Hann等の窓はエネルギーを減衰させ、その補正は行いません。DC除去もエネルギーを変えます。平均ONは各窓のエネルギーのEMAで、累積値ではありません。シングルショット・トリガー連携は未実装で、Live／Latestの過渡捕捉は保証しません。

**Place cursor: A / B**を選んでグラフをクリック／ドラッグすると、2つの周波数を独立に固定し、選択CHの最寄りビンの振幅／PSD／ESDとΔf・ΔLを読み取れます。A／Bの選択は次の配置対象を選ぶ操作で、配置済みの対象は **Placed** に表示します。ここでの **Clear cursors** は共通の周波数だけを解除し、時間選択とXYの点を保ちます。Scope・Spectrogram・XYでは全種類のカーソルとSpectrogramフレーム選択を解除します。取得済みデータは消去しません。平均は下部の**Average / Weight**で設定する線形パワーの指数平均（EMA）です。整定目安を表示し、処理窓数は**Advanced analysis / diagnostics**へまとめています。OFFのCHはFFTを停止し、再ONで新しい平均を開始します。ピーク・カーソル・結果書き出しは選択CHを対象にします。未校正振幅の0 dBFSはビン中心の1 FS peak正弦波です。

コンソール内で追加の測定詳細が区画高を超える場合は、その区画内を縦にスクロールできます。区画名と共通の入出力状態・停止操作はスクロールの外に残ります。

## 時間・周波数の変化を読む

**Spectrogram** を選び、**Details / Display** で配色、dBFSのMin／Max、**Auto color range**を設定します。初期設定は **Viridis、−120〜0 dBFS、Auto OFF** です。保存済みの配色・表示レンジ・Auto設定は復元時に維持し、配色の項目がない旧設定は従来のBlueで復元します。Min／Maxを編集するとManualへ戻ります。右端のカラーバーは有効な色範囲を示し、表示操作で解析・履歴は変更しません。

配色の切替順は **Viridis → Inferno → Turbo → Magma → Grayscale → Blue → Heat → Hot → Copper** です。暗騒音・微弱成分を見るときは、まず表示レンジを絞ってください。下の比較図では通常の−120〜0 dBFSに加え、−110〜−80 dBFSでも比較しています。ノイズ床付近の成分は、配色だけで確実に判別できるわけではありません。

![同じ合成音声とSTFTによる9種類のスペクトログラム配色比較](assets/spectrogram-colormap-comparison.png)

*AIで作成した説明用の比較図。各配色の主図は−120〜0 dBFS、下段の微弱成分用パネルは−110〜−80 dBFSで、AutoはOFFです。アプリのスクリーンショットや実機測定、視認性を保証する評価結果ではありません。*

プロット上のホイールで周波数をズームし、背景ドラッグで周波数・時間をパンします。Shift＋ホイールでも時間をスクロールできます。クリックでHoldへ入り、実FFTフレームを時間A／Bへ固定します。Hold中も測定は続き、**Live** で履歴と時間選択を解放します。ダブルクリックは周波数全体と現在モードの最新端へ戻ります。**Time Range** は5／10／30／60秒です。履歴は最大120秒・96 MiBで、表示は512行・1,024列以内へ縮約します。実際の保持秒数と容量制限を表示し、不足分を補完しません。

**Split view with… / Spectrum** で選択した時間A／Bを重ね、**Time A／Time B** でピーク・周波数カーソルの対象を選びます。元のf64値と取得時の窓区間・CH・Fs・FFT条件を使う未校正FS／dBFS・平均なしの表示です。未選択・欠落には理由を表示します。**Normal Spectrum**、Live、Undo、入力再開で通常Spectrumへ戻り、通常の設定・平均・保持を維持します。履歴Spectrumの出力は対象外で、FileのScopeのみの出力は使えます。

**Details / Analysis / FFT Overlap** は50／75（既定）／87.5%です。行間隔はN/2／N/4／N/8サンプルで、周波数・振幅の定義は変わりません。高Overlapでは解析量が増え、容量内の保持秒数が短くなります。取得中の変更は旧履歴と連携を解除して完全窓を待ちます。停止中の編集は次回Start用です。旧設定のOverlapは75%で復元します。

各行のFFTはN/Fs秒の窓全体を使い、行間隔はhop/Fs秒です。時間A／Bは窓終端と実際の窓区間を示します。Overlapを増やしても窓時間や周波数分解能は変わりません。

画像の上部だけにデータがある場合は、見出しの保持秒数と**Time Range**を比べてください。表示幅が保持時間より長いと下側が空白になります。表示幅を短くすると、保持した範囲を大きく確認できます。

## Generatorで正弦波を観測する

1. **Generator** を選び、**Split view with… / Scope** で並べます。通常ビルドで使える2chの内部出力です。
2. 中央のカードで **Waveform / Sine** と **OUT 1／2** を選び、各GENを **ON** にして周波数（Hz）・振幅（dBFS peak）・位相（発振器に対する進み、°）を入力します。Enterまたはフォーカス移動で適用し、Escで編集を取り消します。詳細欄の **EDIT STEP**で刻みを選び、±ボタンや上下キーでも調整できます。
3. **Audio I/O → Input / output → Generator loopback** で内部出力を入力に選び、**Start output** と **Start input** をそれぞれ押します。設定プレビューと実測波形は別です。
4. Generator単独表示からSpectrum／Lock-inを並べて解析できます。動作中の編集では振幅・位相を滑らかに遷移し、Spectrum／Lock-inは遷移後に平均・整定をやり直します。
5. **Stop input** は結果を保持し、出力は継続します。**Stop output** で出力を停止すると、取得中の入力には新しい無音サンプルが届きます。

**+ Add signal**で最大16カードまで追加でき、各カードの**Duplicate／Remove／Up／Down**で複製・削除・並べ替えます。GEN IDはOUTや順序と独立し、他カードの削除・並べ替えで出力先は変わりません。複製は新しいID・OFF・空きOUT（なければ未割当）になります。使用中のOUTはOFFのカードを含め選べません。カード構成・波形・OUTは出力停止中に変更します。

波形はSine／Square／Triangle／Noiseです。Square／Triangleは0.45 Fs未満の奇数次高調波を最大16本使い、peak欄は振幅上限、RMSは周波数依存です。Triangleの0°は正のpeakです。Noiseはseed付きの連続一様白色雑音で、周波数・位相欄は値を保持した無効表示になります。GEN見出しでカードを選び、右側でseedと適用詳細を確認・編集します。Sweep・同期／グループ・リンク・複数OUT・Mixは未実装です。

中央は従来の3行編集と設定プレビューを保ちます。広い画面はカードを2列に並べ、狭い画面はGEN ID・OUT・ON/OFFを残すカード選択になります。**Hide signal controls**で全カードを概要表示にできます。

共通Fsは**Audio I/O → Input / output**の共通欄で44.1／48／96／192 kHzから、入力・出力を停止して選びます。設定の復元には両方の停止が必要で、復元後も出力はOFFです。内部接続のJSON／CSV結果には受信区間に対応する出力条件を保存します。

実デバイスへ出力する場合は、停止中に**Audio I/O → Input / output**のOutput欄でデバイス・CH数・PCM、共通欄でFsを選び、GeneratorカードでOUTを設定します。未割当CHは無音です。**Audio I/O → Input / output**のInput欄で接続先の実入力を選び、**Start output**／**Start input**を個別に開始します。**Generator loopback**は内部接続専用です。出力通知・コールバック停止はERRORとして保持し、**Reset output (stays OFF)**と明示Startで復帰します。設定は出力先・形式を保存し、復元後はOFFです。

**Audio I/O → Input / output → Output** の **Enable dithering (TPDF)** をONにすると、8／16／24 bitのTPDFディザと量子化を選べます（既定OFF・24 bit）。f32／f64出力にも適用し、整数PCMでは形式の精度を超える深度を選べません。入出力停止中に変更し、次のStartから適用します。停止・OFF・未割当CHは無音を保ち、内部ループバックはf64のままです。条件は設定・外部出力の観測履歴に保存され、旧ファイルはディザOFFで読み込みます。

外部入出力は別の時計で、出力遷移と入力解析窓は自動対応しません。編集後は入力側の整定を待ち、Lock-inは同期REFの実入力2chを使ってください。外部Generatorを観測した結果のJSON／CSVには、実適用設定・出力状態・失敗と最大128件の観測履歴を保存します。入力Stop／Single／失敗後の編集では履歴を変更しません。履歴と入力窓の対応は未校正として参照との数値差を表示しません。ホストで応答を観測した時刻はDAC／ADC時刻ではなく、欠落・退役した履歴も補完しません。結果形式は版7で、旧版1〜6も読み込めます。出力校正・DAC／ADC遅延は未確認です。

## 実入力を使う

入力デバイスと対応するサンプルレートを選び、**Start input** を押します。macOSでは起動したアプリ／ターミナルへのマイク許可が必要です。CH数やFsは機器に依存します。CH校正を使う場合も、Scopeの波形軸とトリガーはFSのままです。

macOSの実入出力は、起動処理やスケジューリングに余裕を持たせるため、機器の対応範囲内で約20 msの音声バッファを要求します。48 kHzで対応していれば1,024フレーム、約21.3 msです。出力編集・停止の応答はこのバッファ長にも依存します。サンプルレート・CH数・PCMの選択値や測定単位は変わりません。

停止中に入力・解析・校正を編集した場合は、次回Start用の条件です。保持中の結果の取得条件は変わりません。入力変更・再開時は古い世代の結果を混ぜず、新しい履歴を取得します。

## 実験段階のLock-in

計器一覧の **Lock-in** を選び、Software LoopbackでREFと応答を用意して本体のSIG／REF CHを指定します。**Start analysis** と **Start input** を個別に開始し、REF・フィルターは詳細欄で調整します。X/YとRはpeak単位、正の位相は応答の進みです。整定中・REF喪失・欠落を有効な測定値と扱わないでください。実機確認は未完了です。

Stopの解析完了後、**File** からLock-inの条件・校正・状態とf64値をJSON／CSVへ保存できます。無効値はJSONの `null`、CSVの空欄になります。参照比較には両結果の数値・取得条件を表示し、整定済みで公称Fs・CH・REF／フィルター設定・校正が一致する場合だけ数値差を表示します。PNGの表示対象はScope／Spectrumです。

## 同期2chのゲイン・位相・遅延を比べる

1. Software Loopbackまたは実入力で同期2chを用意し、**Synchronous 2ch** を選びます。
2. 本体で異なるREF／SIG CHを設定し、**Start analysis** と **Start input** を個別に開始します。窓・平均は詳細欄で調整します。既定N=4,096・平均8窓では48 kHzで約0.683秒の充填が必要です。
3. **Read at** またはグラフをクリックして周波数ビンを選び、ゲイン・進み位相・コヒーレンスを読みます。正の位相はSIGの進み、正の遅延はSIGの遅れです。低REF・低コヒーレンス・欠落では数値を表示しません。
4. Stop後にJSON／CSVへ保存し、停止中に設定を復元して再測定します。復元だけで入力・出力は始まりません。参照との差は条件・校正・励振が一致する有効結果に限ります。

**Display range**は選択点周辺・有効帯域・Nyquist全域・任意範囲、軸は線形／対数を選べます。既定は選択点周辺を拡大します。表示範囲は測定条件を変更しません。主要値は独立した読出しに表示し、詳細のホバーとJSON／CSVに元のf64精度を残します。

窓内平均を除去するf64のAC比較です。自己／複素クロスPSDを重複しない有限窓で算術平均し、H1とコヒーレンスを求めます。位相遅延は1/fだけ曖昧です。傾斜は8ビン以上の連続した十分な励振・コヒーレンスを必要とし、正弦波1本には広帯域遅延を表示しません。公称Fsを使用し、CH間位相・時間校正やDAC／ADCの絶対遅延は未確認です。PNGはScope／Spectrumの表示を対象とします。

確認範囲と未実装機能は [概要](index.md) を参照してください。
